# 产品需求与实现状态

更新：2026-10-18。本文集中维护功能完成状态；`[x]` 仅表示完整源码实现，`[ ]` 表示未实现或部分实现。编译、运行和平台验收独立判断，当前版本尚未完成完整集成、三平台与发布验收。

## 1. 产品定位

Termeta 是本地优先、无需账号的桌面终端客户端，面向开发、运维及设备工程师。采用 Tauri 2 + Rust + Vue 3 + TypeScript，以 Termius 桌面核心体验为参照，自主实现主机管理、终端、文件与连接工具。

## 2. 平台与非目标

目标验证矩阵为 Windows 11 x64/WebView2、macOS Apple Silicon 与 Intel/WKWebView、Ubuntu 24.04 x64/WebKitGTK（X11/Wayland）。这些是待验证目标，最低系统版本及支持声明以实测确定。

不计划 Android/iOS、浏览器远程终端服务或内嵌 SSH 服务端。Mosh、AI、插件市场、跨重启会话保活与回放不在首期范围。自动双向同步和团队能力属后续范围，手动加密云备份已实现。

## 3. 核心行为

- 保存连接与当前会话分开；断开、失败和远端退出保留终端，关闭视图才销毁。手动重连向原缓冲追加，不重放输入。
- 工作区显式保存布局和已保存连接引用，打开创建新会话；不自动恢复退出前标签或持久化终端正文。
- 业务数据与秘密存于加密保险库，OS 仅缓存主密钥；不可用时密码恢复，不回退明文。
- 云备份上传独立版本、下载先预览后新增合并；应用设置和现有会话保留本机状态。

## 6. 非功能要求

- 可靠性：输入交付不确定时不自动重试；流缓冲有界，取消/关闭独立运行，尾输出不静默丢弃。
- 安全与隐私：未知密钥显式确认、变更阻断；默认不启用弱算法、Agent forwarding、OSC52 写剪贴板、遥测或会话内容日志。
- 可维护性：协议核心独立；Rust/TS、ACL 与模块文档同步，不维护第二套推测接口。
- 初始性能目标：启动 ≤2 秒、低延迟网络交互额外开销 p95 ≤20 ms、可见终端 ≥2 MiB/s 持续 60 秒、高输出 10 分钟无持续线性内存增长；20 会话（5 个持续输出）仍可操作；普通单会话进程树 ≤200 MiB、10 会话 ≤500 MiB；取消/关闭 p95 ≤3 秒。均未完成真实三平台测量。

## 7. MVP 完成定义

M2 的 P0 需求完整实现，且三平台连接、认证、信任拒绝、resize、长输出、取消、关闭、重连和加密持久化具有实际证据，才可称 MVP 验收通过。单平台反馈、依赖库能力或静态检查不能替代应用验收。
