# 产品需求与实现状态

更新：2026-10-27。本文集中维护功能状态：源码完整实现即标记 `[x]`，未实现或部分实现标记 `[ ]`；已实现能力与剩余范围分列，不记录测试或验证状态。

## 1. 产品定位

Termeta 是独立使用本机加密保险库的桌面终端客户端，面向开发、运维及设备工程师。采用 Tauri 2 + Rust + Vue 3 + TypeScript，以 Termius 桌面核心体验为参照，自主实现主机管理、终端、文件与连接工具。

## 2. 平台与非目标

目标平台为 Windows 11 x64/WebView2、macOS Apple Silicon 与 Intel/WKWebView、Ubuntu 24.04 x64/WebKitGTK（X11/Wayland）。

不计划 Android/iOS、浏览器远程终端服务或客户端内嵌 SSH 服务端。Mosh、AI、插件市场、跨重启会话保活与回放不在首期范围。Gist/WebDAV 手动第三方备份已实现；第三方自动双向同步和团队能力属后续范围。

当前 dev 仅提供与 cloud 分支 schema 10 保险库的数据库兼容，不包含 CLOUD 产品功能；兼容范围与迁移约束见 [存储](07-storage.md#6-schema-与迁移)。

## 3. 核心行为

- 保存连接与当前会话分开；断开、失败和远端退出保留终端，关闭视图才销毁。手动重连向原缓冲追加，不重放输入。
- 工作区显式保存布局和已保存连接引用，打开创建新会话；不自动恢复退出前标签或持久化终端正文。
- 业务数据与秘密存于加密保险库，OS 仅缓存主密钥；不可用时密码恢复，不回退明文。
- 第三方备份上传独立版本、选择恢复版本后验证并直接新增合并，无二次确认；应用设置和现有会话保留本机状态。

职责归属见 [系统架构](03-architecture.md)，剩余结构问题见 [结构评估](27-architecture-refactoring.md)。

## 6. 非功能要求

- 可靠性：输入交付不确定时不自动重试；流缓冲有界，取消/关闭独立运行，尾输出不静默丢弃。
- 安全与隐私：未知密钥显式确认、变更阻断；默认不启用弱算法、Agent forwarding、OSC52 写剪贴板或遥测；会话内容仅关闭视图/软件时归档到本机加密日志，不进入云备份。
- 可维护性：协议核心独立；Rust/TS、ACL 与模块文档同步，不维护第二套推测接口。
- 初始性能目标：启动 ≤2 秒、低延迟网络交互额外开销 p95 ≤20 ms、可见终端 ≥2 MiB/s 持续 60 秒、高输出 10 分钟无持续线性内存增长；20 会话（5 个持续输出）仍可操作；普通单会话进程树 ≤200 MiB、10 会话 ≤500 MiB；取消/关闭 p95 ≤3 秒。
