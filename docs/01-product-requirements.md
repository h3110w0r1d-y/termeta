# 产品需求与范围

日期：2026-10-15。需求基线，状态：源码实现待验收。

## 1. 产品定位

Termvexa 面向需要频繁连接服务器的开发、运维和设备工程师。首期提供本地优先、无需账号、凭据由用户控制的桌面 SSH 工作台；长期对标 Termius 的主机管理、终端、文件传输和连接工具体验。Termius 官网公开展示 SFTP、Snippets、端口转发等能力，但本项目按自己的里程碑交付，不承诺一次覆盖其全部产品。[产品参照](https://www.termius.com/)

## 2. 平台与非目标

| 平台    | 计划发布范围              | 待确认项                                 |
| ------- | ------------------------- | ---------------------------------------- |
| Windows | Windows 11 x64 + WebView2 | Windows 10、ARM64 以后评估               |
| macOS   | Apple Silicon 与 Intel    | 最低系统版本由 Tauri/WebKit/依赖实测确定 |
| Linux   | 优先 Ubuntu 24.04 LTS x64 | WebKitGTK、发行版打包、Wayland/X11 实测  |

这是初始验证矩阵，并非已通过的支持声明。只考虑桌面端；Android/iOS、浏览器远程终端服务、内嵌 SSH 服务端不在范围。首期不包含 Mosh、Telnet、AI、云同步、团队权限、插件市场、跨重启保活和终端会话回放。

## 3. 用户场景

1. 用户创建主机、选择密码或私钥，核验首次指纹后进入远端 Shell。
2. 同时打开多个服务器终端，在标签间切换，远端任务与屏幕缓冲持续存在。
3. 连接超时、失败或中断时保留原 Tab 与终端，历史仍可滚动/复制/搜索；手动重连创建新后端连接，在原终端继续追加输出，不重放已有输入。
4. 重启应用后保留主机、分组、偏好与历史；不自动连接、不宣称恢复远端 Shell；主机专属密码按保存表单的非空输入存入 OS 凭据库。
5. 后续在同一个终端框架内打开本地 PTY 或串口；串口原始字节可进入独立 HEX 查看器。

分组删除默认只删除分组并把直属主机/子分组移动到父级，预览影响并确认；删除主机清理其专属密码，不删除共享凭据，也不自动关闭已经建立的会话。

“断开连接”与“关闭 Tab”是两个操作：前者释放后端连接但保留视图与历史，后者由用户明确触发并释放视图。历史保留受已配置的 scrollback 上限约束，不因重连额外裁剪；终端正文不跨应用重启持久保存。错误提示不得用整页遮罩阻止滚动或复制。

## 6. 非功能要求

- 可靠性：输出不得静默截断；重连与写入不可自动重试导致命令重复执行；清理有时限与可观测结果。
- 安全：默认拒绝未知/变更密钥，用户明确确认后才信任；密码和私钥不以明文落盘。默认关闭弱算法、Agent forwarding、OSC52 剪贴板写入。
- 性能：采用 [验证计划](11-validation.md) 的初始目标；所有指标在真实三平台测量前只称“目标”。限制滚屏、并发会话、流缓冲及输入大小。
- 隐私：默认无账号、无遥测、无会话内容日志；错误报告不包含凭据或完整终端内容。
- 可维护性：协议核心不依赖 Tauri；一个统一生命周期和数据通路；业务变化同步文档。
- 可用性：终端内容支持 UTF-8，UI 首期中文；显示文案集中管理，预留 i18n，不把多语言平台建设设为前置。

## 7. MVP 完成定义

M2 的 P0 需求全部落实且通过授权后的验证矩阵，至少完成三平台的连接、认证、密钥拒绝、resize、长输出、取消、关闭、重连和存储持久化。仅跑通一个 SSH 样例不算 MVP；仅有设计文档也不算功能实现。无法覆盖的平台或认证格式必须列出限制，不能用“russh 支持”代替应用验证。

## 8. 当前实施范围

M1/M2 的 SSH、主机/凭据、终端生命周期、分屏广播、Naive UI、配色和快捷键已落源码；未完成三平台集成验收，不能标记 MVP 已完成。

单 SSH 终端底部开关显示可调宽右侧 SFTP 侧栏；Workspace 禁用，开启侧栏的终端不能作为分屏合并来源或目标。面板提供分页浏览、目录链接逻辑路径导航、上传下载与轻量批次队列。上传支持原生多选和文件/目录拖入，目标固定当前目录；文件逐项确认覆盖，目录递归合并。macOS 原生文件承诺支持文件和真实目录递归拖出，源链接不递归；Windows/Linux 拖出未实现。隐藏继续任务，断开或关闭终端会取消任务，不支持独立连接租约。

独立双栏、位置持久化、远端互传、完整任务恢复及 Local/Serial/隧道保持后续范围。静态检查不等于编译或运行验证，当前限制见 [实施状态](17-implementation-status.md) 和 [SFTP](16-sftp-workspace.md)。
