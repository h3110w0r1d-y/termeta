## 1. 产品定位

Termvexa 面向需要频繁连接服务器的开发、运维和设备工程师。首期提供本地优先、无需账号、凭据由用户控制的桌面 SSH 工作台；长期对标 Termius 的主机管理、终端、文件传输和连接工具体验。Termius 官网公开展示 SFTP、Snippets、端口转发等能力，但本项目按自己的里程碑交付，不承诺一次覆盖其全部产品。[产品参照](https://www.termius.com/)

## 3. 用户场景

1. 用户创建主机、选择密码或私钥，核验首次指纹后进入远端 Shell。
2. 同时打开多个服务器终端，在标签间切换，远端任务与屏幕缓冲持续存在。
3. 连接超时、失败或中断时保留原 Tab 与终端，历史仍可滚动/复制/搜索；手动重连创建新后端连接，在原终端继续追加输出，不重放已有输入。
4. 重启应用后保留主机、分组、偏好与历史；不自动连接、不宣称恢复远端 Shell；首次设置保险库密码后，主机配置及凭据统一存入AES-256加密数据库，OS凭据库只保存一把主密钥；后续优先自动解锁，失败则密码恢复并重存主密钥。
5. 后续在同一个终端框架内打开本地 PTY 或串口；串口原始字节可进入独立 HEX 查看器。

分组删除先选择处理方式：默认只删除当前组并把直属主机/子分组移动到父级；选择一并删除会展示子树/主机数量并独立二次确认，Rust事务删除整棵子树和主机、登记专属密码清理；共享凭据与已有会话不受影响。删除主机清理其专属密码，不删除共享凭据，也不自动关闭已经建立的会话。

“断开连接”与“关闭 Tab”是两个操作：前者释放后端连接但保留视图与历史，后者由用户明确触发并释放视图。历史保留受已配置的 scrollback 上限约束，不因重连额外裁剪；终端正文不跨应用重启持久保存。错误提示不得用整页遮罩阻止滚动或复制。

## 6. 非功能要求

- 可靠性：输出不得静默截断；重连与写入不可自动重试导致命令重复执行；清理有时限与可观测结果。
- 安全：默认拒绝未知/变更密钥，用户明确确认后才信任；密码和私钥不以明文落盘。默认关闭弱算法、Agent forwarding、OSC52 剪贴板写入。
- 性能：限制滚屏、并发会话、流缓冲及输入大小。初始待测目标为启动 ≤2 秒、低延迟网络新增交互开销 p95 ≤20 ms、可见终端 ≥2 MiB/s 持续60秒且高输出10分钟无持续线性内存增长、20会话（5个持续输出）仍可操作、单普通会话进程树 ≤200 MiB/10会话 ≤500 MiB、取消关闭 p95 ≤3秒。所有指标在真实三平台测量前只称“目标”。
- 隐私：默认无账号、无遥测、无会话内容日志；错误报告不包含凭据或完整终端内容。
- 可维护性：协议核心不依赖 Tauri；一个统一生命周期和数据通路；业务变化同步文档。
- 可用性：终端内容支持 UTF-8，UI 首期中文；显示文案集中管理，预留 i18n，不把多语言平台建设设为前置。

## 7. MVP 完成定义

M2 的 P0 需求全部落实且通过授权后的验证矩阵，至少完成三平台的连接、认证、密钥拒绝、resize、长输出、取消、关闭、重连和存储持久化。仅跑通一个 SSH 样例不算 MVP；仅有设计文档也不算功能实现。无法覆盖的平台或认证格式必须列出限制，不能用“russh 支持”代替应用验证。

### 8.5 SFTP 当前边界

单 SSH 终端底部开关控制可调右栏，隐藏保留浏览与传输，断线/关闭取消；Workspace 无效，开启侧栏的终端不能作为来源或目标参与分屏，仍可排序。

列表每次最多100项、协议包256 KiB、视图10000项；选择框/名称图标/大小/权限，目录及目录链接优先，`..` 置顶且根目录禁用；大小按1024进制两位小数。READLINK/STAT识别链接原始目标与类型，失败降级未知；实际请求保留 `/bin/...` 逻辑路径，不先展开目标。终端外部留白归 terminal-host margin，侧栏不继承。

上传按钮多选文件，外部文件/目录拖入仅以当前浏览目录为目标，确认后排队。原生路径登记为 owner-bound、一次性 dropId（5分钟/16批/每批1000根）；前端不能传任意本地路径。递归上限64层/10000项，拒绝源链接/特殊项，目录保留合并，文件/目录类型冲突拒绝，树内远端链接不自动合并。

上传直接写最终文件，不依赖远端 hardlink/临时项；同名普通文件逐项原生确认后打开、核对类型、截断并以64 KiB块写入。中断可能留下不完整内容、旧文件无法回滚；SFTP v3 并发路径替换竞态仍存在，不能宣称原子覆盖。目录不会被删除来处理冲突。

macOS 用 NSFilePromiseProvider 拖出普通文件/真实目录及混合多选（最多100根）；外部接受并请求写入后才显示下载记录，取消/内部松开不显示，也不触发上传。软件内Drop直接取消拖出，上传仅消费有真实路径的外部Enter/Drop配对，迟到或空路径回流忽略。主线程50ms松键检测独立于ended回调及Copy结束结果，软件内松键且未兑现时按取消收尾；外部松键后等待兑现，未兑现条目在无写入回调时有5秒等待上限，收尾后拒绝迟到兑现并恢复侧栏操作；命令返回前对已交接原生且已松键的手势补齐WebView mouseUp，前端清理指针捕获与点击抑制；用户已确认取消后首次点击及再次拖动恢复正常；拖出令牌现由命令统一持有并显式传入原生层，底层不重复校验条目上限；原生拖放完整矩阵仍待验收。Finder授权新目标后才开始读取；目录独立游标、64层/10000项、不递归跟随链接/特殊项，不覆盖或删除已有本地目录，失败保留已完成内容并报告数量/路径。

“显示隐藏文件”在侧栏与双栏全局同步，自动保存至数据库app.sftpShowHidden，旧设置默认false；设置写入串行化，设置页旧草稿不会覆盖即时偏好，保存失败维持原值并提示。

普通文件下载以本地独占临时项+硬链接无覆盖发布，不支持硬链接时明确失败；下载按钮仍为单文件。终端侧栏前端最多32等待批次、20结束记录，全局4任务/每浏览器1操作；选择器/扫描/确认/读写可取消，隐藏继续，断线/重连不重放。固定双栏从保存主机独立建立两条SSH/SFTP连接，复用主机信任与认证，不申请PTY/Shell；各自浏览器和分页游标，切页保活，断开/窗口退出释放。Pointer Events栏间拖动多选普通文件或真实目录到对侧当前目录；Rust以64 KiB流式中转，源树预扫描64层/10000项，同名文件确认覆盖、目录合并，进度与取消共用Channel，双端锁/一个全局传输许可。Windows/Linux原生拖出、本地浏览、通用共享连接租约尚未实现。
