# 产品需求与范围

日期：2026-10-15。需求基线 v0.2，状态：待实现。

## 1. 产品定位

Termvexa 面向需要频繁连接服务器的开发、运维和设备工程师。首期提供本地优先、无需账号、凭据由用户控制的桌面 SSH 工作台；长期对标 Termius 的主机管理、终端、文件传输和连接工具体验。Termius 官网公开展示 SFTP、Snippets、端口转发等能力，但本项目按自己的里程碑交付，不承诺一次覆盖其全部产品。[产品参照](https://www.termius.com/)

## 2. 平台与非目标

| 平台 | 计划发布范围 | 待确认项 |
| --- | --- | --- |
| Windows | Windows 11 x64 + WebView2 | Windows 10、ARM64 以后评估 |
| macOS | Apple Silicon 与 Intel | 最低系统版本由 Tauri/WebKit/依赖实测确定 |
| Linux | 优先 Ubuntu 24.04 LTS x64 | WebKitGTK、发行版打包、Wayland/X11 实测 |

这是初始验证矩阵，并非已通过的支持声明。只考虑桌面端；Android/iOS、浏览器远程终端服务、内嵌 SSH 服务端不在范围。首期不包含 Mosh、Telnet、AI、云同步、团队权限、插件市场、跨重启保活和终端会话回放。

## 3. 用户场景

1. 用户创建主机、选择密码或私钥，核验首次指纹后进入远端 Shell。
2. 同时打开多个服务器终端，在标签间切换，远端任务与屏幕缓冲持续存在。
3. 连接超时、失败或中断时保留原 Tab 与终端，历史仍可滚动/复制/搜索；手动重连创建新后端连接，在原终端继续追加输出，不重放已有输入。
4. 重启应用后保留主机、分组、偏好与历史；不自动连接、不自动保存密码、不宣称恢复远端 Shell。
5. 后续在同一个终端框架内打开本地 PTY 或串口；串口原始字节可进入独立 HEX 查看器。

| TERM-03 | M2/P0 | 多标签、切换保活、独立关闭与重连 | 关闭单标签不影响其他会话；切换不重建 xterm |
| TERM-04 | M2/P0 | 选择复制、粘贴、终端搜索、可配置滚屏、字体/字号 | 多行粘贴可确认；快捷键与配色按 KEY/THEME 需求独立设置 |
| TERM-05 | M1/P0 | 断线、认证/连接失败、正常远端退出均保留 Tab 和终端缓冲 | 不清屏、不自动关闭；支持滚动、选择、复制，已有搜索能力保持可用；首次失败也保留空终端与错误信息 |
| TERM-06 | M2/P0 | 重连复用相同 Tab、terminalId、xterm 实例与滚屏历史，在末尾继续追加 | 新后端 sessionId；不 clear/reset/dispose；重连失败仍保留全部已有缓冲；迟到旧输出不混入新连接 |
| LIFE-01 | M1/P0 | 状态可见、超时、取消、幂等关闭、远端退出 | 无悬挂连接任务；关闭可打断等待信任/认证/ACK |
| LIFE-02 | M2/P0 | KeepAlive、睡眠/网络中断识别、手动重连 | 不因用户空闲自动退出；重连重新校验密钥 |
| PERF-01 | M1/P0 | 输出分块、有界队列、ACK、输入保序 | 大量输出时内存受界约束且可关闭 |
| DATA-01 | M2/P0 | SQLite 主机、分组、设置、连接历史；迁移与备份 | 迁移失败保护旧数据；秘密不在 DB/日志 |
| SEC-01 | M1/P0 | 受控 IPC、资源所有权、CSP、安全 URL | 非授权 WebView 调用失败；远端内容不成为 HTML |
| UX-01 | M2/P0 | 清晰错误、键盘导航、中文输入法、焦点管理 | 信任/认证弹窗聚焦；关闭后焦点合理恢复 |
| UX-02 | M2/P0 | Reka UI 基础控件 + 项目组件封装 + 自定义桌面样式 | 主题/密度/结构可定制；弹层不吞终端快捷键，隐藏标签不卸载终端；具体版本待验证 |
| KEY-01 | M2/P0 | 设置分全局（应用前台跨页面）/终端类别，动作尽量可自定义 | 录制/多绑定/禁用/恢复/导入导出/冲突提示；按钮/菜单同命令，详见 14 |
| KEY-02 | M2/P0 | 终端修饰键+鼠标绑定，默认 Cmd/Ctrl+点击 URL 打开浏览器 | 普通点击不打开；只允许 http/https，离线历史也可用，不重复发送鼠标事件 |
| KEY-03 | M2 配置、M4 启用 | 全局 Cmd+L 新建 Local Terminal，其他平台默认 Ctrl+Shift+L | Local 未实现显示禁用原因；可自定义，不占用默认远端 Ctrl+L |
| THEME-01 | M2/P0 | 独立终端配色：至少 8 内置方案、自定义取色/HEX/RGB、ANSI 编辑 | 全局/profile/当前终端覆盖；热切换不清空、不重连，与应用主题独立 |
| THEME-02 | M2/P0 | 原生 scheme JSON 与 xterm ITheme JSON 导入/导出 | 校验/预览/重名处理、无静默覆盖；其他格式范围见 15 |

分组删除默认只删除分组并把直属主机/子分组移动到父级，预览影响并确认；删除主机不自动删除共享凭据，也不自动关闭已经建立的会话。

“断开连接”与“关闭 Tab”是两个操作：前者释放后端连接但保留视图与历史，后者由用户明确触发并释放视图。历史保留受已配置的 scrollback 上限约束，不因重连额外裁剪；本轮不要求跨应用重启持久保存终端正文。错误提示不得用整页遮罩阻止滚动或复制。

## 6. 非功能要求

- 可靠性：输出不得静默截断；重连与写入不可自动重试导致命令重复执行；清理有时限与可观测结果。
- 安全：默认拒绝未知/变更密钥，用户明确确认后才信任；密码和私钥不以明文落盘。默认关闭弱算法、Agent forwarding、OSC52 剪贴板写入。
- 性能：采用 [验证计划](11-validation.md) 的初始目标；所有指标在真实三平台测量前只称“目标”。限制滚屏、并发会话、流缓冲及输入大小。
- 隐私：默认无账号、无遥测、无会话内容日志；错误报告不包含凭据或完整终端内容。
- 可维护性：协议核心不依赖 Tauri；一个统一生命周期和数据通路；业务变化同步文档。
- 可用性：终端内容支持 UTF-8，UI 首期中文；显示文案集中管理，预留 i18n，不把多语言平台建设设为前置。

## 7. MVP 完成定义

M2 的 P0 需求全部落实且通过授权后的验证矩阵，至少完成三平台的连接、认证、密钥拒绝、resize、长输出、取消、关闭、重连和存储持久化。仅跑通一个 SSH 样例不算 MVP；仅有设计文档也不算功能实现。无法覆盖的平台或认证格式必须列出限制，不能用“russh 支持”代替应用验证。
