# 有效架构决策

更新：2026-10-17。本文按当前源码归纳有效决策及理由，不保留逐次修复日志；实现进度见 [路线](10-roadmap.md)，验证状态见 [需求](01-product-requirements.md#11-运行验收边界)。

## 1. 桌面技术与协议边界

采用 Tauri 2 + Rust + Vue 3 + TypeScript，Rust workspace 使用 edition 2024/resolver 3，前端使用 pnpm。协议核心不依赖 Tauri/Vue，具体 SSH/Telnet/Local/Serial 工厂依赖 terminal-core；Tauri 壳负责装配、权限与桥接。理由是复用生命周期和数据通路，同时将协议/设备差异留在适配器。当前不引入 HTTP/WebSocket 后端或 React。

## 2. 会话 actor 与受界数据流

每会话独立 actor、有界字节队列和取消信号，输出走二进制 Channel、控制走类型化 Channel，以 xterm 解析后的累计 ACK 施加背压。取消不能被输出 ACK、认证或文件 I/O 阻塞。全局表锁仅查找/复制轻量句柄，不跨网络或数据库等待。协议扩展沿用 core 的类型与能力，不添加任意 JSON 控制入口。

## 3. 稳定终端与布局分离

terminalId 跨重连稳定，sessionId 表示一次连接；TerminalRegistry 按 terminalId 持有 xterm，TerminalStage 扁平渲染宿主。标签切换、分屏/交换、窗格迁移和重连保留同一实例及缓冲，只有用户关闭视图才销毁。理由是避免布局操作和连接失败破坏历史、选区与终端状态。

运行树与存档分离：工作区仅显式保存布局、焦点和保存主机 ID，打开创建新会话，广播关闭。存档不包含秘密、输出或 live handle，不自动恢复退出前的标签。完整契约见 [工作区设计](18-terminal-workspaces.md#8-显式保存与替换工作区)。

## 4. 加密保险库与迁移不可变

SQLCipher 加密全部业务表；Argon2id 从用户密码派生主密钥，OS 凭据库仅缓存一把主密钥。缓存不可用时密码恢复，不回退明文。数据库和配套 vault 元数据必须配对保留，不自动迁移/删除早期格式。

已应用迁移字节不可变，后续变更新增迁移，保留 SQLx 校验。当前 schema 6 接受同加密格式 schema 2–5 升级；迁移在专用连接上运行，恢复外键并核验后才发布业务池。四类保存项使用 trim 后区分大小写的唯一名称与 revision 事务，避免并发覆盖。见 [存储契约](07-storage.md)。

2026-10-17：保险库改密保留直接密码派生主密钥的加密格式2，在加密副本上执行 SQLCipher rekey，校验后用持久化状态标记协调数据库/元数据切换。理由是单独更新校验记录不能改变数据密钥，而直接对活动数据库 rekey 难以与元数据形成可恢复提交。代价是额外磁盘空间及短暂等待数据库请求；原 OnceLock 池改为可切换的生命周期门闩，活动终端不重建。提交后 OS 缓存/清理失败以成功附警告返回，备份与未清理旧副本仍受旧密码保护。详见[存储](07-storage.md#修改密码与中断恢复)。

## 5. SSH 身份与认证由 Rust 管理

未知主机密钥需确认，变更密钥阻断；前端不读取已保存密码或私钥正文。主要认证为密码或公钥，Keyboard-interactive/OTP 按服务器协商补充，OTP 不持久化。仅明确且唯一的非回显密码提示允许自动使用保存密码一次；空白零输入轮自动响应，其他提示人工处理。

系统识别只在保存 SSH 终端打开后运行独立固定 exec，探测前事务消耗一次机会，失败不重试。结果仅作图标信息，不参与信任、授权或算法降级。理由是隔离远端探测与用户终端输入。

2026-10-16：SSH 主机增加 Shell/exec 启动方式。exec 仍申请 PTY 并复用终端 actor，不通过 Shell 模拟输入，命令退出不回退 Shell、不自动重启。理由是支持工作区内并排操作与交互监控程序，避免提示符/输入时序影响。命令保存于现有 config_json，工作区继续引用主机 ID，无新增表或迁移；文件/转发不继承终端启动行为，命令模式跳过自动系统识别。

## 6. SFTP 与端口转发独立于终端协议

终端 SFTP 侧栏复用该终端的认证连接，固定双栏使用独立文件会话；端口转发使用独立转发会话。后两者不请求 PTY/Shell，切页保活；通用跨功能连接租约仍是后续范围。文件正文和转发载荷只在 Rust 中流动，不进入 Vue/Pinia。

上传普通文件逐项确认后直接覆盖，目录合并，失败可能留下部分内容；下载拒绝覆盖。macOS 拖出使用原生文件/目录承诺，Web Pointer Events 仅用于应用内对拷与布局交互，不能替代系统拖出。详见 [SFTP](16-sftp-workspace.md) 与 [转发](21-port-forwarding.md)。

## 7. UI 库、主题与图标

通用交互优先使用 Naive UI 2.45.3，封装保持薄适配；工作区标签和终端几何由应用管理。业务 CSS 位于所属 Vue scoped 样式，两个窗口共用 assets/base.css。应用明暗/主色与终端配色独立，设置有效修改自动持久化并跨窗口热应用。

通用按钮/导航图标使用 xicons Ionicons 5；用户指定的28个 SSH 系统/类型 SVG 为明确资源例外，保留来源与摘要。现有 SFTP 文件类型和分组文件夹图案继续保留。来源详见 [UI 选型](13-ui-stack.md#图标来源与替换范围) 与 [资源说明](../resources/README.md)。

## 8. 权限、输入与广播

所有业务 IPC 经 desktop 门面、自定义命令 ACL、本地窗口校验及资源所有权检查。settings 窗口只获得设置、专用保险库改密和 JSON 导出权限，不获得会话、凭据或文件管理权限。

广播默认关闭且不持久化，仅复制当前组的用户输入，各目标独立排队，禁止跨重连重放。命令模式窗格默认且固定排除收发，依据后端本次实际会话模式判断；直接操作保留，避免监控按键与普通 Shell 输入互相干扰。固定 xterm 6 的内部用户输入事件仅由 inputOrigin.ts 薄适配订阅；能力缺失拒绝开启广播。升级 xterm 需复核 IME、自动应答与事件顺序。系统后台热键另行 opt-in，不混同应用内快捷键。
