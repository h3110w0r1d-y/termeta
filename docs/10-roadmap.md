## 2. M1：SSH 纵向切片

依赖 M0，已实现 core/ssh、Tauri 门面与 xterm 数据通路。核心交付包括 owner/request 幂等、每会话 actor、有界输入输出、独立取消、二进制 Channel/消费 ACK、主机信任、密码/公钥/多轮交互认证、PTY/Shell/resize/KeepAlive。

退出条件：SSH 拒绝/临时信任/保存信任、密钥变化阻断、认证失败/取消、满输出队列关闭和尾输出全部有真实证据；未信任前不读取或提交秘密，核心不依赖 SSH/Tauri 类型。M1 当前未验收通过。

## 4. M3：专业 SSH 工作台

| 任务                   | 依赖                     | 当前边界与剩余工作                                                                                                        |
| ---------------------- | ------------------------ | ------------------------------------------------------------------------------------------------------------------------- |
| SSH channel 与连接租约 | M1/M2                    | 已复用认证连接签发 owner-bound SFTP channel；独立 SFTP 认证/后台租约未实现                                                |
| 文件服务与浏览         | SSH channel              | files/sftp crate、每页 100 项、链接识别/逻辑路径导航已实现；独立本地浏览与完整能力映射未实现                              |
| 上传下载与任务         | 文件服务                 | 有界流、多选/目录上传、直接覆盖确认、目录合并、前端串行批次与取消已实现；跨远端/本地端点复制与完整 TransferManager 未实现 |
| 单终端侧栏             | 文件服务、任务           | 底部开关、可调右栏、隐藏保活；Workspace 禁用，开启侧栏禁止参与分屏；其他停靠位置及尺寸持久化未实现                        |
| 原生文件拖放           | 文件服务、任务、平台适配 | 三平台拖入、macOS 文件/目录承诺拖出已落源码；Windows/Linux 拖出未实现，所有原生运行验收待执行                             |
| 独立双栏               | 连接租约、本地浏览、任务 | 固定 Tab 仍占位；端点切换、内部拖拽与快照授权未实现                                                                       |
| SSH 扩展               | 连接服务与权限治理       | 隧道、ProxyJump/Agent/config 导入未开始，禁止自动 ProxyCommand 与默认 Agent forwarding                                    |
| 工作台扩展             | M2                       | Snippets、opt-in 会话日志、布局持久化/恢复未开始                                                                          |

上传直接写最终文件，同名普通文件确认后覆盖；目录仅合并，不删除目录处理冲突。中断可能留下不完整目标且覆盖不能回滚，不能宣称原子覆盖。下载保持独占临时项和本地硬链接无覆盖发布。详见 [SFTP 设计](16-sftp-workspace.md)。

M3 退出条件：浏览/传输安全边界、取消/断线/磁盘满、SSH 公平性及 SP-10/11 有实际结果。原生拖出必须在真实文件管理器验收，浏览器 DOM 行为不能代替。

## 5. M4：Local Terminal 与 Serial

| 子阶段 | 最小交付与退出条件                                                                |
| ------ | --------------------------------------------------------------------------------- |
| Local  | portable-pty 工厂、Shell/cwd/env、resize、退出码与进程树清理；三平台真实 PTY 验证 |
| Serial | 枚举、串口参数、独占、DTR/RTS、拔出错误与可退出读取；真实设备验证                 |
| HEX    | 原始字节、虚拟列表、时间戳、文本/HEX 与换行发送、Local Echo；有界滚屏和丢字节检测 |

Local 工厂落地后才启用预留的 Cmd+L 动作。本地文件浏览不依赖 Local PTY。串口背压不能保证外设永不溢出，必须显示丢字节或驱动错误。

## 6. M5：发布与产品化

完成三平台安装、签名/公证、Linux 桌面集成、受签名验证的更新、备份恢复、依赖 notices 和诊断流程。最低系统版本按验证结果确定，默认不新增遥测。系统后台热键为独立 opt-in 能力；云同步/Vault/团队与移动端不作为首期依赖。

## 7. 执行与风险

近期优先验收用户可见修复与原生拖放，再覆盖认证/信任/凭据、重连/关闭/流控、安全/压力/三平台。主要风险是 WebView/IME 差异、OS 凭据服务、共享 SSH channel 公平性、取消收尾、直接覆盖竞态及依赖公告。

按 AGENTS.md，代理未经明确要求不编译、启动、运行测试或连接 SSH/串口。允许格式、类型、清单/锁文件、ACL、文档和差异等无构建静态检查；每次交付记录实际检查与未执行项，不以静态通过标记里程碑通过。
