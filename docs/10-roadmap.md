## 2. M1/M2：终端与持久化基线

M1 依赖协议无关 core、SSH 适配器和 Tauri/前端流桥。M2 在稳定 terminalId/xterm 与存储/安全适配器上提供主机管理、分屏和设置。

验收需覆盖未知/变更密钥、密码/加密私钥/OTP/PAM、取消与超时、PTY/resize/KeepAlive、洪泛与无 ACK 关闭、失败保留、连续重连、IME/焦点/全屏。保险库还需覆盖 SQLCipher 三平台原生依赖、初始化中断、密码恢复/修改、OS 缓存失败、迁移及配对备份；改密还需验证 WAL/活动历史保留、并发写入、新旧密码切换、磁盘满与各文件切换/恢复阶段中断。当前存储基线为 schema 6，升级契约统一见 [存储设计](07-storage.md)。

DATA-03 已实现 Gist / WebDAV 手动备份、逐包解密的版本列表、下载预览与非覆盖合并，以及首次初始化云拉取并将云端配置及备份密码写入本机加密设置；详见[备份与同步](22-data-backup.md)。白名单 SQLite 快照、Zstd 压缩、独立密码加密、8 个命令与窗口 ACL 均已接入，schema 6 及已应用迁移不变。退出门槛包括真实云服务/跨设备恢复、凭据与工作区关联、名称和信任冲突、超限/损坏/错密码、配置旧版补填升级/秘密脱敏/已保存密码复用、预览过期/重复确认、初始化与事务中断、远端异常及 ACL 拒绝路径；这些编译和运行验收尚未执行。自动备份、双向融合、版本清理、本地文件入口与取消 IPC 仍待实现。

SSH 命令模式已接入保存/临时连接、PTY exec、退出后手动重新运行及广播隔离；仍需验证 exec 接受/拒绝、短命令尾输出、非零退出/信号、监控全屏缩放/按键、关闭提醒、保存工作区重新打开，以及独立 SFTP/转发不执行命令。无 PTY、自定义 cwd/env 和自动重启不属本次实现。

应用多语言首轮已接入简体中文/English/跟随系统及跨窗口热应用，设置窗口原生标题已复用同一词典并随语言更新；仍需验收语言持久化、系统回退、表单/菜单切换、窗口标题热切换/重新打开与英文布局；后端诊断、系统原生菜单/对话框的应用文案及更多语种仍待扩展。

终端运行层位于 workbench 模块，使用 Workbench/TerminalTabGroup/TerminalItem 区分工作台、标签组与终端，Workspace 保留给工作区功能；AppTabs、SftpBrowser 与相关 class/DOM 标识已同步命名。快捷键仅接受版本 2（workbench 命令与上下文），读取/导入不再转换旧格式或自动补充动作；本地迁移已由用户确认完成，移除转换后的当前格式读写、JSON 往返、旧格式拒绝、重启及双窗口更新仍待运行验收。重命名后的样式、焦点和 ARIA 关联仍需运行验收。标签排序已统一为连续插入槽和单一指示线，保留间隙、源标签占位及窗格悬停切页；横纵间隙松手、首尾/原位/双向排序、溢出自动滚动、窗格拆出/取消和焦点恢复仍需三平台运行验收，回归源码尚未执行。

M2 退出要求全部对应 P0 需求及平台矩阵具有实际证据。系统后台热键另属 M5 opt-in 能力。

终端滚轮广播已按源端最终输入分发，未聚焦窗格可作为滚轮来源；不再派发合成滚轮或由接收端累积触摸板增量。公开滚轮敏感度固定为2，用户已确认所测场景多终端滚动同步；仍需验收两倍敏感度体验及 macOS/Windows/Linux 下双向滚动速率、原生事件标记时序、SGR/像素/二进制模式、历史滚动与模态/命令/隐藏组隔离。回归源码未执行，详见[工作区输入广播](18-terminal-workspaces.md#5-工作区输入广播)。

## 4. M4：Local、Serial 与 Telnet

| 类型   | 已有实现                                                               | 剩余范围                                                                     |
| ------ | ---------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| Local  | 系统 Shell、主目录、继承环境、PTY/resize/退出码、原缓冲重开、复制/分屏 | 自定义 Shell/cwd/env、完整跨平台进程树清理与真实 PTY 验收                    |
| Serial | 枚举/手输、保存配置、参数与字符集、独占文本 I/O、原缓冲重开            | 手动 DTR/RTS、DSR/DTR 流控、其他设备/高级参数/平台验收                       |
| Telnet | TCP、IAC/BINARY/ECHO/SGA/TTYPE/NAWS、保存/快速连接、明文终端登录       | 实际服务兼容性、登录回显、尺寸与三平台验收；TLS/自动登录/非 UTF-8 当前不支持 |
| HEX    | 尚未实现                                                               | 原始字节通道、虚拟列表、时间戳、HEX/文本发送、换行和 Local Echo              |

本地文件浏览属于 M3，不依赖本地 PTY。串口背压不保证硬件永不溢出。串口局部验证不能覆盖后来增加的保存主机与多类型集成。

EXT-05/06 的设计与依赖顺序见[系统终端集成方案](24-terminal-system-integration-plan.md)：先实现解锁后一次性启动本地 TAB，再补 Local cwd/CLI、冷暖启动请求队列与显式 argv 执行。当前均未实现；不将自动开新 TAB 等同于退出前标签恢复，也不扩大锁定前会话权限。

## 5. M5 与执行顺序

发布前完成三平台安装、签名/公证、受签名验证的更新、恢复演练、依赖 notices 与诊断流程；最低系统版本按实测确定。默认不新增遥测，自动双向云同步/团队和移动端不作为首期依赖；手动云备份与下载合并属于当前源码范围。

macOS 显示名称与可执行文件名已在源码中统一为 Termeta，固定 Cmd+, 由 AppKit 应用内事件监视器在 WebKit 前交给原生“设置”菜单并消费，前端不绑定；需重新编译桌面壳后验收输入框/主机搜索/终端可用且无逗号输入、中英输入法、一次按键仅执行一次、菜单快捷键显示/打开与单实例聚焦、开发运行及安装包的 Dock、应用菜单与关于窗口显示一致性，详见[桌面交互](09-desktop-ux.md#1-信息结构)。

PROD-02/03 按[平台调研](23-terminal-system-integration-research.md)分别交付：macOS Services 与文件/URL 关联、Linux desktop/发行版/桌面默认启动器、Windows 自有目录菜单。Windows 系统默认终端需独立验证包身份、双扩展/COM、inbound 生命周期、保险库锁定、提权及失败/卸载回退；未通过原型前不作为已支持能力，也不阻塞先行的启动偏好与目录入口。

近期优先级为用户可见交互与原生拖放、认证/信任/加密库迁移、重连/关闭/流控，再覆盖安全/压力和三平台矩阵。未关闭的依赖公告见 [风险记录](01-product-requirements.md#10-依赖与公告核查)。

遵循 [协作规则](../AGENTS.md)：未经用户明确要求，不构建、启动、运行项目测试或连接主机/设备。文档只记录实际执行的验证，旧检查结果不作为当前版本重新验证的证据。
