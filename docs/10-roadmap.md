# 开发路线与剩余门槛

更新：2026-10-21。功能完成标记只维护在 [产品需求](01-product-requirements.md)；本文维护交付依赖和剩余门槛。当前没有完整验收通过的里程碑，源码实现与三平台交付分开判断。

## 1. 阶段与依赖

| 阶段 | 当前基础 | 剩余门槛 |
| --- | --- | --- |
| M0 选型与架构 | 技术栈、领域分层、依赖锁定 | 固定 release API、原生工具链、许可和公告复核 |
| M1 SSH 纵向切片 | actor、信任/认证、PTY、Channel/ACK、取消 | 真实认证/信任、流控、尾输出和资源回收验收 |
| M2 SSH 工作台 | 加密保险库、主机管理、稳定终端/分屏广播、设置、第三方备份 | 睡眠恢复、第三方自动备份/双向同步、本地备份入口；集成、安全和性能验收 |
| M3 文件与连接工具 | SFTP 侧栏/双远端/对拷、面包屑/多选/文件操作与底部传输反馈、macOS 拖出、Windows 文件/目录拖出源码、转发、工作区存档、Snippets、关闭归档与日志回看 | 本地文件端点、通用租约/完整传输管理、Linux 拖出、Windows OLE 运行验收、ProxyJump/Agent；运行验收 |
| M4 Local/Serial/Telnet | 系统 Shell、串口文本终端、Telnet | Local 自定义启动/完整进程树清理、串口控制线/HEX、启动偏好/CLI；平台设备矩阵 |
| M5 发布与产品化 | Windows 多语言/安装范围配置 | 安装/卸载/UAC、签名/公证/updater、恢复演练及发布许可 |

M1 依赖 core、SSH 和桌面流桥；M2 依赖稳定终端及存储/安全适配器。M3 使用独立文件/转发会话，本地文件端点不依赖本地 PTY；M4 复用会话生命周期和数据通路。

## 2. 近期顺序

1. 验收连接、认证/信任、背压、取消/关闭与重连，确认失败保留视图、旧流隔离和资源回收。
2. 验收保险库升级/改密/恢复、第三方备份与跨设备恢复，覆盖OpenSSH/PEM/PPK 私钥正文粘贴、格式/大小分别报错、可选口令与提交/取消清空、公钥查看复制、加密 PEM/PPK 临时口令清理及跨窗口拒绝，以及直接备份、版本选择后无二次确认的新增合并、分行包与旧单行包兼容、并发与中断故障。
3. 验收工作台布局/广播/存档、日志关闭握手、原生窗口/焦点/IME/剪贴板、五语言/外观及 SFTP/转发，设置覆盖侧栏导航、常规页整合、切页状态/独立滚动和快捷键多语言列对齐；工具侧栏覆盖所有动态标签、顶部/左侧标签布局下的 Header 方形开关及展开/收起图标、全局控件圆角在默认/自定义主色与局部明暗主题下的一致性、工具侧栏明暗热切换/下拉菜单、输入与卡片默认边框及悬停/聚焦态、固定页签下的长列表滚动/紧凑表单、字体字号/全局配色热应用与当前主机继承重置、片段粘贴/执行的广播、队列限额和确认期间切页/重连取消；SFTP 验收左右停靠偏好与两侧鼠标/键盘调宽；SFTP 覆盖双栏主机搜索/点击连接及失败重选、窄栏路径折叠与编辑焦点、终端工作目录跟随与重连隔离、拖至终端插入多路径及原生拖出交接、状态栏/侧栏及弹层配色热切换、普通文字与未激活标签同色及 UI 色缺省回退/禁用态、多选/框选与名称拖动互斥、递归删除/权限编辑、底部任务弹层和断线取消；同时覆盖主机卡片两行标题、多选与页面方向键/搜索焦点、批量打开/排序/迁组、选字与拖拽互斥及 schema 9 升级/事务冲突；Windows 覆盖冷启动与设置窗口首次显示的白闪检查。
4. 完成安全/压力和三平台矩阵后确定最低系统版本、支持声明与发布流程。

[结构重构](27-architecture-refactoring.md) 的 A/B/C 已落地源码：主机快照与订阅、输入泵与凭据原子边界、统一关闭和会话资源撤销。受控回归源码已补，尚未编译或运行验收；先完成上述连接、保险库和工作台门槛，再按 E/F 推进本地文件端点及类型治理。

详细场景只维护在 [运行验收边界](01-product-requirements.md#11-运行验收边界)。领域文档保留独特行为和安全约束，历史单平台证据不能替代当前版本回归。结构优化优先按资源生命周期和事务职责拆分长文件，保持现有接口；不为未实现能力提前建立空模块。

## 3. 后续能力的准入边界

- 启动偏好、通用 CLI/cwd/argv 和系统终端关联尚未实现。扩展须保持解锁门禁、显式请求优先和结构化参数，Windows 默认终端委派另需 POC。
- 自动恢复打开标签不同于显式工作区存档；不得恢复秘密、终端正文或重放未确认输入。
- 文件任务扩展先定义连接租约、后台/取消策略及部分失败语义；覆盖和目录合并不承诺回滚。
- 第三方自动同步、团队、远程编辑与后台热键另行定义权限及冲突处理。

发布前关闭 [已知依赖风险](01-product-requirements.md#10-依赖与公告核查)，完成安装、签名、更新和配对恢复演练。编译/运行/连接验证遵循 [协作规则](../AGENTS.md)，未经授权不执行。
