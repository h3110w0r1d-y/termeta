全未开始。M4-Local 启用已预留的 `workspace.newLocalTerminal` 动作与 Cmd+L 默认值，补充三平台快捷键验证；M2 配置可见不代表 Local 已实现。M3 本地文件浏览不依赖此阶段。串口背压只能保护应用内存，无法总能阻止外设继续发送；必须定义驱动溢出/丢字节的检测和可见计数，不能承诺任意硬件永不丢包。

## 8. 风险与决策触发

| 风险 | 影响 | 应对与触发点 |
| --- | --- | --- |
| russh 文档/版本 API 不一致 | 无法复现示例 | 固定 release/tag；M1 验证；不混用 latest 子页 |
| WebKit/WebGL/IME 差异 | 终端显示/输入异常 | 非 WebGL 回退；三平台真实手工验收 |
| 无端到端背压 | WebView 内存增长 | SP-02/05 必须检查 ACK 与库内部窗口 |
| Linux 凭据服务缺失 | 保存失败 | 显式不保存模式，不明文回退 |
| close 被输出或阻塞 I/O 卡住 | 资源泄漏/退出挂死 | 独立取消、期限、后续线程退出验证 |
| 过度提前设计全部功能 | 首期长期不可用 | 只创建当前需要的 crate；每阶段纵向交付 |
| 未经授权的自动验证 | 违背开发规则 | 静态检查优先，准确报告待执行项 |
