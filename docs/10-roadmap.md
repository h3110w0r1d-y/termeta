# 开发路线与剩余门槛

更新：2026-10-20。功能完成标记统一见 [产品需求](01-product-requirements.md)，本文只维护交付顺序和剩余门槛，不记录逐轮实现日志。当前没有完整验收通过的里程碑。

## 1. 阶段与依赖

| 阶段 | 当前基础 | 剩余门槛 |
| --- | --- | --- |
| M0 选型与架构 | 技术栈、领域分层、依赖锁定 | 持续复核固定 release 的 API、原生工具链、许可和公告 |
| M1 SSH 纵向切片 | actor、信任/认证、PTY、Channel/ACK、取消 | 真实认证与信任、流控、尾输出和资源回收验收 |
| M2 SSH 工作台 | 加密保险库/改密、主机管理、稳定终端、分屏广播、设置/五语言/主题/快捷键、离线第三方备份与官方全量自动同步 | 专门睡眠恢复、第三方自动备份/双向同步、本地备份文件入口；三平台集成、安全和性能验收 |
| M3 文件与连接工具 | SFTP 侧栏/双远端/对拷、macOS 拖出、三模式转发、显式工作区存档、Snippets 管理/备份、关闭归档与日志 TAB | 本地文件端点、通用租约/完整传输管理、Windows/Linux 拖出、ProxyJump/Agent、Snippets/彩色日志（配色、宽字符、历史尺寸适配及关闭画面双向滚动）及退出保存的运行验收 |

## 2. 近期顺序

1. 完成认证/信任、取消/关闭、重连及背压验收，确认失败始终保留视图。
2. 验证加密库初始化、升级、改密与中断恢复，以及第三方备份、官方双模式登录/密码门禁/全量合并/改密的真实服务及跨设备恢复，覆盖已确认账号冷启动自动进入、并发通知和恢复期间账号/门禁变化。
3. 覆盖桌面焦点/IME/剪贴板、动态终端组与日志标签中键关闭及确认/取消、独立设置与五语言切换/系统语言匹配、长文案布局及原生菜单、仅设置原生深色外观与背景时的三平台窗口首次显示及系统浅色外观下的白闪表现、固定深色应用及浅色/深色终端下沉浸式标签栏三色派生的普通/悬停/选中/拖动态及控件对比度、工作区拖入/创建/恢复时统一配色、右键全组换色/默认回退及各窗格标题/按钮与广播启用态、分屏广播/存档、SFTP 原生拖放及三模式转发。
4. 补齐安全/压力和 Windows、macOS、Linux 矩阵，再决定最低系统版本与发布支持声明。

详细验收维度只维护在 [运行验收边界](01-product-requirements.md#11-运行验收边界)，领域文档保留独特行为与安全约束。历史局部 macOS 或串口证据不能代替当前版本回归。

## 3. 后续能力的准入边界

- 系统启动偏好、通用外部 CLI/cwd/argv 和终端平台关联目前未实现；已实现的termeta://仅限账号授权回跳。后续须保持解锁门禁、显式请求优先、参数不经 Shell 拼接；Windows 默认终端委派须先有独立 POC，不能由 ConPTY 推定支持。
- 打开标签自动恢复不同于显式工作区存档；不得自动恢复秘密、终端正文或重放未确认输入。
- 文件任务扩展须先明确连接租约、后台/取消策略及部分失败语义；上传覆盖和目录合并不承诺回滚。
- 官方全量密文同步按[独立契约](26-official-vault-sync.md)实施；第三方自动同步、团队、远程编辑与系统后台热键仍需单独定义权限及冲突处理。

发布前关闭 [已知依赖风险](01-product-requirements.md#10-依赖与公告核查)，完成实际安装/签名/更新及配对备份恢复演练。所有编译、运行和连接验证遵循 [协作规则](../AGENTS.md)，未经授权不执行。

## 4. 独立官方服务

官方服务端为独立项目，已有账号、密文备份与Tauri更新/分发基础代码及pip/requirements、Compose配置。剩余门槛：外部MySQL迁移/恢复、鉴权和配额并发、安全与部署验收；客户端官方同步多设备/故障恢复与updater插件接入；正式签名/制品发布。临时一次性SSH远程协助仅规划，需另行完成授权、认领/撤销、隧道与gateway设计和验证。见[官方服务](24-official-service.md)。

管理端为独立项目，已接入管理员邮箱密码/GitHub/Google登录与软件版本管理API；两个前端已提供Cloudflare静态Workers/Pages部署配置，当前同域Tunnel采用Worker Route与API无脚本排除。仍需部署及路由优先级/API故障隔离、固定管理端OAuth回跳/非管理员拒绝、浏览器响应式/权限/错误和真实服务联调验收。

官方账号已按[认证契约](25-account-authentication.md)重构为 termeta.io/GitHub/Google 浏览器登录与永久可撤销桌面会话；独立用户端已有注册登录与基础账号管理。官方双模式门禁、同主密钥加密、稳定 ID 合并与 CAS 源码见[官方同步](26-official-vault-sync.md)。上线前需应用客户端迁移6（schema 7）/服务端004（原003保持），部署同源用户端与API、配置真实OAuth，完成永久会话撤销、三平台协议注册/唤起、错密码/本地锁定、双设备增删改/信任冲突、409/丢响应、离线重启与跨云端/本地改密故障验收。忘记密码清空云端尚未实现。本轮仅静态检查，不代表编译或运行通过。
