# 开发路线与剩余门槛

更新：2026-10-19。功能完成标记统一见 [产品需求](01-product-requirements.md)，本文只维护交付顺序和剩余门槛，不记录逐轮实现日志。当前没有完整验收通过的里程碑。

## 1. 阶段与依赖

| 阶段 | 当前基础 | 剩余门槛 |
| --- | --- | --- |
| M0 选型与架构 | 技术栈、领域分层、依赖锁定 | 持续复核固定 release 的 API、原生工具链、许可和公告 |
| M1 SSH 纵向切片 | actor、信任/认证、PTY、Channel/ACK、取消 | 真实认证与信任、流控、尾输出和资源回收验收 |
| M2 SSH 工作台 | 加密保险库/改密、主机管理、稳定终端、分屏广播、设置/五语言/主题/快捷键、手动云备份 | 专门睡眠恢复、自动备份/双向同步、本地备份文件入口；三平台集成、安全和性能验收 |
| M3 文件与连接工具 | SFTP 侧栏/双远端/对拷、macOS 拖出、三模式转发、显式工作区存档、Snippets 管理/备份、关闭归档与日志 TAB | 本地文件端点、通用租约/完整传输管理、Windows/Linux 拖出、ProxyJump/Agent、Snippets/彩色日志（配色、宽字符、历史尺寸适配及关闭画面双向滚动）及退出保存的运行验收 |
| M4 Local/Serial/Telnet | 本地系统 Shell、串口文本终端、Telnet 协商及保存配置 | Local 自定义 Shell/cwd/env/进程树清理、串口控制线/HEX、启动偏好/CLI；平台与设备矩阵 |
| M5 发布与产品化 | Windows WiX/NSIS 安装程序已配置 16 种语言，NSIS 支持当前用户/所有用户选择，尚无完整发布流程 | Windows 多语言安装/卸载、范围切换、UAC 与用户数据/密钥隔离验收、签名/公证/更新、恢复演练、诊断、依赖与资源许可、系统终端集成 |

M1 依赖 core、SSH 和桌面流桥；M2 依赖稳定终端与存储/安全适配器。M3 使用 SSH 文件子系统和独立文件/转发会话，本地文件端点不依赖本地 PTY。M4 复用会话生命周期及数据通路。

## 2. 近期顺序

1. 完成认证/信任、取消/关闭、重连及背压验收，确认失败始终保留视图。
2. 验证加密库初始化、升级、改密与中断恢复，以及手动云备份的真实服务/跨设备恢复。
3. 覆盖桌面焦点/IME/剪贴板、动态终端组与日志标签中键关闭及确认/取消、独立设置与五语言切换/系统语言匹配、长文案布局及原生菜单、三平台窗口首次显示及系统浅色外观下的防白闪表现、固定深色应用及浅色/深色终端下沉浸式标签栏三色派生的普通/悬停/选中/拖动态及控件对比度、工作区拖入/创建/恢复时统一配色、右键全组换色/默认回退及各窗格标题/按钮与广播启用态、分屏广播/存档、SFTP 原生拖放及三模式转发。
4. 补齐安全/压力和 Windows、macOS、Linux 矩阵，再决定最低系统版本与发布支持声明。

详细验收维度只维护在 [运行验收边界](01-product-requirements.md#11-运行验收边界)，领域文档保留独特行为与安全约束。历史局部 macOS 或串口证据不能代替当前版本回归。

## 3. 后续能力的准入边界

- 系统启动偏好、外部 CLI/cwd/argv 和平台关联目前未实现。后续须保持解锁门禁、显式请求优先、参数不经 Shell 拼接；Windows 默认终端委派须先有独立 POC，不能由 ConPTY 推定支持。
- 打开标签自动恢复不同于显式工作区存档；不得自动恢复秘密、终端正文或重放未确认输入。
- 文件任务扩展须先明确连接租约、后台/取消策略及部分失败语义；上传覆盖和目录合并不承诺回滚。
- 自动同步、团队、远程编辑与系统后台热键单独定义权限及冲突处理，不作为已有手动备份能力的默认行为。

发布前关闭 [已知依赖风险](01-product-requirements.md#10-依赖与公告核查)，完成实际安装/签名/更新及配对备份恢复演练。所有编译、运行和连接验证遵循 [协作规则](../AGENTS.md)，未经授权不执行。
