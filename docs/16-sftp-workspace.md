# SFTP 浏览、上传下载与双栏对拷

更新：2026-10-21。本文维护连接、文件授权和传输边界；当前范围与完整验收状态见 [产品需求](01-product-requirements.md#8-当前实现与限制)。

## 1. 连接与生命周期

终端侧栏仅适用于单个已连接 SSH 终端，复用其已认证传输的独立 SFTP channel。开启侧栏时禁止作为分屏来源或目标；隐藏保留任务，断开或关闭终端取消任务，重连不重放。侧栏及其传输/文件操作弹层跟随所属终端的背景、前景与 UI 辅助色，切换或热编辑方案时同步更新；固定双远端页沿用应用外观。

固定 SFTP 页为双远端文件浏览器，左右从保存 SSH 主机各建独立连接，可连接同一主机。复用主机信任与认证，不借用终端、不申请 PTY/Shell。文件专用 manager 最多两条连接；切页保留，断开或窗口退出关闭。通用共享连接租约、本地浏览和其他侧栏停靠位置尚未实现。

未连接的栏顶部显示搜索框，下方直接展示已保存的 SSH 主机列表，包含系统图标、名称、连接地址及所属分组；搜索沿用主机搜索字段和拼音偏好。单击主机建立该栏连接，连接中阻止重复选择；连接成功后显示当前主机与断开按钮，断开或失败后返回主机列表，可直接重新选择。两栏搜索互相独立，不修改保险库分组范围。

终端、文件与转发共用前端轻量控制投影和认证队列，连接资源仍由各自 Rust manager 持有。core 在驱动结束或关闭请求时通知壳撤销 SFTP 浏览器，取消传输、选择器/覆盖确认的应用等待及原生拖出，定时扫描只兜底。浏览器创建与传输登记继承会话取消，迟到登记和原生回调不得恢复操作；系统选择器自身可能仍可见，迟到选择结果不再消费。

## 2. 目录与路径

每页最多 100 条，单视图最多 10000 条，SFTP 报文上限 256 KiB。侧栏与双栏复用浏览表格和导航工具栏，支持逻辑上级、主目录、刷新、目录优先排序及全局隐藏文件偏好；`..` 不计入分页和选择。隐藏文件勾选立即同步当前窗口各浏览区的过滤状态，不等待保存或焦点变化；保存失败恢复已确认值并提示错误。

路径按目录段呈现可点击面包屑，点击尾部空白进入路径编辑，Enter 或图标按钮前往，Esc 或离开编辑区恢复浏览。空间不足时保留末级目录并将前面的祖先折叠为省略入口，悬浮展开完整祖先路径并可跳转；末级仍过长时截断显示，完整路径可悬浮查看或进入编辑。

终端侧栏可勾选“跟随终端工作目录”，默认关闭、仅驻当前终端内存；开启后同步已知目录，后续目录变化自动导航。传输、目录读取、文件菜单/弹窗或拖放期间暂缓，只保留最新目标；侧栏隐藏时不主动读取，展开后跟随。取消勾选丢弃待跳转，失败显示原始诊断且不循环重试。手动浏览仍可用，下一次终端目录变化继续跟随；不会向终端反向发送 `cd`。

2026-10-21 决策：目录由当前交互 SSH 的 OSC 7 `file://` URI、OSC 1337 `CurrentDir` 提供，兼容完整 `user@host:/path` 或 `user@host:~/path` 标题；明确目录上报优先于标题。解析完整原标题，不使用界面截断文本；拒绝控制字符、非法编码、非文件 URI 和截断目录，`~` 按 SFTP 初始主目录展开。未提供目录的 Shell 显示等待提示，不推断用户命令，不注入 Shell 配置、执行 `pwd` 或轮询远端进程。目录只用于所属已认证会话的只读浏览，不打开本机 URI，不执行目录文本。重连清除旧目录并等待新连接上报；固定双远端页没有关联终端，不提供此开关。不同文件命名空间（如嵌套 SSH、容器或 SFTP chroot）可能无法用相同路径访问，仍由 SFTP 服务端决定可读范围。

列表支持复选框、Shift 范围选择、Ctrl/Cmd 切换多选及键盘选择。拖动名称列发起文件拖动，其他单元格或列表空白拖动为半透明框选；框选按当前排序与过滤后的列表命中，支持边缘滚动。名称拖动保留已有选区，取消、失焦或连接变化清理手势，拖动后的点击不触发选择或目录跳转。

终端侧栏的名称拖动在窗口内由前端处理，悬浮所属终端时通过拖动浮层提示路径插入；松手插入所选文件/目录的绝对路径，按选择的列表顺序以一个空格连接，不追加空格或回车。特殊字符使用 POSIX Shell 单引号规则，内嵌单引号独立转义，防止变量、命令替换、通配符与交互历史展开；拒绝控制字符和超过终端粘贴上限的整批路径，不部分插入。路径插入复用终端括号粘贴及会话/焦点检查，仅发送到所属终端，不加入广播、不改剪贴板、不读取文件正文或创建传输任务。远端非 POSIX Shell 的引用语法不自动探测。

2026-10-21：拖动决策从侧栏拆为独立控制器，DOM 指针捕获/取消由适配层负责，路径参数格式化独立于手势；窗口内落点与原生拖出互斥。只有越过窗口内容边界且仍按住鼠标时才交给原生下载流程；普通点击、其他区域松手、Esc、失焦、切页、隐藏和会话/目录变化取消，不产生终端输入。固定双远端页仍使用独立的栏间复制手势。

READLINK 获取链接目标，STAT 尽力判断目标类型，失败不阻断列表。可进入目录链接；浏览保留逻辑绝对路径，折叠重复斜杠、`.`、`..`，不越过根。相对输入通过 REALPATH 获取起始目录。

当前只接受安全的 UTF-8 单个名称，不支持任意字节名、控制字符或反斜线名；不得以有损显示名称执行传输。远端访问范围以 SSH 账户权限为界。

## 3. 上传与覆盖

按钮通过原生选择器授权普通文件；终端侧栏原生拖入支持文件和目录，目标为当前浏览目录。Rust 签发绑定 owner 的一次性 dropId，前端不提交任意本地路径。授权保留 5 分钟、最多 16 批，每批最多 1000 个根路径；仅接受真实外部进入后的 Drop，应用内拖放或拖出回流不产生上传授权。

目录预扫描最多 64 层、10000 项，不跟随本地链接、不接受特殊文件。Windows 同样拒绝 junction、符号链接及其他 reparse point，打开上传文件时使用不跟随末级重解析点的标志并复核已打开对象。已有目录合并，文件/目录冲突拒绝，上传树内链接不自动递归合并。已进入的远端目录链接可作为目标目录。

同名普通文件逐项确认覆盖。新文件独占创建；已有文件打开后 FSTAT 核对类型，再截断写入。无远端临时文件或回滚；失败、取消或断网可能留下部分内容。SFTPv3 不提供通用 NOFOLLOW/条件写入，不能消除并发路径替换竞态或承诺原子覆盖。

## 4. 下载与原生拖出

下载按钮仅支持单个普通文件，通过原生保存对话框授权目标。先写同目录独占临时文件（Unix 权限 0600），完成后以 hard_link 无覆盖发布；只清理本任务的精确临时路径，清理失败报告路径。

macOS 支持最多 100 个普通文件/真实目录拖到 Finder，通过 NSFilePromiseProvider 按需下载。Finder 请求兑现后才创建任务；无效落点、Esc 或应用内松开取消手势，不留下下载记录。成功要求 Copy 会话结束且全部承诺兑现；收尾拒绝迟到请求，内部落点不能转为上传。

目录递归独立于列表游标，最多 64 层、10000 项；不跟随链接或特殊文件，只创建 Finder 授权的新目录，不覆盖已有目标。失败保留已完成部分。链接拖出、Linux 原生拖出及按钮目录下载尚未实现。

Windows 终端侧栏支持最多 100 个普通文件/真实目录混合拖到资源管理器，包括嵌套目录、空目录和空文件。使用 Shell `FILEGROUPDESCRIPTORW` / `FILECONTENTS`：目录显式标记为目录属性，父目录在子项之前；内容索引与描述符索引一致。接收端请求时才生成有界清单，最多 64 层、合计 10000 项，独立于浏览器分页，不预下载到临时文件。

每次内容请求及克隆使用独立游标，支持定位、只读流复制和大小查询；远端打开后复核普通文件类型与句柄大小。64 KiB 分块，进度节流，只记录已交付的字节区间；最多 128 个存活流/等待回调，区间跟踪有总量限制。Windows 设备名、尾随空格/句点、非法字符、大小写冲突及超过描述符容量的相对路径明确拒绝，不静默改名；链接、特殊文件和无法获取大小的文件不拖出。

OLE 松键不代表传输完成：异步目标的 `EndOperation`、Copy 结果与文件交付状态共同决定完成；空目录由目录描述符和目标成功结果确认。接收端接受前的描述符查询不显示下载任务；无效落点、Esc 和应用内落点取消，不产生上传授权。取消/断线后阻断迟到打开与读取，排空在途 I/O 并关闭远端句柄，再在创建它们的 STA 线程释放原生保活引用。同步 COM 回调将远端请求交给后台，等待期间继续分派窗口/COM 消息，同一流的重入操作拒绝阻塞。

Windows 外部接收端负责创建目标、冲突交互和部分文件清理；源端只提供 Copy，不删除远端源，不承诺外部目标的无覆盖发布或失败回滚。目录预扫描不构成远端快照，不能普遍消除 SFTPv3 并发路径替换；本地上传同样不承诺完整目录树的并发替换防护。Windows 实际拖入/拖出和其他接收端兼容性仍待运行验收。

## 5. 双远端对拷

可把选中的普通文件/真实目录复制到对侧当前目录，支持栏间拖放；双栏不提供系统文件拖入/拖出。手势取消不创建任务。

`sftp_copy` 重查两端文件会话 owner 和连接，获取两端操作锁及全局传输许可；Rust 流式中转，不落盘、不经 WebView。每批最多 100 根，扫描上限同目录上传；目录合并、链接拒绝和逐文件覆盖确认沿用上传语义。取消/失败不回滚，可能留下部分文件。

Rust 的内部 EndpointIdentity 使用规范 host、port 和 username，不使用省略端口的显示标题，也不因共享主机密钥断言同一文件命名空间。同端点使用 REALPATH 拒绝复制到自身或其子树；不同主机别名、硬链接和并发路径替换无法普遍证明对象身份，不承诺严格快照。端点身份不改变显示标题或公开会话 DTO。传输期间禁止两栏导航或切换连接，重连不恢复任务。

## 6. 文件操作与权限编辑

2026-10-21：为保持侧栏与双栏的一致操作边界，文件菜单、权限弹窗和 Rust 元数据操作统一复用。右击已选条目保留整组选择，右击未选条目先选中该项；连续右击重新定位并更新菜单目标，右键松开不作为外部关闭，macOS Control+单击遵循相同规则。菜单支持批量删除和权限编辑，每批最多 100 个根条目；`..` 不可操作。

删除文件不进入回收站；涉及真实目录时额外确认并勾选同意包含子目录和非空目录的永久删除。Rust 先预扫描完整范围，最多 64 层、10000 项，再按子项优先删除；预扫描失败不开始删除。链接只删除链接本身，不递归其目标。执行中断或部分失败不会回滚，界面重新读取目录；SFTPv3 的路径操作不能普遍消除并发替换竞态。

权限弹窗按所有者、用户组、其他用户分别勾选读取、写入、执行，并同步八进制权限，特殊权限在扩展区显示。批量选择权限不同时要求明确输入或勾选后再应用。仅修改所选普通文件或真实目录本身，不递归，也不修改链接目标；保留所有者、大小与时间。所有权限操作由服务端实际授权决定。LSTAT 复核不是快照，SFTPv3 SETSTAT 没有 NOFOLLOW，不能保证消除检查与写入之间的并发替换。

文件操作与传输共用浏览器操作锁和全局许可，均校验 main 窗口与会话 owner，继承会话取消；前端操作期间禁用导航和冲突操作。没有撤销、递归 chmod 或事务回滚承诺。

## 7. 传输反馈、资源与源码

文件正文仅在 Rust 流动，不进入 WebView、状态仓库、数据库或日志。64 KiB 数据块，全局最多 4 个传输，每浏览器一个操作；进度经 Channel 节流，u64 字节数以十进制字符串传递。没有持久化队列、断点续传、完整批量冲突策略或哈希校验。

传输入口与日志位于浏览区底部，点击弹出轻量任务列表，展示进度条、状态、文件/字节进度并允许取消或清理已结束记录。多文件批次的整体进度按已完成文件数占比展示，字节数描述当前文件；单文件可按字节展示进度。递归下载尚未确定文件总数时保持未知进度，不能以当前文件完成代表整个目录完成。侧栏保留有界队列，双栏保留有界对拷历史；准备阶段或总量未知时不伪造完成百分比，原生拖动未兑现时不产生任务记录。

命令为 `sftp_connect`、`sftp_list`、`sftp_copy`、`sftp_transfer`、`sftp_drop_upload`、`sftp_start_drag`、`sftp_cancel`、`sftp_delete`、`sftp_set_permissions`；均需命令 ACL、main 窗口及会话 owner 校验，本地路径只能来自原生授权。
