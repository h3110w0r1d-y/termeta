# SFTP 浏览与上传下载

更新：2026-10-15。单 SSH 终端侧栏已有源码，编译、真实 SSH 与原生拖放验收尚未完成。SFTP 范围仅为浏览和上传下载。

## 1. 入口与生命周期

- 已连接的单 SSH 终端通过底部状态栏开关显示可调宽度的右侧栏；Workspace 中禁用。
- 开启侧栏的终端可以排序，但 `WorkspaceStore.canSplit` 禁止其作为分屏来源或目标；隐藏后恢复合并。
- 文件视图首次打开时挂载，隐藏保留目录、选择和任务。终端宿主以 margin 留白，侧栏不继承终端外层 padding；显隐由既有 ResizeObserver 驱动 fit/resize，不重建 xterm。
- 复用当前已认证 SSH 的独立 SFTP channel，不另启 Shell。隐藏继续传输，断开或关闭终端取消相关任务；重连使用新 sessionId，旧请求和任务不自动重放。
- 固定 SFTP Tab 仍为未连接双栏占位。可选左侧/底部面板、独立端点与连接租约、本地浏览及远端互传尚未实现。

## 2. 目录浏览

列表列序为选择框、名称、大小、权限；名称前图标区分文件、目录和链接，链接显示原始目标。不显示类型和修改时间列。大小使用 BigInt，按 1024 进制换算 B/KB/MB/GB/TB，保留两位小数。

每页最多 100 个实际条目，跨 READDIR 包补齐并暂存余项；报文上限 256 KiB，单视图最多 10000 项，前端使用虚拟列表。目录及目录链接始终排在其他条目前，升降序只作用于组内。置顶 `..` 不计入分页、不参与选择，双击进入逻辑上级；根目录禁用。支持路径输入、主目录、上级、刷新和隐藏文件开关。

软链接通过 READLINK 获取原始目标、STAT 判断目标类型，每批最多并发 8 个；断链、权限不足或不支持时允许信息缺失，不阻断列表。目录链接可以直接进入，路径保持 `/bin` 等逻辑绝对路径，服务器负责跟随链接；仅相对输入以 REALPATH(".") 获取初始目录。逻辑折叠重复斜杠、`.`、`..`，不越过根目录。

当前仅支持安全的 UTF-8 单个名称；不支持任意字节名、控制字符或反斜线名，不以有损显示名称执行传输。

## 3. 上传

上传按钮通过原生选择器多选普通文件；操作系统拖入支持文件和目录。侧栏内任意落点均上传至**当前浏览目录**，先确认目标路径，再加入批次队列。拖出期间的原生 hover/drop 回流由 Rust 生命周期令牌和前端状态共同屏蔽，不能形成上传授权。

原生 drop 在 Rust 签发 owner-bound 一次性 dropId，前端仅接收引用及逻辑坐标，不提交任意本地路径。授权有效期 5 分钟，最多 16 批，每批最多 1000 个根路径；超限拒绝，未消费授权可按最旧项淘汰。macOS/GTK 原生坐标直接采用，Windows 按窗口 scale factor 转为逻辑坐标。

目录上传预扫描最多 64 层、10000 项，不跟随本地链接、不接受特殊文件。已有远端目录始终保留并合并；文件/目录类型冲突拒绝，不能通过移除目录解决冲突。已打开的目录链接可作为上传位置，上传树内部的同名链接不自动递归合并。

同名普通文件逐项原生确认，只有明确同意才覆盖。新文件独占创建；已有文件先打开并 FSTAT 核对普通文件，再 FSETSTAT 截断并分块写入。不使用远端临时文件或 hardlink。失败、取消或断网可能留下部分目标，旧内容不保证恢复；错误报告具体路径与完成计数。SFTPv3 缺少通用 NOFOLLOW/条件写入，存在并发替换路径竞态，不承诺原子覆盖。

## 4. 下载与原生拖出

下载按钮仅支持单个普通文件，通过原生保存对话框授权目标。文件写入目标同目录的独占临时项，权限为 0600，完成后以本地 hard_link 无覆盖发布；仅清理本任务的精确临时路径，清理失败报告路径，不覆盖已有目标。

macOS 可将最多 100 个普通文件/真实目录（可混选）拖到 Finder，采用 NSFilePromiseProvider 的 `public.data` / `public.folder`，无需先缓存完整内容。前端指针移动达到阈值后发起原生手势，Rust 检查真实左键状态；已松开则按取消处理。

Finder 请求兑现目标后才显示下载任务、进度及传输中状态。未被接收、Esc 取消、无效落点或在应用内松开均不留下载记录；原生 source 拒绝应用内部落点。Copy 结束且所有承诺兑现成功后才报告成功。

目录使用独立 OPENDIR 游标递归下载，不影响侧栏分页，最多 64 层/10000 项。不跟随源链接或特殊文件，只在 Finder 授权的新目标创建目录，不覆盖已有本地目录；失败保留已下载部分并报告路径及计数。链接拖出、Windows/Linux 原生拖出及按钮目录下载尚未实现。

## 5. 任务与实现边界

- 文件正文仅在 Rust 流动，不进入 WebView、Pinia、数据库或日志；进度通过 Channel 节流约 150ms，u64 字节数使用十进制字符串。
- 64 KiB 数据块，全局最多 4 个传输，每浏览器同时一个操作。前端最多 32 个等待批次、保留 20 个结束记录；取消停止后续文件并释放句柄。
- `terminal-files` 定义目录元数据、只读列表端口、FileReader/FileWriter 与受界 copy_file；`terminal-sftp` 使用锁定的 russh-sftp RawSftpSession；`terminal-ssh::SshChannels` 提供 owner-bound 子系统。
- 无独立后台连接租约、持久化队列、断点续传、完整批量冲突策略或哈希校验。任务不跨重连恢复。

当前 IPC：

| 命令               | 用途                                             |
| ------------------ | ------------------------------------------------ |
| `sftp_list`        | 按 sessionId/path/more 分页列目录                |
| `sftp_transfer`    | 原生选择器授权上传源或下载目标，传输进度 Channel |
| `sftp_drop_upload` | 消费一次性 dropId，上传到当前目录                |
| `sftp_start_drag`  | macOS 原生文件/目录承诺拖出                      |
| `sftp_cancel`      | 按 sessionId/transferId 取消                     |

命令均注册 AppManifest、handler 与 main capability，逐次检查窗口和会话所有权；远端路径权限以 SSH 账户可访问命名空间为界。普通 IPC 不接受任意本地路径。

## 6. 验证与资料

静态检查只能说明类型、格式和契约一致；当前版本未完成 Rust 编译、真实 SSH 或 Finder 运行验收。SP-10/11 覆盖目录分页与链接、上传合并/覆盖/取消、资源上限、断线隔离、三平台拖入、macOS 文件及目录拖出、无效落点与目标冲突；详见 [验证计划](11-validation.md)。

参考：[russh-sftp 3.0.1](https://docs.rs/russh-sftp/3.0.1/russh_sftp/)、[Tauri Webview](https://v2.tauri.app/reference/javascript/api/namespacewebview/)、[NSFilePromiseProvider](https://developer.apple.com/documentation/appkit/nsfilepromiseprovider)。原生拖放必须独立验收，Web DnD 可用不代表系统文件管理器已通过。
