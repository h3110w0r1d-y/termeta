# 桌面交互、设置与外观

更新：2026-10-20。本文维护用户可见行为与前端边界；功能状态及运行验收见 [产品需求](01-product-requirements.md)。组件流程、样式数值和默认值以源码为准。

## 1. 页面与窗口

主窗口包含不可关闭的保险箱、双远端 SFTP 固定页，以及动态终端组和只读日志标签。保险箱管理主机、端口转发、凭据、Snippets、主机信任与会话日志；设置为独立单实例窗口，重复打开聚焦已有窗口。

标签可在顶部或左侧排列。动态终端组与日志标签支持中键关闭，沿用确认、任务处理和归档流程；中键不激活标签。固定页不创建终端；顶部固定页和新建按钮支持越过阈值后拖动窗口。切页、排序、分屏和迁移保留终端实例。返回保险箱进入主机页并聚焦搜索，保留分组选择。

macOS 使用 overlay traffic lights；Windows/Linux 使用应用窗口控件和独立应用菜单。主窗口与设置窗口指定原生深色外观及背景，启动白闪和各平台窗口交互仍待实测。

首次使用选择官方账号或本地/离线模式。已有库先尝试 OS 主密钥解锁，失败后要求本机密码；官方云密码门禁独立于本地解锁。首次进入前不挂载业务页面，已挂载工作台被门禁遮住时保留终端宿主并禁用业务交互。缓存失败不撤销本次解锁；密码与主密钥均丢失且无备份时无法恢复。详见 [安全](08-security.md) 与 [官方同步](26-official-vault-sync.md)。

## 2. 主机与分组

保存项包括 SSH、Telnet、串口和工作区，名称 trim 后区分大小写、全库唯一。主机表单保存配置，快速连接创建临时会话，本地终端启动系统 Shell；工作区从运行标签保存。

主机页支持卡片/列表、收藏、标签和分组树。默认显示直属项，可包含子组；搜索全库且不改变分组选择，支持字段配置和拼音匹配，不进行网络探测。新建标签页复用搜索，取消不创建终端。

分组计数和批量打开包含后代，不受搜索/直属显示偏好影响；配置 ID 去重，保存工作区独立恢复。多项连接可选择独立标签或均分布局，广播默认关闭。

迁组前后端防环。删除分组默认将直属主机/子组上移；递归删除须独立二次确认。删除保存项不影响已有会话，工作区和转发的失效引用保留供处理。工作区支持移动、收藏和删除，不通过主机表单编辑或复制。

SSH 默认公钥认证，按方式筛选就绪凭据并提供新建入口；公钥须选择私钥凭据，密码可留空后在连接时询问。保存秘密不回填。Telnet 明确提示明文登录，串口保存不打开设备。协议约束见 [SSH](05-ssh-design.md)、[Telnet](20-telnet-terminal.md)、[Serial](19-serial-terminal.md)。

## 3. 终端、认证与输入

失败、取消、断线及远端退出保留终端与复制/搜索能力，重连在原历史末尾追加且不重放输入；关闭视图才归档并销毁实例。信任/认证弹窗退出后恢复当前活动终端焦点。信任和 OTP 约束见 [SSH](05-ssh-design.md)。

关闭标签关闭整组，关闭窗格只影响自身；可能执行命令、SFTP 传输和活动转发按各自规则确认。窗口关闭及正常退出须等待日志保存，失败保留视图。关闭提示仅为启发式判断，详见 [标题与关闭](18-terminal-workspaces.md#4-标题与关闭) 和 [日志归档](23-snippets-and-session-logs.md)。

按钮、菜单与快捷键共用命令注册表；录制、IME、模态和弹层优先。标准粘贴由系统 paste 事件进入终端宿主，执行大小、多行和广播校验，不自动补 Enter。链接须用户以修饰键点击，仅允许 http/https。详见 [快捷键](14-shortcuts.md)。

## 4. 设置与跨窗口同步

常规设置的有效修改自动保存并热应用。Rust 串行读取最新值、局部合并并通知窗口重读，旧草稿不能覆盖即时偏好。无效输入/写入失败保留编辑供重试，关闭设置须等待写入完成。

账号页提供浏览器登录、同步状态/重试和退出；退出保留本地数据。第三方备份仅本地模式可用，Rust 同时校验模式。保险库改密和云配置单独显式提交，改密/云操作期间阻止设置关闭。settings 仅获得专用设置、改密、JSON 导出、备份及账号权限，不获得通用业务资源或首次云初始化权限。详见 [存储](07-storage.md)、[备份](22-data-backup.md) 和 [官方同步](26-official-vault-sync.md)。

## 5. 界面语言与文案

应用支持简体中文、繁體中文、English、日本語、한국어及跟随系统。系统匹配按首个受支持语言选择，中文区分字形/地区，未知语言回退英文。解锁前使用系统语言，解锁后读取加密设置；主窗口、设置、控件、日期和窗口标题同步切换，不重连或重建终端。

macOS 应用菜单和已识别的系统固定项随语言更新；其他系统项、服务提供方和窗口名称由系统管理。界面使用类型化语义 key 和五语言词典，语言目录直接位于 `src/i18n/<locale>/`，动态整句使用命名参数；用户内容、路径、后端诊断和终端历史保留原文。提示说明操作与后果。

Windows 安装发布者为 `termeta.io`；NSIS 配置 16 种安装语言，WiX 仅配置英文，均独立于应用语言。NSIS 可选当前用户/所有用户安装，当前双模式仍请求管理员权限；WiX 为所有用户安装。数据和主密钥始终按运行用户隔离。具体语言及打包参数见 [Tauri 配置](../src-tauri/tauri.conf.json)，安装/卸载、UAC 和范围切换待 Windows 验收。

## 6. 应用外观与终端配色

应用固定深色，自定义主色与终端配色独立；旧外观设置兼容归一为深色。终端可使用浅色方案。2026-10-19 决策：应用移除浅色/跟随系统外观，终端标签栏按终端背景、前景与 UI 辅助色派生状态色，局部适配明暗，保持浅色终端可读性。

运行标签栏跟随当前聚焦终端，子终端标题/按钮跟随组内统一配色；固定页回退应用深色。局部 Naive UI Provider 不包裹终端宿主或 SFTP。自定义方案可设置 `colors.ui`，缺省回退前景色；具体色值比例由源码维护。

内置 64 套只读方案，自定义最多 64 套，默认 Pro。优先级为 terminalId 临时覆盖 → 主机覆盖 → 全局默认；工作区统一配色、创建/恢复和回退规则见 [工作区](18-terminal-workspaces.md)。临时覆盖只驻内存，重连保留，不改主机或存档。编辑内置方案创建副本，删除自定义方案须确认并回退引用。

有效编辑自动保存；导入先预览再新增副本，支持 Termeta Scheme v1 与基础 xterm ITheme JSON，拒绝非法结构、重复键、CSS 表达式和资源 URL。导出只含配色。热应用保留历史，预览使用无连接样本终端；远端 truecolor 不随 ANSI 色表重着色，选区适配依赖固定 xterm 渲染结构，升级须复核。

字体限随包分发的 12 家族，默认 DejaVu Sans Mono；版本和许可见 [字体资源](../resources/fonts/README.md)。字体加载后在原实例适配尺寸，不承诺编程连字。配色源与导入限制见 [配色资源](../resources/terminal-palettes.json) 和 [主题模块](../src/modules/settings/themes.ts)。

## 7. 前端实现边界

使用 Vue Composition API、严格 TypeScript、Pinia 和 Naive UI 薄适配；通用控件优先公开库能力，业务布局自行管理。表单 model、v-model、rules/path 共享响应式字段，程序更新用公开 API 重验；可选字段保持可选。弹窗操作区和滚动正文分离，图标按钮保留可访问名称。

通用图标使用 Tabler，AssetIcon 只做语义映射；用户指定的 28 个 SSH 系统 SVG 使用静态白名单并保留原样，品牌资源保留品牌图稿。来源和许可见 [资源说明](../resources/README.md)。

前端仅保存轻量状态，IPC 统一经过 desktop 门面，秘密、文件正文、网络、设备和加密留在 Rust。装配入口为 [App.vue](../src/App.vue)、[设置](../src/modules/settings/SettingsWindow.vue) 和 [外观](../src/layout/useAppAppearance.ts)，具体分层见 [架构](03-architecture.md)。
