# 桌面交互、设置与外观

更新：2026-10-19。本文维护桌面行为和前端边界；功能状态与运行验收统一见 [产品需求](01-product-requirements.md)。组件细节、样式和操作时序以源码为准。

## 1. 页面与窗口

主窗口包含不可关闭的保险箱、双远端 SFTP 固定页，以及 SSH/Telnet/Local/Serial 动态终端标签和只读日志 TAB。保险箱提供主机、端口转发、凭据、Snippets、主机信任与会话日志。设置为独立单实例窗口，重复打开聚焦已有窗口。主窗口与设置窗口创建时统一指定原生深色外观和深色背景，沿用默认显示时机。入口 HTML 不添加防白闪内联样式，也不等待页面加载后再显示窗口；启动阶段是否仍有白色闪烁待运行确认。

标签支持顶部或左侧排列。动态终端组与只读日志标签支持鼠标中键点击关闭，走既有关闭确认、任务处理与日志归档流程；中键不激活标签，也不触发自动滚动，固定页不可关闭。固定页不创建终端；顶部 Header 的固定页和新建按钮在指针移动超过拖动阈值后可拖动窗口，短按仍执行原有点击动作。切页、排序、分屏和窗格迁移不销毁终端。返回保险箱默认进入主机页并聚焦搜索，保留分组选择。桌面显示名称为 Termeta，应用标识与数据位置独立于显示名称。

主窗口的窗口装饰按平台处理：macOS 使用 overlay traffic lights；Windows 和 Linux 使用无边框窗口，由应用标签栏承载最小化、最大化/还原和关闭控件。非 macOS 的应用菜单位于标题栏最左侧，与窗口控制按钮分离。无边框窗口下无法直接保留 Windows 系统非客户区按钮；应用控件触发同一套窗口关闭协调，可能执行命令、活动转发或会话日志保存时按既有规则确认或等待。

首次使用可创建空保险库，或从云端版本初始化。已有库先尝试 OS 主密钥解锁，失败后使用密码；锁定时不挂载业务页面、不执行业务快捷键。主密钥缓存失败不撤销本次解锁，但显示警告。密码和主密钥均丢失且没有可用备份时不能恢复，不提供静默重置。详见 [安全](08-security.md) 与 [备份](22-data-backup.md)。

## 2. 主机与分组

保存项包括 SSH、Telnet、串口和工作区；名称 trim 后区分大小写、全库唯一。新建主机保存配置，快速连接创建临时会话，本地终端启动系统 Shell；工作区仅从运行标签保存。

主机页支持卡片/列表、收藏、标签、分组树和迁组。默认显示直属项，可包含子组；侧栏可显示直属保存项。搜索全库且不改变分组范围，支持字段配置和可关闭的拼音匹配，不进行网络探测。新建标签页弹窗复用搜索，取消不创建终端。

分组计数和批量打开包含后代，不受搜索或直属显示偏好影响。一项直接打开，多项确认选择独立标签或均分工作区；配置 ID 去重，保存工作区各自独立恢复。失败或断线保留各终端，广播默认关闭。

分组迁移前后端防环。删除分组默认保留直属主机与子组并上移；连同子树删除须独立二次确认。删除保存项不关闭现有会话，工作区及转发规则的失效引用保留供处理。保存工作区可移动、收藏和删除，不通过主机表单编辑或复制。

SSH 新建/快速连接默认公钥认证，保存秘密不回填；Telnet 明确提示明文传输，登录在终端完成；串口保存配置不打开设备。协议字段、校验与限制分别见 [SSH](05-ssh-design.md)、[Telnet](20-telnet-terminal.md) 和 [Serial](19-serial-terminal.md)。

SSH 认证字段按当前方式只展示匹配类型的就绪凭据，并提供“新建凭证”入口；公钥认证不提供空凭据选项。密码认证的空值不引用共享凭据，保存主机时可填写专属密码，留空则连接再询问且不写入凭据库。

## 3. 终端、认证与输入

每个视图以稳定 terminalId 持有 xterm，重连只替换 sessionId。失败、取消、断线和远端退出保留标签、输出与本地复制/搜索；重连在原末尾追加，不重放输入。只有用户关闭视图才释放实例，关闭时将现存终端缓冲与配色归档为本机加密会话日志，回看用独立只读终端还原颜色，不恢复会话。

首次 SSH 信任展示端点、算法与指纹，允许拒绝、仅本次或保存；密钥变化阻断连接，信任前不提交认证秘密。多会话认证排队，OTP 不保存。连接/认证弹窗退出后恢复当前活动终端焦点。认证策略见 [SSH](05-ssh-design.md)。

关闭标签关闭整组，关闭窗格只影响自身；可能执行命令的成员统一确认，SFTP 传输另行确认。交互 Shell 使用 OSC 133 与标题前缀作提示，SSH 命令模式在已连接时始终视为运行中，均受 confirmClose 开关控制；这不等于可靠的进程检测。窗口关闭还考虑活动转发，窗口关闭和 Cmd+Q 均等待日志保存，写入失败保留视图。详情见 [Snippets 与会话日志](23-snippets-and-session-logs.md)。详见 [标题与关闭](18-terminal-workspaces.md#4-标题与关闭)。

SSH 命令模式保留 PTY 和直接输入，程序结束后保留输出，手动“重新运行”创建新会话；该窗格不收发广播。分屏、存档及 SFTP 互斥见 [工作区](18-terminal-workspaces.md)。

按钮、菜单和快捷键复用命令注册表；录制、IME、模态和普通弹层优先。标准终端粘贴由系统 paste 事件进入宿主，执行大小、多行确认与广播检查，不自动补 Enter。链接仅在修饰键主键点击后打开，限 http/https，不随远端输出自动打开。平台绑定与原生菜单例外见 [快捷键](14-shortcuts.md)。

## 4. 设置与跨窗口同步

常规设置的有效修改自动保存并热应用；写入采用串行局部合并，避免旧草稿覆盖主窗口即时偏好。无效输入或写入失败保留编辑并允许重试。关闭设置窗口须等待写入完成，失败时保留窗口。

保险库改密与云端配置各自显式提交，不并入常规自动保存。改密须校验旧密码，云操作和重新加密期间阻止窗口关闭。settings capability 仅开放设置、专用改密/JSON 导出及备份同步命令，不开放通用主机、凭据、会话、文件或首次云端初始化操作。数据与密码契约见 [存储](07-storage.md)、[安全](08-security.md) 和 [备份](22-data-backup.md)。

## 5. 界面语言与文案

Windows 安装程序语言独立于应用界面语言，在 [Tauri 配置](../src-tauri/tauri.conf.json) 中同时配置 WiX（MSI）和 NSIS（EXE）。支持简体中文、繁体中文、英文、日文、韩文、法文、德文、西班牙文、葡萄牙文（巴西/葡萄牙）、意大利文、俄文、荷兰文、瑞典文、土耳其文和乌克兰文。WiX 按语言生成独立 MSI；NSIS 在同一安装程序中提供语言选择框，默认匹配系统语言，未匹配时回退英文。

NSIS 使用双安装模式，允许用户选择“仅当前用户”或“所有用户”；Tauri 当前双模式即使选择仅当前用户也会请求管理员权限。WiX 默认模板仍为所有用户安装，不提供范围选择。安装范围只影响程序文件、快捷方式及安装登记；运行数据和 OS 主密钥缓存仍按启动应用的 Windows 用户隔离，详见 [存储边界](07-storage.md#1-存储边界)。实际 Windows 安装/卸载、范围切换、UAC 及语言显示仍待运行验收。

支持简体中文（zh-CN）、繁體中文（zh-TW）、English（en-US）、日本語（ja-JP）、한국어（ko-KR）及跟随系统。跟随系统按语言顺序选择首个受支持语言；中文优先依据 Hans/Hant 字形，其次将 TW/HK/MO 地区映射为繁体，其余中文映射为简体，日语/韩语区域变体统一映射为 ja-JP/ko-KR，未知语言回退 English。解锁前按系统语言显示，解锁后应用加密设置，不另存明文偏好。主窗口、设置窗口、控件语言、日期格式与窗口标题同步切换。

macOS 应用菜单及已识别的系统注入固定项随应用语言更新；未知系统项、服务提供方、设备与窗口名称仍由系统管理。菜单失败显示可重试提示，不宣称全量系统菜单本地化。

界面文案使用 `src/i18n` 的类型化语义 key 和五语言模块词典，动态整句使用命名参数；校验、选项与状态展示随语言更新。用户内容、协议标识、路径、后端诊断与远端输出保留原文；已显示提示和终端历史不追溯翻译。用户提示说明操作和后果，不展示内部实现流程。语言变化不重连、不重建终端。

## 6. 应用外观与终端配色

应用统一使用深色外观，不再提供浅色或跟随系统选项；旧设置的外观字段兼容读取并归一为深色，无需数据库迁移。自定义主色限不透明六位 HEX，空值使用组件库默认。应用主色与终端配色独立，终端仍可使用浅色配色。

终端标签激活时，顶部或左侧 AppTabs 使用当前聚焦终端的背景色、前景色和 UI 辅助色：Header 底色为终端背景；普通标签文字使用辅助色，背景与悬停背景分别叠加辅助色的 10% 与 20%；选中标签文字使用前景色，背景与悬停均叠加前景色的 20%；拖动浮层叠加辅助色的 30%。工具按钮默认使用辅助色，悬停切到前景色并叠加辅助色的 20%；选中标签关闭按钮悬停叠加前景色的 10%。

工作区子终端采用全组统一配色，标题栏随该配色更新：未聚焦标题和普通按钮使用 UI 辅助色，聚焦标题、标题悬停、按钮悬停及广播启用态使用前景色；按钮悬停叠加辅助色的 20%，广播启用态叠加前景色的 10%，聚焦/广播状态线使用前景色。标题栏的局部 Provider 不包裹终端宿主或 SFTP。

局部 Naive UI Provider 根据背景亮度选择明暗主题，弹出菜单沿用对应主题的表面和文字。固定页回退到应用深色外观。此局部变化不影响设置窗口、其他业务页面或终端实例。内置方案保留来源数据中的 UI 辅助色，自定义方案支持编辑和导入导出可选的 `colors.ui`；旧方案或留空时回退终端前景色，不需要数据库迁移。

2026-10-19 决策：移除应用浅色与跟随系统外观，保留终端浅色配色，并让沉浸式标签栏以背景、前景与 UI 辅助色派生状态色，局部适配明暗，避免全局深色文字在浅色终端背景上失去可读性。

终端内置 64 套只读配色，默认 Pro，自定义最多 64 套。前后端共用 [配色资源](../resources/terminal-palettes.json)。优先级为当前 terminalId 临时覆盖 → 主机覆盖 → 全局默认；工作区按目标窗格配色统一成员临时覆盖，右键选色应用全组，创建/恢复及默认值行为见 [工作区约束](18-terminal-workspaces.md#2-布局与关闭行为)。临时覆盖仅在内存，重连保留，不改主机配色或工作区存档。编辑内置方案创建副本；删除自定义方案须确认，相关引用回退全局默认，删除全局默认时回退 Pro。

有效编辑自动保存，导入先预览并确认后新增副本，不覆盖现有方案。导入支持单个 Termeta Scheme v1 JSON 或基础 xterm ITheme 颜色对象，文件上限 1 MiB；校验颜色、16 项 ANSI 与 16–255 索引范围，拒绝重复键、非法结构、CSS 表达式及资源 URL。背景和 ANSI 基础色不透明。导出为 Termeta Scheme JSON，只含配色，不含主机、凭据或历史。

热应用在原终端更新，不清历史、不重连；预览使用独立样本终端，不执行远端命令。远端 truecolor 不随 ANSI 色表重着色；粗体不自动改用亮色。显式选区文字色优先；未设置时使用选区色混合原文字。选区适配依赖固定 xterm 的渲染结构，升级须复核。

字体限随包分发的 12 家族，默认 DejaVu Sans Mono，不依赖 CDN 或系统安装；名单、版本与许可见 [字体资源](../resources/fonts/README.md)。字号 10–32，滚屏 1000–50000、默认 5000。字体加载后在原实例重新适配尺寸，不承诺编程连字。

## 7. 前端实现边界

采用 Vue 3、TypeScript、Pinia 与 Naive UI 2.45.3；通用控件优先库实现，业务标签、分屏几何与稳定终端宿主自行管理。封装保持薄适配，样式就近维护，不复制组件库皮肤。

表单校验与控件共享同一响应式 model，rules/path 一致，提交前校验；程序更新通过公开 API 重验字段。快速连接名称、可选秘密和服务器允许的空回答保持可选。弹窗操作区与滚动正文分离；按钮保留可访问名称，终端及可复制内容保留选择能力。

通用界面图标使用 Tabler Icons Vue 组件；AssetIcon 负责稳定语义映射。SFTP 文件类型和主机分组文件夹也使用 Tabler 图标。用户指定的 28 个 SSH 系统/类型 SVG 主机标志保留原样，采用静态白名单，不接收运行时外部 SVG；应用品牌资源继续使用项目品牌图稿。来源与发布前许可门槛见 [资源说明](../resources/README.md)。

前端仅保存轻量状态，IPC 统一经过 desktop 门面，秘密、文件正文、网络、设备和加密操作留在 Rust。主要入口为 [App.vue](../src/App.vue)、[设置](../src/modules/settings/SettingsWindow.vue)、[外观](../src/layout/useAppAppearance.ts)、[语言](../src/i18n/index.ts)、[配色](../src/modules/settings/themes.ts) 与 [终端注册表](../src/modules/terminal/registry.ts)。三平台视觉、IME、焦点、原生菜单和跨窗口行为仍需运行验收。
