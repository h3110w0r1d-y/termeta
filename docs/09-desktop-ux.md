# 桌面工作台与终端交互

更新：2026-10-17。本文保留当前交互契约，功能状态统一见 [产品需求](01-product-requirements.md#8-当前实现与限制)。桌面体验与三平台矩阵尚未完整验收。

## 1. 信息结构

```text
主窗口
├── 固定保险箱 Tab：主机 / 端口转发 / 凭据 / 主机信任 / 连接历史
├── 固定 SFTP Tab：双远端独立连接与栏间对拷
└── 动态终端/Workspace：SSH、Telnet、Local、Serial
独立设置窗口：常规 / 终端配色 / 快捷键 / 搜索 / SSH 系统识别 / 安全 / 备份同步
```

固定页位于最前且不可关闭，不创建终端。标签可在顶部/左侧切换，切页或布局变化不卸载 xterm。顶部标签承载窗口标题栏，macOS Overlay 保留原生按钮，Windows/Linux 使用库按钮；左侧模式保留顶部窗口栏。窗口拖动仅作用于指定空白区，按钮/标签各自处理交互，多窗口标签拖出未实现。

桌面显示名称统一为 `Termeta`：Tauri `productName` 与 Cargo 显式二进制目标同名，macOS 应用菜单、About/Hide/Quit 标签及原生关于窗口沿用 Tauri 默认生成逻辑。Rust 包名仍为 `termeta`；应用标识、数据目录与保险库文件名不随显示名称调整。开发运行和安装包中的 Dock、菜单及关于窗口一致性仍待运行验收。

首次设置保险库密码，可选择创建空库或填写 Gist/WebDAV 配置从云端版本初始化；已有库锁定时仅提供解锁。后续先尝试 OS 主密钥自动解锁，失败输入密码恢复。未解锁不挂载业务页面或执行业务快捷键，保留窗口操作。缓存失败明确提示且本次仍解锁；没有可用的独立备份时，密码与主密钥均丢失将无法恢复本机库，不提供静默重置。

从其他标签返回保险箱默认进入主机页并聚焦搜索，保留所选分组。主机信任页支持刷新/指纹/确认后撤销，连接历史页支持刷新和确认清空，合计保留最近20次 SSH/Telnet/Local/Serial 连接尝试。设置不再承载信任或历史管理。

## 2. 主机管理

主机页搜索置顶，其下依次为“新建主机”“快速连接”“本地终端”；前两项共用 SSH/Telnet/串口类型下拉。新建保存配置，快速连接打开临时会话，本地按钮启动系统 Shell。工作区存档仅从运行 Workspace Tab 右键保存。

左右分别为分组树和主机卡片/列表，独立滚动，标题/操作区固定。树的 `(n)` 包含全部后代保存项，不随搜索变化；“全部主机”“未分组”为固定入口。右侧默认直属项，可选择包含子分组，收藏优先再按名称排序。侧栏显示主机默认关闭，开启后可展开直属保存项；空组不可展开，“全部主机”保持叶入口。显示模式、包含子组和展开状态即时持久化，旧数据补默认。

卡片、列表、侧栏共享连接/菜单/收藏/拖动；点击选择，双击或 Enter 打开。SSH/Telnet/串口显示对应连接摘要，workspace 显示存档类型；长名省略但保留类型标识。Shift+F10/菜单键打开菜单，F2 编辑适用项；工作区不提供编辑或复制配置。四类名称去首尾空格后区分大小写、全库唯一。

分组菜单支持子组、名称/父级编辑、删除，键盘可替代拖拽。Pointer Events 支持主机迁组/未分组、分组改父级/回顶层，前后端防环；达到阈值显示源快照与目标提示，悬停展开/边缘滚动，Esc/失焦/切页/无效落点取消并清理，不误触连接。无同级手动排序、批量拖动或跨窗口拖动。

删除分组默认保留直属主机/子组并上移；一并删除须独立二次确认范围和数量，Rust 事务删除子树并登记专属密码清理，共享凭据和现有会话快照保留。删除主机只影响保存配置；转发规则和工作区失效引用保留供处理。

### 搜索与新建标签页

顶部 NSelect 搜索全部保存项，不改变下方组筛选；拼音开关和 name/address/username/tags/group 字段配置共用即时设置，名称固定。默认拼音开启、全字段参与，支持全拼/首字母/多音字/混合/多词，关闭拼音保留不区分大小写的原文匹配。不触发网络探测，无有效关键词不显示下拉，最多100条；鼠标勾选字段保留输入光标。

标签＋、Cmd/Ctrl+T 及原新连接动作统一打开全局新建标签页弹窗，正文列出同一搜索结果，空查询收藏优先。上下键/Enter 选择，IME 组合期间不提交。主页与弹窗 footer 均保留协议快速连接入口；先等弹窗退场，再打开连接或快速连接表单，取消不创建 Tab。

### 协议表单与批量打开

SSH 默认端口22，新建/快速连接默认公钥认证、私钥引用必选；编辑/复制保留原方式。直接密码非空自动保存，显式空值移除、省略保留，界面不回填已存秘密；私钥及可选口令从凭据库引用。

Telnet 默认23，只需地址/端口和公共元数据，隐藏 SSH 用户名/凭据，表单及状态栏标识明文；在终端中登录，无自动登录、TLS、Local Echo 或非 UTF-8 选择。Serial 支持枚举/手输、波特率及高级参数，保存不打开设备，实际连接时由 Rust 校验设备。已有保存连接不可转换类型。详见 [Serial](19-serial-terminal.md) 和 [Telnet](20-telnet-terminal.md)。

分组正文双击/Enter 打开整棵子树，不受右侧包含子组/搜索偏好影响；全部/未分组各按自身范围。空组无操作，一项直接打开，多项确认选择独立 Tab 或均分 Workspace。按收藏/名称排序、配置 ID 去重，确认后不加入新增项、删除项跳过；退场后创建会话，取消/切页不连接。普通连接独立认证，存档独立打开；现有会话保留，失败保留各自终端，广播默认关闭。

## 3. 标签与终端

每个终端拥有稳定 terminalId/xterm，重连只替换后端 sessionId。标签切换、排序、分屏、比例调整/交换、窗格迁移保留实例、缓冲和选区。隐藏终端继续解析输出；Connected 前或断线后禁用远端输入，保留滚动/复制/搜索。

失败、取消、断线和远端退出保留 Tab 与缓冲，重连在原末尾追加，不重放输入；只有关闭 Tab/窗格释放视图。滚屏受用户上限约束，正文不跨重启保存。全屏结束保留有界可读快照，不承诺完整交互画面恢复；错误不得覆盖历史或阻止复制。

关闭确认依 confirmClose：已连接终端的 OSC 133 执行标记或当前标题冒号前缀不同于首次前缀时提醒，目录后缀变化不提醒；这是远端信息提示，不是可靠进程检测。SFTP 传输和活动转发另纳入关闭确认；组/窗口统一确认。断开只释放连接，关闭释放视图。详见 [标题与关闭](18-terminal-workspaces.md#6-标题与关闭提醒)。

普通标签支持复制连接、向右拆分、搜索、配色、断开/重连；串口禁止复制活动连接，SFTP 开启时禁止拆分。双击动作可设无动作/关闭/复制/拆分，Workspace 仅支持关闭；Workspace 标签菜单仅保存工作区，窗格菜单保留。标签键盘导航、顶部纵轮转横向与边缘渐隐详见 [工作区](18-terminal-workspaces.md)。

## 4. 首次信任与认证

首次信任展示 endpoint、算法和 SHA256 指纹，提供拒绝/仅本次/信任并保存；密钥变化阻断，须进入信任管理显式处理。信任前不提交认证秘密。

认证按服务端 challenge 生成字段，掩码密码/OTP，多会话提示排队并标识目标。Keyboard-interactive 自动协商，明确且唯一的非回显密码提示可使用保存密码一次，失败/OTP/未知/复合提示人工输入；空白零输入轮直接响应，非空通知保留。OTP 不保存，认证弹窗退场后恢复当前活动终端焦点。

## 5. 快捷键与输入

CommandRegistry 统一按钮/菜单/按键。应用快捷键在前台跨页面生效，终端动作仅终端内生效；录制、IME、模态与浮层优先。默认本地终端 Cmd+L（其他平台 Ctrl+Shift+L），新标签 Cmd/Ctrl+T，新连接 Cmd+N/Ctrl+Shift+N，完整绑定见 [快捷键](14-shortcuts.md)。当前没有 SFTP 面板专用快捷键。

标准粘贴放行系统 paste，由宿主处理大小/多行确认/括号粘贴/广播校验，不自动补 Enter；自定义绑定可显式读取剪贴板。复制和搜索离线可用，Windows/Linux Ctrl+C 默认送远端中断。链接须修饰键主键点击，仅允许 http/https，不因远端输出自动打开。

模态内主窗口 Cmd+W 被消费，不关闭标签/窗口；macOS 原生 Close Window 菜单不带 Cmd+W，显式菜单/窗口按钮仍走关闭流程。设置窗口 Cmd/Ctrl+W 等待写入后关闭，录制/模态优先。

## 6. 字体、主题与可访问性

应用支持深色/浅色/跟随系统，自定义不透明六位 HEX 主色可恢复库默认，并跨窗口热应用；Workspace 拖放预览跟随应用主色。终端配色独立，64内置方案默认 Pro，支持缩略图、自定义/预览/JSON。当前终端临时覆盖优先于主机、全局默认，热切换不清历史、不重连。详见 [终端配色](15-terminal-themes.md)。

字体固定12家族，默认 DejaVu Sans Mono，来自随包资源且保留许可证，NSelect 标签以对应字体显示；不依赖 CDN/系统安装。名称由 Rust 白名单校验，加载后在原实例适配尺寸，迟到加载不能覆盖新设置。完整名单见 [字体资源](../public/fonts/README.md)。滚屏默认5000、范围1000–50000，字号10–32；不承诺编程连字。

通用图标采用 Ionicons/NIcon，SSH 系统/类型资源为指定例外。按钮保留无障碍名称，装饰图标不参与名称；表单使用库规则/错误提示。装饰文字默认不可选，输入、可复制正文与终端选择保留。三平台高 DPI、IME、对比度、字宽与辅助功能仍待验收。

## 7. 工作区保存

仅显式保存布局/比例/焦点与已保存 SSH/Telnet/串口引用，同名 workspace 可替换，保留 ID/分组/收藏；不能与其他类型同名。临时连接、Local 和失效引用阻止保存，失效存档阻止打开。打开创建全新会话、广播关闭，不自动恢复退出前标签或 Shell。详见 [存档契约](18-terminal-workspaces.md#8-显式保存与替换工作区)。

## 8. SFTP

单 SSH 终端状态栏开关控制可调右栏，Workspace/非 SSH 隐藏；开启侧栏禁止作为分屏来源或目标，排序仍可用。隐藏保留浏览/任务，断开/关闭取消，重连不重放。无停靠位置或尺寸持久化。

浏览支持路径/上级/主目录/刷新、隐藏项、链接与分页排序；目录/目录链接优先，根目录禁用上级。上传文件/目录到当前目录，普通文件逐项确认覆盖、目录合并、类型冲突拒绝，取消不回滚。下载按钮单文件；macOS 原生文件/目录拖至 Finder，兑现请求后才显示任务，取消无请求不留记录。Windows/Linux 拖出未实现。

固定双栏独立选择保存 SSH 主机、分别认证且无 PTY/Shell，Pointer Events 多选文件/真实目录对拷至对侧当前目录，覆盖确认/目录合并/进度/取消；双栏当前无系统文件拖入/拖出。本地端点、通用租约和完整任务管理待实现。详见 [SFTP](16-sftp-workspace.md)。

## 9. 端口转发

保险箱主机与凭据之间提供转发页，规则引用保存 SSH 主机，支持本地/远程/SOCKS5、搜索/CRUD/复制/启停；保存不连接，启动独立 SSH，不打开 Tab。只在监听就绪后高亮，切页保活；活动期间禁止编辑/删除，可复制配置。默认回环，SOCKS5 限回环且无认证，仅 TCP CONNECT；目标访问和解析位置明确展示，远程监听受服务器策略控制。不自动启动/重连，窗口与心跳清理。详见 [转发](21-port-forwarding.md)。

## 10. 页面与表单约定

主机两栏使用独立 NScrollbar，显隐挂原生 DOM；主机列表/分组树/标签共用 ScrollFade，仅可继续滚动一端显示与底色一致的渐隐。通用 UI 由库承载，业务布局归所属 Vue scoped 样式。

表单 model、控件 v-model、rules/path 共享同一响应式字段，提交前 validate，必填星号由规则生成；快速连接名称、可选秘密及允许的空回答保持可选。主机编辑使用 NGrid/NFormItemGi，避免自定义行距叠加。AppDialog 正文滚动、footer 独立，配色表单与常规设置不嵌套。右键菜单忽略打开菜单的右键/Control+单击外部关闭回调，弹层标记只随真实显示状态保留。

SSH 主机编辑与快速连接提供“启动方式”：交互 Shell（默认）/执行命令。命令模式显示必填命令字段，按 UTF-8 字节限额校验；保留原文，以 PTY exec 启动，程序结束后保留输出、右键“重新运行”。分屏标题显示“命令”，该窗格不收发广播，直接输入仍有效。工作区继续保存主机引用，重新打开执行最新保存命令；不自动重启或退出后进入 Shell。详见 [命令模式工作区](18-terminal-workspaces.md#9-ssh-命令模式工作区)。

## 11. 独立设置窗口与自动应用

应用菜单“设置”（不带省略号）/可配置快捷键打开单实例 settings 窗口，macOS 固定 Cmd+, 由 AppKit 应用内事件监视器在 WebKit 前交给原生菜单，菜单成功处理后消费事件，前端默认不绑定且对已有同组合绑定放行；其他组合仍可自定义，Windows/Linux 默认 Ctrl+,。重复打开恢复聚焦；主窗口销毁时清理。两个入口共享 NConfigProvider 与 assets/base.css。设置窗口创建时先显示 Termeta，前端按当前界面语言同步原生标题为“Termeta 设置”或“Termeta Settings”，语言变化时更新，重新打开读取已保存偏好。常规页可选简体中文/English/跟随系统，保存后两窗口同步切换界面及控件语言；解锁前先用系统语言，详见 [界面语言](13-ui-stack.md#界面语言与文案)。常规页为统一单列宽度，配色默认仅在配色页选择，网格自然展开、自定义默认折叠并在展开后初始化预览。

常规应用设置的有效修改自动持久化并跨窗口热应用，无显式保存/放弃按钮；云端备份配置使用独立保存按钮，亦会在上传/列表操作前保存有效修改。Rust 串行合并局部字段，主窗口即时偏好不被旧草稿覆盖。无效输入/写入失败保留编辑，修正自动重试或手动重试；关闭等待待写入完成，失败保留窗口。settings capability 仅设置、保险库改密/JSON 导出及专用备份同步命令，不能调用通用会话/主机/凭据/文件命令或首次云端初始化。关闭须包含 allow-close/allow-destroy 的库权限。

安全页提供“修改保险库密码”弹窗，使用共享响应式 NForm model，旧密码/新密码/确认新密码均必填；新密码至少12字符、不超过1024 UTF-8字节且与旧密码不同。显式提交，不走设置自动保存；新密码变化通过 FormItem 公开 API 重验确认字段。操作按钮位于 AppDialog footer，重新加密期间锁定弹窗并阻止设置窗口关闭，显示进度提示；成功与钥匙串/旧副本清理警告分开展示。提交完成、关闭或卸载清空输入，不 trim 密码；保险库数据库文件副本仍使用创建时的密码；独立云备份密码不随改密变化。没有遗忘密码重设或 Touch ID 入口。

## 12. SSH 系统图标

保存 SSH 主机可手动选择内置系统/类型图标，非默认优先。交互 Shell 模式默认开启一次性识别，命令模式跳过且不消耗机会；PTY/Shell 打开后独立固定 exec，不写终端；失败/超时/取消均消耗机会，修改地址不重置，关闭开关不消耗。设置仅提供自动识别开关与用途说明，不展示内部只读命令、不接受自定义脚本；识别结果不参与信任/权限。详见 [SSH](05-ssh-design.md#10-一次性主机系统识别)。

## 13. 手动备份与云端同步

设置的“备份 / 同步”页与首次初始化复用 BackupPanel。云端配置支持 Gist Token 或 WebDAV HTTPS 目录、用户名和密码，以及本机设备名称和独立备份密码；保存后仅回读 hasSecret/hasBackupPassword 状态，不显示已有秘密。目录须预先创建，测试连接不创建备份。应用设置与连接历史不进入云备份；主机、分组/标签/工作区、凭据、转发规则和主机信任按白名单导出。

用户明确选择“备份 · 上传新版本”或“同步 · 从云端下载”。备份密码作为云配置字段，首次填写或替换时校验确认值，保存后后续操作无需重复输入；留空沿用。上传使用配置中的密码，压缩数据库后将时间、设备名和计数一起加密，创建新远端对象；已有版本保留。下载使用已保存密码逐包解密版本信息，每页10项，可加载更多；无法解密项只显示通用错误。密码与云端配置变化会清除旧列表和恢复预览。备份密码至少12字符且不超过1024 UTF-8字节，随云配置加密写入本机设置；修改只影响新备份，旧包需配置原密码。旧配置只需补填一次备份密码。

选中版本先下载、解密并校验，确认弹窗展示来源时间/设备名和各类数量，操作置于 AppDialog footer。确认后在事务中新增合并，来源 ID 重新映射，名称冲突另存；重复导入同一备份也会新增副本，确认框明确提示。同一端点的信任密钥冲突跳过并提示，保留本机设置和现有会话。成功后只广播失效通知，主机/转发/当前凭据与信任列表重读。

首次云端初始化在同一页面填写本机新密码/确认、云配置及独立备份密码，选择版本预览后明确确认创建并导入。此入口只对全新 setup 保险库开放；业务导入与本机云配置及备份密码在同一数据库事务提交。创建本机库后导入失败时重新读取状态，允许进入已创建的库后再同步，不静默重置。云操作期间禁用相应控件并阻止设置窗口关闭；无自动上传/拉取、双向融合、版本清理、本地备份文件入口或取消 IPC。详见[备份与同步](22-data-backup.md)。

全部待运行范围统一见 [验收边界](01-product-requirements.md#11-运行验收边界)，本文不重复逐轮静态检查日志。

## 14. 启动本地标签与系统集成（待实现）

常规设置计划增加“启动进入：保险箱 / 本地终端”，缺失默认保险箱，选择本地后仅在普通冷启动解锁并准备就绪时创建一个 Local TAB；设置热应用、再次激活和 Reopen 不重复创建，显式外部请求优先。菜单与系统设置按真实能力分别标注目录入口、文件/URL 关联、Linux 默认启动器及 Windows 控制台委派，不用一个“默认终端”开关覆盖不同状态。当前没有这些设置/集成功能，完整交互及平台门槛见[功能调研](23-terminal-system-integration-research.md)和[实现方案](24-terminal-system-integration-plan.md)。
