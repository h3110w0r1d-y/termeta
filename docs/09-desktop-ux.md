# 桌面交互、设置与外观

更新：2026-10-27。本文维护用户可见行为与前端边界；功能状态见 [产品需求](01-product-requirements.md)。组件流程、样式数值和默认值以源码为准。

## 1. 页面与窗口

主窗口包含不可关闭的保险库、双远端 SFTP 固定页，以及动态终端组和只读日志标签。保险库管理主机、端口转发、凭据、Snippets、主机信任与会话日志；设置为独立单实例窗口，重复打开聚焦已有窗口。

标签可在顶部或左侧排列。动态终端组与日志标签支持中键关闭，沿用确认、任务处理和归档流程；中键不激活标签。固定页不创建终端；顶部固定页和新建按钮支持越过阈值后拖动窗口。切页、排序、分屏和迁移保留终端实例。返回保险库进入主机页并聚焦搜索，保留分组选择。

顶部与左侧标签布局共用窗口 Header 的明暗及按钮状态色，均跟随当前聚焦终端；固定页与日志标签的窗口导航回退应用深色。Header、标签导航和工作台内容各自分责，标签位置切换不移动内容及终端宿主；具体层级见 [系统架构](03-architecture.md#1-分层与代码入口)。

动态终端、工作区和只读日志标签共用工作台右侧工具栏，位于标签内容之外。开关留在顶部 Header 最右侧，Windows/Linux 位于窗口控制按钮之前，不随标签改为左侧而迁移；图标反映展开/收起状态。固定保险库/SFTP 页隐藏工具栏，返回动态标签保留开关及页面状态。“主题”“Snippets”页签固定，内容独立滚动；校验失败显示错误。工具栏随聚焦终端热应用局部主题；日志页回退全局默认配色，片段操作禁用。

macOS 使用 overlay traffic lights；Windows/Linux 使用应用窗口控件和独立应用菜单。主窗口与设置窗口指定原生深色外观及背景。Windows 窗口创建时保持隐藏，首次本地页面加载完成后显示，避免原生窗口早于 WebView2 初始化而暴露空白画面；HTML 入口提前声明深色底色，覆盖前端模块和样式加载阶段。后续刷新不自动显示或聚焦窗口。

发布版主窗口与设置窗口禁用 WebView 默认右键菜单，移除其中的页面刷新入口，避免误刷新丢失前端会话视图；主机、终端标题、标签和文件的业务右键菜单仍可使用。开发环境在终端正文以外保留默认菜单；终端正文统一按鼠标设置处理。

首次使用创建本机保险库并设置密码。已有库先尝试 OS 主密钥解锁，失败后要求本机密码。首次进入前不挂载业务页面，已挂载工作台被门禁遮住时保留终端宿主并禁用业务交互。缓存失败不撤销本次解锁；密码与主密钥均丢失且无备份时无法恢复。详见 [安全](08-security.md)。

## 2. 主机与分组

保存项包括 SSH、Telnet、串口和工作区，名称 trim 后区分大小写、全库唯一。主机表单保存配置，快速连接创建临时会话，本地终端启动系统 Shell；工作区从运行标签保存。

主机页支持卡片/列表、标签和分组树，不提供收藏。卡片头部图标在左侧跨两行，右侧上方显示名称和连接类型，下方显示分组路径；名称和分组过长时省略。卡片与列表共享持久化手动顺序，新项按名称排在手动顺序之后。默认显示直属项，可包含子组；搜索全库且不改变分组选择，支持字段配置和拼音匹配，不进行网络探测。新建标签页复用搜索，取消不创建终端。

单击选中，Ctrl/Cmd+单击增减多选，Shift+单击按当前显示顺序选择锚点至目标的范围。选中与焦点使用同样粗细的边框，不叠加焦点描边。主机页监听方向键：导航不依赖卡片焦点，没有选区时主动选中首项，有选区时从当前选中项按实际卡片行列或列表移动；搜索输入为空时方向键移出输入焦点并选中首项。Cmd/Ctrl+F 聚焦主机搜索；输入编辑、分组树及其他控件导航、模态和弹层优先。Shift+方向键扩展范围，Escape 清除选区。选区只属于当前浏览范围，切换分组/后代范围时清空，删除或迁出项不残留。

单项回车连接，多项回车复用分组的打开方式确认窗；多项右键提供工作组和独立标签两种直接打开入口。右键所选项保留批次，右键其他项改为单选。排序菜单支持将所选项置顶、置底、上移或下移。拖动任一选中项携带整个批次，保持批次内部显示顺序；拖到主机边缘插入排序，拖到树分组/未分组迁组并追加到目标组末尾。普通拖动不修改主机所属组，跨组迁移只在明确分组落点发生。地址正文保留原生选字，不作为拖动起点；拖动期间禁止地址文字选区，松开或取消后恢复。

分组计数和批量打开包含后代，不受搜索/直属显示偏好影响；配置 ID 去重，保存工作区独立恢复。多项连接可选择独立标签或均分布局，广播默认关闭。

迁组前后端防环。删除分组默认将直属主机/子组上移；递归删除须独立二次确认。删除保存项不影响已有会话，工作区和转发的失效引用保留供处理。工作区支持移动和删除，不通过主机表单编辑或复制。

SSH 默认公钥认证，按方式筛选就绪凭据并提供新建入口；公钥须选择私钥凭据，密码可留空后在连接时询问。保存秘密不回填。Telnet 明确提示明文登录，串口保存不打开设备。协议约束见 [SSH](05-ssh-design.md)、[Telnet](20-telnet-terminal.md)、[Serial](19-serial-terminal.md)。

## 3. 终端、认证与输入

失败、取消、断线及远端退出保留终端与复制/搜索能力，重连在原历史末尾追加且不重放输入；关闭视图才归档并销毁实例。终端已聚焦且处于关闭、失败或断开终态时，按普通回车重连；连接/认证中、已连接及关闭过程中不触发，长按连发、输入法确认与粘贴不触发，重连回车不发给新会话或广播目标。信任/认证弹窗退出后恢复当前活动终端焦点。信任和 OTP 约束见 [SSH](05-ssh-design.md)。

关闭标签关闭整组，关闭窗格只影响自身；可能执行命令、SFTP 传输和活动转发按各自规则确认。窗口关闭及正常退出须等待日志保存，失败保留视图。关闭提示仅为启发式判断，详见 [标题与关闭](18-terminal-workspaces.md#4-标题与关闭) 和 [日志归档](23-snippets-and-session-logs.md)。

按钮、菜单与快捷键共用命令注册表；录制、IME、模态和弹层优先。标准粘贴由系统 paste 事件进入终端宿主，执行大小、多行和广播校验，不自动补 Enter。链接须用户以修饰键点击，仅允许 http/https。详见 [快捷键](14-shortcuts.md)。

终端正文的右键和中键独立配置“无动作 / 粘贴”，新安装与旧设置缺失字段时均默认无动作。无动作不执行本地粘贴，保留远端程序的鼠标协议；终端正文不弹出默认右键菜单或触发系统中键选区粘贴。选择粘贴时，该按键手势由本地消费并聚焦终端，使用系统剪贴板及现有大小、多行、广播与会话代次校验，不向远端发送鼠标按下/松开，也不自动回车。仅已连接终端可触发粘贴，模态和弹层阻止该动作。标题及标签的业务菜单不受影响，标签中键关闭独立于终端中键设置。

## 4. 设置与跨窗口同步

设置沿用保险库的侧边菜单导航，提供常规、安全、备份 / 恢复、终端配色与快捷键；SSH 系统识别和搜索设置合并到常规页，减少独立导航项。右侧页面各自滚动，已访问页面在切换后保留编辑、滚动及操作状态；侧栏保持可见。

常规页提供 SFTP 左右停靠与终端右键/中键功能选择；默认停靠右侧，位置切换不重建浏览、任务或终端。

常规设置的有效修改自动保存并热应用。Rust 串行读取最新值、局部合并并通知窗口重读，旧草稿不能覆盖即时偏好。无效输入/写入失败保留编辑供重试，关闭设置须等待写入完成。窗口关闭按钮与 Cmd/Ctrl+W 共用保存等待流程。

第三方备份在已解锁后的设置中可用，备份 / 恢复页面顶部提供带图标的“备份”“恢复”按钮；备份直接上传，恢复选择版本后直接新增合并，均无二次确认。保险库改密和云配置单独显式提交，改密/云操作期间阻止设置关闭。settings 仅获得专用设置、改密、JSON 导出及备份权限，不获得通用业务资源或首次初始化权限。详见 [存储](07-storage.md) 和 [备份](22-data-backup.md)。

## 5. 界面语言与文案

应用支持简体中文、繁體中文、English、日本語、한국어及跟随系统。系统匹配按首个受支持语言选择，中文区分字形/地区，未知语言回退英文。解锁前使用系统语言，解锁后读取加密设置；主窗口、设置、控件、日期和窗口标题同步切换，不重连或重建终端。

macOS 应用菜单和已识别的系统固定项随语言更新；其他系统项、服务提供方和窗口名称由系统管理。界面使用类型化语义 key 和五语言词典，语言目录直接位于 `src/i18n/<locale>/`，动态整句使用命名参数；用户内容、路径、后端诊断和终端历史保留原文。提示说明操作与后果。

NSIS 配置 16 种安装语言，WiX 仅配置英文，均独立于应用语言。NSIS 可选当前用户/所有用户安装，当前双模式仍请求管理员权限；WiX 为所有用户安装。数据和主密钥始终按运行用户隔离。具体语言及打包参数见 [Tauri 配置](../src-tauri/tauri.conf.json)。

## 6. 应用外观与终端配色

主窗口、设置窗口与终端局部控件共用 Naive UI 根主题的圆角配置，自定义主色不改变其一致性。

应用固定深色，自定义主色与终端配色独立；旧外观设置兼容归一为深色。终端可使用浅色方案。终端标签栏按终端背景、前景与 UI 辅助色派生状态色，局部适配明暗，保持浅色终端可读性。

运行标签栏与底部状态栏跟随当前聚焦终端，子终端标题/按钮跟随组内统一配色；固定页回退应用深色。底部状态栏、终端 SFTP 与工具侧栏及其弹层按终端背景、前景和 UI 辅助色派生局部明暗主题，包含传送后的菜单与弹窗；固定双远端 SFTP 页使用应用外观。普通文字与顶部未激活标签共用 `colors.ui`，缺省回退终端前景色；禁用文字从 UI 色派生，强调状态使用前景色。输入与选择控件的默认边框和普通配色卡片一致，悬停/聚焦保持高亮。局部主题不包裹或重建终端宿主，具体颜色运算由源码维护。

传入 Naive UI 主题的派生颜色须预先计算为具体 RGB/RGBA，保留自定义颜色透明通道；不将 `color-mix()` 等 CSS 表达式交由控件库解析。

内置 64 套只读方案，自定义最多 64 套，默认 Pro。优先级为 terminalId 临时覆盖 → 主机覆盖 → 全局默认；工作区统一配色、创建/恢复和回退规则见 [工作区](18-terminal-workspaces.md)。临时覆盖只驻内存，重连保留，不改主机或存档。编辑内置方案创建副本，删除自定义方案须确认并回退引用。

有效编辑自动保存；导入先预览再新增副本，支持 Termeta Scheme v1 与基础 xterm ITheme JSON，拒绝非法结构、重复键、CSS 表达式和资源 URL。导出只含配色。热应用保留历史，预览使用无连接样本终端；远端 truecolor 不随 ANSI 色表重着色，选区适配依赖固定 xterm 渲染结构，升级须复核。

工具侧栏的字体与字号写入全局设置。选择配色会在同次设置提交中移除当前聚焦终端对应的已保存主机配色覆盖、更新全局默认，再清除当前标签的临时覆盖；快速连接不关联存储主机。工作区按新默认统一全组，其他标签仍按自身覆盖与继承规则解析。主机配色按 ID 局部合并，删除引用不覆盖其他主机的并发修改。

字体限随包分发的 12 家族，默认 DejaVu Sans Mono；版本和许可见 [字体资源](../resources/fonts/README.md)。字体加载后在原实例适配尺寸，不承诺编程连字。配色源与导入限制见 [配色资源](../resources/terminal-palettes.json) 和 [主题域](../src/theme/schemes.ts)，主题职责分层见 [系统架构](03-architecture.md)。

## 7. 前端实现边界

前端技术栈、表单、图标、i18n 与 IPC 规则统一见 [协作指南](../AGENTS.md#4-实现规则)，职责归属见 [系统架构](03-architecture.md)。用户指定的 SSH 系统素材及品牌图稿的来源、许可、平台留白与生成方式只在 [资源说明](../resources/README.md) 维护；深色品牌图标为默认，亮色底仅为备选，不随应用主题自动切换。

## 8. SFTP 文件浏览

侧栏和双远端页共用紧凑导航、面包屑与文件表格，目录导航和操作靠上，条目数/选择状态及可展开传输记录靠下。名称列保留文件拖动，其他列表区域提供框选；Shift 和 Ctrl/Cmd 与桌面文件管理器的范围/切换选择一致。长路径折叠祖先，尾部空白可编辑路径；权限使用读写执行矩阵与八进制同步编辑，非空目录永久删除需额外确认。完整操作和资源边界见 [SFTP](16-sftp-workspace.md)。
