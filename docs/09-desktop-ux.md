# 桌面工作台与终端交互

日期：2026-10-16。交互规格与首期重构源码已同步；尚未通过运行体验验收。

## 1. 信息结构

首期单主窗口，顶部 app-tabs 直接作为窗口标题栏，高度 54px。macOS 使用 Tauri Overlay/hidden title，保留原生红黄绿按钮，位置设为逻辑坐标 `(16, 27)` 以向下对齐54px栏中线（实际视觉待复验），并预留左侧 88px；Windows/Linux 移除系统标题栏，在右侧以 Naive UI 按钮提供最小化、最大化/还原、关闭。窗口命令统一经 desktop 门面，关闭仍触发会话/传输确认。

只有标记的栏背景、品牌、连接计数及空白区承担窗口拖动/双击最大化，标签、关闭标签及新建按钮维持原有交互。左侧标签模式使用独立的 54px 顶部窗口栏，侧栏本身不拖动窗口；切换布局不卸载终端。多窗口拖出标签仍不在当前范围，原生缩放/全屏/窗口拖动与按钮布局待三平台验收。

```text
主窗口
├── 应用标签栏：固定首页 / 固定 SFTP / SSH 终端标签
│   └── 默认顶部，设置可切换左侧纵向；固定页始终排在最前且不可关闭
├── 首页 Tab
│   ├── 侧栏菜单：主机 / 凭据 / 设置
│   └── 内容区：主机管理 / 加密凭据管理 / 设置编辑
├── SFTP Tab：左右各选保存主机，独立建立SFTP连接，Web栏间拖动对拷；终端另有SFTP侧栏
└── SSH Tab：工具栏 / 保活终端 / 状态；不挤占首页主机栏
```

没有真实主机时显示创建主机入口；全局新建标签页弹窗提供快速连接入口，不填充伪造“已连接服务器”。本地终端按钮接入真实PTY；Serial未实现前不出现可点击却无后端的连接按钮；架构扩展在文档/能力接口中保留即可。

首次启动先显示数据保险库密码设置（至少12字符、确认输入）；后续先尝试唯一OS主密钥自动解锁，失败则输入保险库密码恢复。未解锁不挂载主机/设置/工作区业务页面，不响应全局业务快捷键；保留窗口操作。密码恢复成功后重新缓存主密钥，缓存失败显示可关闭警告且保留本次解锁。密码与主密钥均遗失无法恢复，不提供静默重置。源码见VaultGate，运行效果待验收。

## 2. 主机管理

主机页采用左侧分组树、右侧主机卡片，左右独立滚动，顶部搜索及操作区固定；分组树使用 Naive UI NTree 和文件夹图标，名称后 `(n)` 表示整棵子树的主机数，不随搜索变化。保留“全部主机”和“未分组”入口。右侧默认只显示选中组直属主机，可勾选“包含子分组”；收藏主机始终置顶，同类按名称排序，不显示全部/收藏切换。包含子分组与树展开状态即时保存到数据库app.hostsView，重启恢复，旧设置默认false/空数组；快速展开/收起按顺序保存，最新请求失败回退已保存状态并提示。设置页保存旧草稿不回退这些即时偏好。新建分组按钮为与刷新一致的库有边框样式。新建主机默认归入当前组；主机编辑和移动选择器显示完整分组路径，区分同名子组。卡片显示名称、地址/端口、用户名、分组、收藏和标签。从其他标签返回首页时默认显示主机页（含点击、键盘切换和最后一个终端关闭后回退），显式打开设置仍进入设置；首次显示或从其他页面/标签切回主机页时通过NSelect.focusInput聚焦真实输入框，保留所选分组。主机页移除Header与刷新按钮，搜索框位于页面最顶部，下方左对齐“新建主机”“本地终端”两个按钮，再下方为左右分组区，使用独立NSelect下拉搜索全部主机的名称、地址、用户名、标签和分组路径，输入不改变下方主机列表或所选组；支持全拼、首字母、多音字、部分音节、中文/拼音混合及空格多词（各词可匹配不同字段），复用用户指定roco-helper-web的静态配置和匹配算法。无有效关键词时不显示下拉；鼠标勾选顶部字段复选框阻止mousedown默认聚焦，保留输入光标，键盘Tab仍可访问复选框。下拉最多100台，超出提示缩小范围；显示名称/地址/分组，收藏优先，点击或Enter连接选中主机，选择后清空并收起。库负责上下键/Esc及IME处理。不自动 ping 全列表，不因搜索触发网络请求。

分组右键菜单支持创建子组、编辑名称/父组与删除；树容器聚焦后 Shift+F10/菜单键操作当前高亮行，F2 编辑，菜单和表单提供拖拽的键盘替代。默认不展开全部层级，展开状态持久化，切页保留选中分组；创建/迁移后自动展开父路径也保存，已删除分组从展开集合移除。拖动分组到另一组成为其子组，拖到“全部主机”回到顶层；主机卡片拖到分组变更归属，拖到“未分组”解除归属。使用 Pointer Events，移动超过6px才进入拖动，目标高亮、悬停600ms展开，树边缘随指针移动滚动；自身/后代不是合法父组，后端再次防环。Esc、失焦、切页、pointercancel 或无效落点取消，不写入；松键不误触连接或选择操作。暂不提供同级手动排序、批量拖动及跨窗口拖动。

删除分组先选择处理方式：默认只删除当前组，直属主机和直属子组移到父组，顶层主机移至“未分组”；子组内部层级保留。选择“一并删除”会关闭选择弹窗，再弹出独立确认，明确整棵子树、主机数量、专属密码及不可撤销性。取消不修改数据；确认后由 Rust 单事务删除子组和主机，专属凭据登记清理，共享凭据和现有 SSH/SFTP 会话快照不受影响。删除已提交但重读失败时明确提示刷新，不能提示为删除未成功。

主机编辑器区分基本信息、认证与高级设置。默认端口 22，用户名必填；密码可引用公共凭据，或直接填写为该主机专属密码；输入非空自动保存，留空保存会移除旧密码并改为连接时询问，无记住开关。编辑仅提示 hasPassword，不读取原秘密回填。私钥认证引用凭据库中的私钥；凭据页通过原生选择器导入私钥及可选解密密码，不展示正文。高级算法设置首期不提供弱算法“一键兼容全部”。

主机卡片不显示底部按钮，连接/编辑/复制/删除集中于右键菜单；聚焦卡片后可按 Shift+F10 或菜单键打开，删除沿用确认流程。SSH 标签紧随名称并垂直居中，长名称省略但保留协议标签；收藏按钮和自定义标签保留。点击主机只选择，双击或 Enter 打开会话；避免用户在编辑/搜索时误触连接。打开同一主机可以建多个独立会话，标签追加区分号。删除主机时说明只影响配置，当前已连接会话继续使用其快照；共享凭据单独管理。

快速连接默认临时 profile；连接成功后可另行保存非秘密配置。不能把用户输入的秘密拼进 URL 或完整连接命令。

## 3. 标签与终端

- 首页和 SFTP 是应用级固定标签，不创建会话或 xterm；关闭快捷键在固定页不执行。标签导航包含固定页，顶部使用左右键、侧边使用上下键，Home/End 跳至首尾。
- 每个终端拥有稳定 terminalId 与 xterm 视图，先后绑定多次后端 session；M2 按用户要求增加内存分屏，布局模型为标签组→二叉布局树→terminalId→当前 session。M3 增加独立 sftp Tab 类型，左右 browserId 不创建虚假终端。
- 标签显示名称、类型、状态图标与关闭按钮；颜色之外同时用文本/图标表达状态。
- 切换标签保持同一 xterm 实例、缓冲、selection 与 session；隐藏宿主继续消费输出。
- Connected 前禁用向远端写入，状态文字解释当前阶段；始终保留滚动、选择、复制和已实现的搜索。断线、连接失败、认证失败、取消连接、正常远端退出都保留 Tab、原屏幕和缓冲，清空的只有旧待发送输入队列。
- 重连保留同一 Tab、terminalId、xterm 实例与缓冲，新的 session 输出继续追加到原终端末尾。禁止因重连调用 clear/reset/dispose 或创建替代终端；用本地状态分界显示断线/重连时间及结果。重连失败仍可查看历史并再次尝试。
- 关闭已连接终端时，当 OSC 133 标记执行中，或 OSC 0/2 标题第一个冒号前的部分与本次连接首次标题前缀不同时确认；冒号后的目录变化不触发提醒；其余直接关闭。沿用confirmClose总开关（可关闭提醒），已断开终端直接关闭。确认后取消后端并释放历史。
- 关闭窗口按同一执行状态规则判断；有可能执行命令的终端时统一确认一次，否则直接关闭，逐个取消，不弹多个阻塞对话框。当前 SFTP 与终端共用连接，断开或关闭终端会取消传输；独立租约与隧道后续另行设计。

断开只是停止连接，关闭 Tab 才释放 xterm。首次连接前即创建 Tab，失败后保留空终端与错误详情；不能因为 open_session 抛错而回滚删除 Tab。错误显示采用非遮挡状态条/终端外面板，或以本地诊断行追加到末尾，不用覆盖终端的错误页面替换原内容。

历史遵循用户配置的 scrollback 上限，不因连接失败/重连主动裁剪；不落盘或跨应用重启恢复。用户滚动查看历史时，追加状态/新输出不强制跳底，可提示“有新输出”，由用户选择回到底部。断线期间只禁用远端输入路径，不给整个宿主设置 disabled/pointer-events:none，也不拦截本地复制快捷键。

连接边界需要特别验证旧 Shell 的鼠标跟踪、bracketed paste、alternate screen、未闭合 ANSI/UTF-8 状态：应终止旧连接的输入模式，并在保留已有 normal scrollback 的前提下回到可读/可选取状态。全屏程序最后画面需有界保留为该次连接的可查看快照，具体公开 API/序列方案待 SP-07；不能通过清空终端解决。连接生命周期的保留要求不改变用户明确发出的清屏操作，也不承诺无限历史。

## 4. 首次信任与认证

主机信任弹窗必须突出连接目标、端口、算法和 SHA256 指纹，并解释需要可信来源核验。提供拒绝/仅本次允许/信任并保存；拒绝默认获得安全焦点，普通 Enter 不误触永久信任。等待时支持取消、倒计时和复制指纹；复制动作不复制任何凭据。

密钥变更使用阻断视图，显示旧/新指纹与信任管理入口，不提供隐蔽的忽略复选框。信任管理撤销/替换需要展示受影响 endpoint，然后重新连接。

认证弹窗按 challenge 内容生成普通文本字段；密码/口令掩码，OTP 不显示保存选项。多因素成功一部分时显示还需下一步，不能把 OTP 错误误写成“私钥无效”。同一 session 串行 challenge，不同 session 的提示排队呈现并明确其目标；后台连接不得突然抢走用户当前终端焦点。

## 5. 快捷键与输入

应用根页面固定在视口内，不允许页面级横纵滚动或边缘回弹；主机列表、设置与终端保留各自的内部滚动。终端滚轮到达上下边界时不向根页面传递滚动。单独按 Command/Control/Alt/Shift 不改变终端选区与历史位置，实际输入沿用 xterm 的跟随行为。顶部/侧栏工作区使用自定义 WorkspaceTabs，横向标签按钮高度32px、`padding: 4px 12px`，关闭按钮22×22px、图标16px；纵向保持36px高度、`padding: 6px 12px`，关闭按钮24×24px、图标14px。组件只负责展示、导航与派发 activate/close/menu 等事件，WorkspaceStore 保持唯一状态源；动态标签支持指针拖拽排序与四向拖入嵌套分屏，固定首页/SFTP 不参与，详见 [终端工作区](18-terminal-workspaces.md)。

终端不显示常驻顶部工具栏；名称和状态由标签及底部状态栏展示。普通终端标签的 Naive UI 上下文菜单包含复制标签页、拆分会话、搜索、配色、断开/重连，可右键或聚焦标签后按 Shift+F10/菜单键打开。复制按原连接配置建立独立标签；拆分在右侧新建独立会话，和原终端组成 Workspace，SFTP 侧栏开启时禁用。Workspace 标签不提供鼠标或键盘上下文菜单，窗格标题菜单保留。设置可选择双击无动作（默认）/关闭标签页/复制标签页/拆分会话；复制与拆分仅适用于普通终端，Workspace 可双击关闭，固定页不响应。关闭仍遵循执行状态和传输确认，搜索快捷键继续可用。

M2 设置明确分“全局快捷键”和“终端快捷键”，提供自定义录制、多绑定、移除、恢复默认、导入导出、冲突提示与可用状态。全局默认应用窗口前台跨页面生效；系统后台热键另标系统级，作为 M5/P1 opt-in，不能混同。完整动作表、上下文优先级与模型见 [快捷键规格](14-shortcuts.md)。

| 行为               | macOS 默认    | Windows/Linux 默认          | 交互规则                                            |
| ------------------ | ------------- | --------------------------- | --------------------------------------------------- |
| 新本地终端（全局） | Cmd+L         | Ctrl+Shift+L                | Local M4 可用后启用，当前仅保留配置与禁用原因       |

| 复制/粘贴（终端）  | Cmd+C / Cmd+V | Ctrl+Shift+C / Ctrl+Shift+V | 离线可复制，Ctrl+C 默认送远端作中断                 |

Ctrl/Alt/Option/Meta、功能键、AltGr、鼠标报告、selection 和中文输入法需按平台验证。Option 是否作为 Alt 由设置明确选择。不自动为粘贴末尾补 Enter；多行粘贴确认默认启用，显示真实内容与换行数量。

## 6. 字体、主题与可访问性

应用外壳通过 CSS tokens 提供系统/深/浅主题；终端配色独立设置，不强制跟随应用明暗。M2 现内置64套提取方案（默认 Pro，来源见 [资源说明](../resources/README.md)），支持复制为自定义、任意取色/HEX/RGB、前背景/光标/选区/ANSI16 与支持的扩展色编辑、JSON 导入导出和预览。全局默认 → profile 覆盖 → 当前终端临时覆盖，具体优先级由高到低见 [配色规格](15-terminal-themes.md)。修改立即热应用同一 xterm，不清历史、不重连；导入先校验/预览，不自动覆盖或应用。

终端字体采用固定12项 Naive UI 下拉选择：DejaVu Sans Mono、Droid Sans Mono、Ubuntu Mono、Anonymous Pro、Inconsolata、Fira Mono、Source Code Pro、PT Mono、Cascadia Code、Fira Code、JetBrains Mono、Meslo，默认 DejaVu Sans Mono。下拉选项与当前选中名称通过 NSelect render-label 使用各自实际字体渲染，按可见内容自动加载本地字型。随应用分发原始 TTF/WOFF2 与许可证，完整版本来源见 [字体资源说明](../public/fonts/README.md)；不依赖系统安装或在线 CDN。Meslo 固定 LG S，小行距版本；没有独立字型时由浏览器合成粗体/斜体，不承诺 xterm 编程连字。

fontFamily 保存规范家族名称；Rust 仅接受上述12项。读取旧自由字体串时归一为默认项，不自动写库。CSS 使用 Termvexa 前缀的独立别名，避免系统同名字体干扰。字型加载完成后更新 xterm 并 fit/resize，迟到加载不能覆盖较新的设置或访问已销毁实例；隐藏标签待激活重算，不重建终端或清空历史。加载失败在标签报告错误，允许重新应用。支持字号和有限 scrollback，初始5000行、可设1000–50000；行高与光标更多选项仍属后续设计，内存与三平台字宽表现待验证。仅改颜色不需远端 resize。

开启合适的对比度与屏幕阅读器支持，按钮有可访问名称；分组树与弹窗可用键盘操作。错误信息提供明确行为，如检查地址、重新输入、管理信任、复制脱敏诊断；不显示裸 Rust backtrace 或把所有失败提示为“连接失败”。

| 状态                          | 文案示例                             | 操作                                    |
| ----------------------------- | ------------------------------------ | --------------------------------------- |
| connecting                    | 正在连接目标…                        | 取消                                    |
| awaitingHostKey               | 等待核验主机指纹                     | 查看/拒绝                               |
| authenticating / awaitingAuth | 正在认证 / 需要补充认证信息          | 输入/取消                               |
| opening                       | 正在启动远端终端                     | 取消                                    |
| connected                     | 已连接 · SSH · UTF-8 · 120×32        | 复制/搜索/断开                          |
| disconnected                  | 连接已中断：保活超时                 | 保留历史；重连后原终端继续追加          |
| failed                        | 主机密钥已变更，连接已阻止           | 保留 Tab 与历史；查看详情/管理信任/重试 |
| closed                        | 远端进程已退出（代码 0）或用户已断开 | 重新连接/关闭标签                       |

应用重启只恢复保存的主机和设置；M3 可恢复布局引用，但依然显示未连接，用户确认后才重新建立。不要使用“已恢复会话”暗示远端 Shell 仍然存在。

## 8. SFTP

单 SSH 终端底部 SFTP 开关显示/隐藏可调宽右侧栏，Workspace 与本地终端隐藏开关；开启侧栏的终端可排序，不能作为来源或目标合并分屏。首次开启挂载，之后隐藏保活，终端与文件侧栏不共享外围留白。尚无附属 SFTP 快捷键、停靠位置或尺寸持久化。

面板只提供浏览与上传下载：路径、主目录、上级、刷新、隐藏文件、选择框和名称排序；目录及目录链接优先，`..` 固定首行且根目录禁用。列表仅选择框/名称/大小/权限，文件类型用图标，链接显示名称与目标；大小按 1024 进制、两位小数。每页 100 项，最多载入 10000 项；目录链接直接访问逻辑路径，不跳转显示目标路径。

上传按钮原生多选，外部文件/目录拖入可见面板后确认当前目录；不按目录行定位。已有普通文件逐项询问后直接覆盖，同名目录递归合并，类型冲突拒绝，绝不删除目录再上传。队列显示当前文件、计数、进度、取消及失败；取消覆盖不能恢复原内容，已完成文件保留。

下载按钮保留单普通文件保存。macOS 真实原生文件承诺可将普通文件或真实目录拖至 Finder，目录递归下载且不跟随源链接；鼠标手势不能排队。Finder 请求兑现后才显示任务，没有内容请求的取消不留记录；内部拖放不触发上传。Windows/Linux 拖出未实现，使用下载按钮。隐藏继续任务，断开/关闭终端会取消；不支持关闭 Tab 后后台继续。

固定双栏已支持保存主机独立连接与Web Pointer Events栏间对拷；只复制到对侧当前目录，不使用系统文件拖放。支持多选文件/真实目录，文件覆盖确认、目录合并，显示进度并可取消。本地端点、通用连接租约和布局恢复仍为后续设计，详见 [SFTP](16-sftp-workspace.md)。当前源码尚未完成运行体验验收。

## 9. 后续终端扩展

布局树只计算矩形，TerminalStage 扁平 keyed 宿主不移动或销毁 xterm；持久化只存 profileRef/布局引用，不保存 live handle 或终端正文。Local 与 Serial 分别提供 Shell/cwd 和串口参数，不复用 SSH 认证表单；本地文件服务不依赖 Local PTY。

## 10. 页面与工作区约定

首页提供主机、凭据、内嵌设置三页，原生 DOM 显隐保活；主机分组树和主机列表各自 NScrollbar，凭据页单独 NScrollbar；共用页头和 28px 内边距，无品牌页脚。设置正文滚动，保存/放弃固定底部。常规页采用等宽双列：标签栏位置使用顶部/左侧单选按钮，应用外观使用月亮/太阳/显示器图标单选按钮（深色/浅色/跟随系统，悬停提示并保留辅助文字）；标签栏位置和终端字体与其他选项同宽。默认终端方案仅在终端配色页设置，不在常规页重复显示；配色自然网格铺开，自定义折叠在下方，先改草稿再保存。

工作区标签顶部或左侧布局；横向32px/纵向36px标签、主题圆角，固定页与可滚动会话区分隔，新建按钮保持 36×36。相同主机 profileId 或快速连接 endpoint/user 按次序显示 `(2)` 等，关闭中间标签不重新编号。远端 OSC 标题仅作清理限长后的显示后缀。动态关闭提示参考 OSC 133 与首次/当前标题的冒号前缀比较，不保证检测真实进程；缺少两类信息时不触发命令执行提醒。

标签排序、四向嵌套分屏、窗格拖回 Tab 或跨组重分割保持实例；跨标签悬停 600ms 切页。广播按钮共享组状态，激活实线、其余虚线；仅分发用户键盘/IME/粘贴及远端滚轮，排除点击、拖动、自动应答和认证表单，成员重组关闭。详情见 [工作区](18-terminal-workspaces.md)。

终端右键与配色子菜单受视口约束，库滚动条承载长菜单。本地连接状态消息独立于远端流，备用屏退出保留有界快照，追加状态不清空原历史。三平台焦点、中文输入、缩放、剪贴板、拖放与视觉表现仍须验收。

主机分组增强（2026-10-16）已落源码，前端类型/格式、Rust格式、IPC/ACL与文档差异仅静态核对。树键盘操作、双栏滚动、主机/分组拖拽、取消后首击、两步删除与三平台 WebView 尚待运行验收。

设置页增加“搜索”：拼音模糊搜索开关和可搜索项目（名称固定；地址、用户名、标签、分组可选），默认拼音开启且全部字段参与。NSelect下拉顶部显示同一份字段复选框，修改即时持久化，失败显示错误并保留已保存值。关闭拼音后只做不区分大小写的原文多词匹配。字段变更直接重算下拉结果，不改变所选分组或右侧列表。

主机/快速连接、分组编辑/移动、凭据、保险库、设置、自定义配色、认证回答、通用输入确认以及SFTP连接/路径输入接入Naive UI NForm/NFormItem规则与提交前validate。必填红星由required规则生成，失败在字段旁提示；快速连接名称、专属密码、私钥解密密码保持可选，认证回答允许空值及零提示继续。导航路径拒绝空值但保留合法路径空格。自定义配色表单独立于常规设置表单，避免嵌套HTML form。

连接或认证弹窗退场完成后，通过AppDialog的after-leave恢复当前活动终端焦点；不因连接完成抢走其他活动页或新弹窗的焦点。主机/终端上下文菜单及搜索菜单保活渲染，仅在实际显示时带data-ui-popup-open，避免退出动画留下标记阻断终端聚焦与快捷键。

全局“新建标签页”弹窗由标签栏＋、Cmd/Ctrl+T及原Cmd+N/Ctrl+Shift+N新连接动作打开，打开后真实聚焦搜索输入。复用主页useHostSearch（拼音开关、名称固定/字段选择、多词匹配、收藏置顶），结果直接显示在弹窗正文；空查询列出保存主机，最多100条，超出提示缩小范围。↑/↓定位、Enter或点击主机连接，IME组合期间不处理导航/提交。复选框即时保存且鼠标勾选保留输入光标。主页移除快速连接按钮，入口放入新建标签页弹窗footer；先等弹窗after-leave，再创建保存主机终端或显示既有快速连接表单，避免焦点陷阱重叠。取消不创建Tab。
