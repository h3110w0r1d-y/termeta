# 桌面工作台与终端交互

日期：2026-10-15。交互规格，尚无已实现产品页面。

## 1. 信息结构

首期单主窗口，使用系统标题栏优先保证窗口操作/可访问性；不将自绘无边框、多窗口拖出标签设为 SSH 前置条件。

```text
主窗口
├── 顶部：工作区标题 / 活动会话提示
├── 左侧：主机搜索、收藏、分组树、主机列表
├── 中间：标签栏 + 当前终端 / 欢迎页
├── 底部：状态、SSH endpoint、尺寸、编码、错误入口
└── 独立面板/对话框：主机编辑、认证、主机指纹、设置、凭据元数据
```

没有真实主机时显示创建主机/快速连接入口，不填充伪造“已连接服务器”。Local/Serial 未实现前不出现可点击却无后端的连接按钮；架构扩展在文档/能力接口中保留即可。

## 2. 主机管理

列表显示名称、地址/端口、用户名、分组、收藏和最近连接状态。搜索同时匹配名称、地址、用户名和标签；输入防抖但保留键盘即时导航。不自动 ping 全列表，不因搜索触发网络请求。

主机编辑器区分基本信息、认证与高级设置。默认端口 22，用户名必填；密码在实际连接 challenge 输入，保存的元数据只引用凭据。私钥通过原生选择器引用，UI 显示名称/公钥指纹，不展示私钥正文。高级算法设置首期不提供弱算法“一键兼容全部”。

点击主机只选择，双击或 Enter 打开会话；避免用户在编辑/搜索时误触连接。打开同一主机可以建多个独立会话，标签追加区分号。删除主机时说明只影响配置，当前已连接会话继续使用其快照；共享凭据单独管理。

快速连接默认临时 profile；连接成功后可另行保存非秘密配置。不能把用户输入的秘密拼进 URL 或完整连接命令。

## 3. 标签与终端

- 每个终端标签拥有一个稳定 terminalId 与 xterm 视图，先后绑定多次后端 session；M2 不实现分屏，布局模型为 tab→pane→terminalId→当前 session。M3 增加独立 sftp Tab 类型，左右 browserId 不创建虚假终端。
- 标签显示名称、类型、状态图标与关闭按钮；颜色之外同时用文本/图标表达状态。
- 切换标签保持同一 xterm 实例、缓冲、selection 与 session；隐藏宿主继续消费输出。
- Connected 前禁用向远端写入，状态文字解释当前阶段；始终保留滚动、选择、复制和已实现的搜索。断线、连接失败、认证失败、取消连接、正常远端退出都保留 Tab、原屏幕和缓冲，清空的只有旧待发送输入队列。
- 重连保留同一 Tab、terminalId、xterm 实例与缓冲，新的 session 输出继续追加到原终端末尾。禁止因重连调用 clear/reset/dispose 或创建替代终端；用本地状态分界显示断线/重连时间及结果。重连失败仍可查看历史并再次尝试。
- 关闭已连接标签需要确认（可设置“不再询问”）；已断开标签可直接关闭。确认关闭时先停止新输入并取消后端，释放过程显示 closing。
- 关闭窗口有多个活动会话时统一确认一次，逐个取消，不弹多个阻塞对话框。未来 SFTP/隧道存在时必须区分“关终端”和“断开全部连接”。

断开只是停止连接，关闭 Tab 才释放 xterm。首次连接前即创建 Tab，失败后保留空终端与错误详情；不能因为 open_session 抛错而回滚删除 Tab。错误显示采用非遮挡状态条/终端外面板，或以本地诊断行追加到末尾，不用覆盖终端的错误页面替换原内容。

历史遵循用户配置的 scrollback 上限，不因连接失败/重连主动裁剪；本轮不要求落盘或跨应用重启恢复。用户滚动查看历史时，追加状态/新输出不强制跳底，可提示“有新输出”，由用户选择回到底部。断线期间只禁用远端输入路径，不给整个宿主设置 disabled/pointer-events:none，也不拦截本地复制快捷键。

连接边界需要特别验证旧 Shell 的鼠标跟踪、bracketed paste、alternate screen、未闭合 ANSI/UTF-8 状态：应终止旧连接的输入模式，并在保留已有 normal scrollback 的前提下回到可读/可选取状态。全屏程序最后画面需有界保留为该次连接的可查看快照，具体公开 API/序列方案待 SP-07；不能通过清空终端解决。连接生命周期的保留要求不改变用户明确发出的清屏操作，也不承诺无限历史。

## 4. 首次信任与认证

主机信任弹窗必须突出连接目标、端口、算法和 SHA256 指纹，并解释需要可信来源核验。提供拒绝/仅本次允许/信任并保存；拒绝默认获得安全焦点，普通 Enter 不误触永久信任。等待时支持取消、倒计时和复制指纹；复制动作不复制任何凭据。

密钥变更使用阻断视图，显示旧/新指纹与信任管理入口，不提供隐蔽的忽略复选框。信任管理撤销/替换需要展示受影响 endpoint，然后重新连接。

认证弹窗按 challenge 内容生成普通文本字段；密码/口令掩码，OTP 不显示保存选项。多因素成功一部分时显示还需下一步，不能把 OTP 错误误写成“私钥无效”。同一 session 串行 challenge，不同 session 的提示排队呈现并明确其目标；后台连接不得突然抢走用户当前终端焦点。

## 5. 快捷键与输入

M2 设置明确分“全局快捷键”和“终端快捷键”，提供自定义录制、多绑定、移除、恢复默认、导入导出、冲突提示与可用状态。全局默认应用窗口前台跨页面生效；系统后台热键另标系统级，作为 M5/P1 opt-in，不能混同。完整动作表、上下文优先级与模型见 [快捷键规格](14-shortcuts.md)。

| 行为 | macOS 默认 | Windows/Linux 默认 | 交互规则 |
| --- | --- | --- | --- |
| 新本地终端（全局） | Cmd+L | Ctrl+Shift+L | Local M4 可用后启用，当前仅保留配置与禁用原因 |
| 新连接（全局） | Cmd+N | Ctrl+Shift+N | 不暗中启动本地 Shell |
| 关闭标签（全局） | Cmd+W | Ctrl+Shift+W | 活跃连接/传输遵循关闭确认 |
| 复制/粘贴（终端） | Cmd+C / Cmd+V | Ctrl+Shift+C / Ctrl+Shift+V | 离线可复制，Ctrl+C 默认送远端作中断 |
| 搜索（终端） | Cmd+F | Ctrl+Shift+F | 离线可用，关闭后焦点回终端 |
| 打开终端链接 | Cmd+主键单击 | Ctrl+主键单击 | 可自定义修饰键；普通点击不打开，默认只开 http/https |
| 显隐附属 SFTP | Cmd+Shift+E | Ctrl+Shift+E | M3 SSH 面板可用后启用，位置依设置 |

按钮、菜单与快捷键同一 CommandRegistry，避免重复执行；IME/录制/模态/当前焦点优先，不一刀切捕获全部 keydown。Windows/Linux Ctrl+L 默认仍送远端；用户显式改绑时提示冲突。Cmd/Ctrl+点击仅在链接命中且非拖选时打开，不重复向远端发送同一次鼠标事件。

Ctrl/Alt/Option/Meta、功能键、AltGr、鼠标报告、selection 和中文输入法需按平台验证。Option 是否作为 Alt 由设置明确选择。不自动为粘贴末尾补 Enter；多行粘贴确认默认启用，显示真实内容与换行数量。

## 6. 字体、主题与可访问性

应用外壳通过 CSS tokens 提供系统/深/浅主题；终端配色独立设置，不强制跟随应用明暗。M2 至少 8 个内置方案，支持复制为自定义、任意取色/HEX/RGB、前背景/光标/选区/ANSI16 与支持的扩展色编辑、JSON 导入导出和预览。全局默认 → profile 覆盖 → 当前终端临时覆盖，具体优先级由高到低见 [配色规格](15-terminal-themes.md)。修改立即热应用同一 xterm，不清历史、不重连；导入先校验/预览，不自动覆盖或应用。

字体使用系统等宽候选，支持字号、行高、光标和有限 scrollback；初始 scrollback 5000 行，可设 1000–50000，内存表现需测量。字体变更触发可见终端 fit/resize，隐藏标签待激活重算；仅改颜色不需远端 resize。

开启合适的对比度与屏幕阅读器支持，按钮有可访问名称；分组树与弹窗可用键盘操作。错误信息提供明确行为，如检查地址、重新输入、管理信任、复制脱敏诊断；不显示裸 Rust backtrace 或把所有失败提示为“连接失败”。

## 7. 状态与恢复文案

| 状态 | 文案示例 | 操作 |
| --- | --- | --- |
| connecting | 正在连接目标… | 取消 |
| awaitingHostKey | 等待核验主机指纹 | 查看/拒绝 |
| authenticating / awaitingAuth | 正在认证 / 需要补充认证信息 | 输入/取消 |
| opening | 正在启动远端终端 | 取消 |
| connected | 已连接 · SSH · UTF-8 · 120×32 | 复制/搜索/断开 |
| disconnected | 连接已中断：保活超时 | 保留历史；重连后原终端继续追加 |
| failed | 主机密钥已变更，连接已阻止 | 保留 Tab 与历史；查看详情/管理信任/重试 |
| closed | 远端进程已退出（代码 0）或用户已断开 | 重新连接/关闭标签 |

应用重启只恢复保存的主机和设置；M3 可恢复布局引用，但依然显示未连接，用户确认后才重新建立。不要使用“已恢复会话”暗示远端 Shell 仍然存在。

## 8. SFTP 与 M3/M4 交互延伸

SSH 终端的 SFTP 面板可打开/隐藏，支持左/右/底部位置与尺寸设置，默认右侧；折叠或变换位置不销毁终端、不清屏，传输继续。面板支持文件/目录浏览、上传下载、原生拖入拖出、权限/时间/可支持 uid/gid 修改，上传遇到同名项默认先询问覆盖。详细冲突与拖出平台边界见 [SFTP 规格](16-sftp-workspace.md)。

独立 SFTP Tab 是左右双栏文件工作区，两侧都可选择本地或 SSH，支持本地↔远端和远端 A↔B 拖拽复制。标清两端身份和路径，默认 copy，不能无提示删除源。远端互传默认后台有界中转，不要求用户手动下载/上传；切换侧栏端点不重定向旧任务。关闭有任务的 Tab 可选应用内后台继续或取消，退出应用统一确认。文件列表过期/失败保留但禁用写入，终端断线历史仍可查看。

分屏布局采用版本化树节点 `split(direction, ratio, children)` / `leaf(paneId, profileRef)`，不保存 live handle；移动 pane 不销毁终端。SFTP Tab 与 terminal Tab 分属布局节点类型。串口有参数面板与 Terminal/HEX 切换，本地终端有 Shell/cwd 选择；不能复用 SSH 专用认证表单。本地文件浏览 M3 即可实现，不等待 Local PTY。

## 9. UI 基础组件方案

采用 Reka UI primitives 作为交互基础，项目在 `src/components/ui/` 封装自己的 Dialog、Menu、Select、Tooltip 等组件，结合 CSS tokens/自定义样式形成紧凑桌面视觉。终端标签工作区与宿主由应用管理，不直接依赖 TabsContent 默认显隐生命周期。Tree 等 Alpha 控件先隔离验证，文件选择与系统菜单由 Tauri 原生能力提供。完整官方预研、组件映射与集成约束见 [UI 选型](13-ui-stack.md)。
