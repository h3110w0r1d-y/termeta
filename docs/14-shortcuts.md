# 快捷键设置与输入路由

更新：2026-11-06。应用内快捷键支持分类编辑、录制、多绑定、禁用、恢复默认与 JSON 导入导出。当前没有系统后台热键、多段 chord、按平台独立覆盖或原生菜单 accelerator 的通用同步。

## 1. 默认动作

`Primary` 在 macOS 对应 Command，在 Windows/Linux 对应 Control。按钮、菜单和键盘共用 [命令注册表](../src/services/commands/registry.ts)。

| 动作 | macOS | Windows/Linux |
| --- | --- | --- |
| 新建标签页 | Cmd+T | Ctrl+T |
| 新连接入口 | Cmd+N | Ctrl+Shift+N |
| 关闭标签 | Cmd+W | Ctrl+Shift+W |
| 下一个/上一个标签 | Cmd+Shift+] / [ | Ctrl+PageDown / PageUp |
| 打开设置 | Cmd+,（原生菜单） | Ctrl+, |
| 新建本地终端 | Cmd+L | Ctrl+Shift+L |
| 复制/粘贴 | Cmd+C / V | Ctrl+Shift+C / V |
| 搜索终端 | Cmd+F | Ctrl+Shift+F |
| 聚焦主机搜索（主机页） | Cmd+F | Ctrl+F |
| 打开终端链接 | Cmd+主键单击 | Ctrl+主键单击 |
| 滚动到底部 | 未绑定 | 未绑定 |

新建标签页和新连接入口都打开全局连接选择弹窗，快速连接由弹窗进入。SFTP 没有独立快捷键。Windows/Linux 默认 Ctrl+C 发送远端中断，Ctrl+L 交给 Shell。

## 2. 设置与路由边界

快捷键配置通过设置侧栏进入，名称、绑定控件和操作按钮按统一列宽对齐；长名称在名称列内换行，窄内容区将名称置于整行，保持绑定与按钮对齐。分类和搜索位于列表上方，不影响录制、多绑定与导入导出语义。

仅接受 `keymap.schemaVersion=2`。应用动作使用 `workbench.*` 或 `settings.open`，作用域为 application、上下文为 workbench；终端动作使用 `terminal.*`、terminal 作用域与上下文。前后端校验注册动作、触发器、修饰键、上下文及冲突，不接受脚本、Shell 命令或宏。旧版本、旧命名和未知动作拒绝导入，不静默转默认值。

读取和导入保留用户绑定集合，不补充缺失动作；新安装或主动恢复默认才获取完整默认集。录制只捕获组合，不执行动作或向远端发送输入。

应用动作在前台跨页面生效，包括普通输入框；终端动作仅终端内生效。路由优先处理录制、IME、模态和弹层，再匹配终端动作、应用动作，剩余输入交给 xterm。主机搜索下拉允许应用动作，其他弹层优先。仅实际消费动作时阻止默认行为；用户显式将应用动作绑定到编辑按键时，该绑定优先。

聚焦终端处于关闭、失败或断开终态时，未被自定义快捷键消费的无修饰键回车触发重连；录制、IME、模态和弹层仍优先。该动作只响应键盘按下且排除长按连发，不从粘贴、设备应答或广播输入推断重连；消费回车后不向新会话发送输入。其他状态保持原有输入路由。

标准终端粘贴匹配已启用绑定后放行系统 paste，由宿主统一执行 64 KiB 限制、多行确认、括号粘贴和广播代次校验；自定义绑定使用显式剪贴板读取，可能受 WebView 授权限制。粘贴不自动补 Enter。macOS 无其他修饰键时，Option+左右方向键可转换为 ESC b/f，自定义绑定优先。

中文标点转换按源终端的有效开关处理，以实际确认的文本为准，包含按 Shift 输入的中文标点。原生直接提交的标点在进入终端前转换；输入法组合正文在确认后转换，均只发送一次，广播目标不二次转换。粘贴、Snippets、路径插入、鼠标协议、滚轮、二进制输入和设备应答保持原始内容；开关及临时覆盖见 [终端输入](09-desktop-ux.md#3-终端认证与输入)。临时切换动作没有默认快捷键，可在快捷键设置中自行绑定。

纯修饰键在进入 xterm 按键处理前过滤，仅停止向终端内部传播，保留系统与输入法默认行为。这样可兼容 WebKit 将 Shift 中文标点的文本事件先于字符按键事件提交的顺序，不丢失首次输入；普通字符仍沿用 xterm 的去重处理。

终端正文的右键/中键功能由常规设置独立选择，默认无动作；配置为粘贴时在实际按下事件内读取系统剪贴板，复用上述粘贴流程，并消费对应鼠标手势，避免同时向远端程序发送点击。macOS Control+主键单击按右键处理。默认菜单与系统中键选区粘贴由宿主阻止；无动作仍保留远端鼠标协议。标签栏通过中键 auxclick 关闭动态标签，沿用关闭确认与归档，固定页不可关闭，与正文中键设置无关。

SFTP 侧栏拖至所属终端的路径插入复用同一粘贴入口和长度/会话检查，使用终端自身的括号粘贴模式；该动作只作用于落点终端，不展开广播目标，也不追加 Enter，路径引用及手势边界见 [SFTP](16-sftp-workspace.md#2-目录与路径)。

主机页监听 Cmd/Ctrl+F 聚焦搜索，并提供方向键、Shift 范围扩选、回车和 Escape 导航：方向键导航不依赖卡片焦点，没有选区时主动选中首项；已有选区时按实际布局继续移动，空搜索框方向键转到首台主机；回车连接单项，多项先确认工作组或独立标签。Ctrl/Cmd+单击增减多选，Shift+单击选取范围。控件只处理未被上层路由消费的按键，IME、模态、弹层及用户自定义应用快捷键仍优先；操作地址正文时保留原生文字选择。

## 3. macOS 原生菜单与关闭

固定 Cmd+, 由 AppKit 应用内事件监视器交给原生设置菜单，成功处理后消费事件，避免逗号进入输入框或重复触发。前端不默认绑定该组合，残留同组合绑定也不执行；用户仍可配置其他设置快捷键。此组合不受前端模态或录制拦截，但打开设置仍须通过解锁与窗口权限检查，不属于系统后台热键。

模态中 Cmd+W 被消费，不关闭标签或主窗口，保护独立于关闭标签的用户绑定。原生文件/窗口菜单的关闭项没有 Cmd+W，显式菜单及窗口按钮继续走关闭确认。日志 TAB 的关闭快捷键只关闭回看页；Cmd+Q/应用退出由 Rust 拦截，等待主窗口保存终端日志后才退出，保存失败保留窗口。设置窗口不注册终端或工作台命令，Cmd/Ctrl+W 等待设置写入后关闭，录制和模态优先。

原生入口见 [macos_menu](../src-tauri/src/macos_menu.rs) 和 [settings_window](../src-tauri/src/settings_window.rs)。

## 4. 终端链接与配置入口

自动 URL 与 OSC 8 链接均须匹配配置的修饰键主键点击；普通点击/拖动保留选择及远端鼠标语义。Rust 再校验 http/https、长度与控制字符，拒绝 file/javascript 等协议；输出不得自动打开链接。

配置校验位于 [settings.rs](../src-tauri/src/settings.rs)，终端粘贴与链接执行位于 [registry.ts](../src/modules/terminal/registry.ts)。
