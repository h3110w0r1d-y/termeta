当前凭据基线：可复用密码/私钥（含可选解密密码），主机可引用公共凭据或直接填写专属密码，非空自动保存、留空连接时询问；无记住开关。用户明确不做旧数据库兼容迁移，当前使用重建 schema，旧库与真实凭据未修改；详见 [存储](07-storage.md) 与 [ADR-022](12-decisions.md#adr-022公共凭据与主机专属密码2026-10-15)。

## 开发基调

构建 Windows、macOS、Linux 桌面 SSH 客户端，先形成可靠的交互终端，再逐步发展为包含 Local Terminal、串口和专业 SSH 工具的产品。首期 SSH 不以本地 PTY 为前置条件。Android/iOS、云同步与团队系统不进入首期，也不预先搭建其框架。

保留已创建的 Tauri 2 + Vue 3 + TypeScript 技术栈；Rust 核心与 Tauri 壳分离。优先保证主机身份校验、稳定生命周期、端到端流控与可维护的接口，不用占位 UI 冒充已实现功能。

明确交互基线：断线或连接失败保留 Tab 和原 xterm 缓冲，历史可滚动/复制/搜索；重连仅替换后端连接，在同一终端中继续追加。通用 UI 控件采用 Naive UI 2.45.3 的现成组件与主题，Reka UI 已移除；工作区顶部/侧栏标签按用户要求改为独立 WorkspaceTabs，设置标签仍用 Naive UI。选区蒙色由独立主题适配模块处理，未修改 xterm 源码，视觉效果待复验。

补充功能基线：M2 提供全局/终端快捷键自定义与独立终端配色设置；M3 提供可停靠 SFTP 面板、两侧可选本地/远端的双栏 SFTP Tab、跨主机复制与统一冲突处理。原生拖出单独验证，SFTP 当前仅提前实现固定未连接双栏布局，实际文件能力未实现。

## 阅读约定

- **现状**：通过仓库文件确认的已存在内容；**决策**：本项目采用的设计方向；**候选**：接入前需要验证的方案；**目标**：尚未测量的验收指标。
- M0 为预研；M1 为 SSH 纵向切片；M2 为 SSH MVP；M3 为专业 SSH；M4 为 Local/Serial；M5 为分发与产品化。
- P0 为当前所属里程碑必须完成，P1 为后续增强，P2 为长期方向。优先级不能脱离里程碑解读。
- `host/profile` 是持久化连接配置；`session` 是后端一次连接尝试的生命周期；`connection` 是底层 SSH 传输，未来可承载多个 channel；`terminalId` 是前端持久终端视图标识，跨重连不变；`pane/tab` 是视图布局节点，不等于 connection。
- 所有示例类型、SQL、协议均为设计契约，不代表已有可编译实现。细节变更要同步关联文档。
- 文档描述的接口使用 snake_case 命令与 camelCase JSON 字段；字节流永远保持原始字节，显示解释在消费端完成。

## 本轮交付边界

首期已新增 core、ssh、storage、security 四个 crate、原生命令与 ACL、Vue 主机/终端/设置模块。完成源码静态复核和格式化；验证命令及实际结果见 [实施状态](17-implementation-status.md)。代理未构建、启动应用、连接真实主机或执行 Rust 测试；用户有既有版本日志与终端使用反馈，不能据此宣布当前 MVP 验收完成。

内置终端字体：固定12项、本地资源与许可证，来源/版本详见 [字体资源清单](../public/fonts/README.md)，交互与加载行为见 [桌面 UX](09-desktop-ux.md#6-字体主题与可访问性)。

内置配色当前为用户指定解包数据提取的64套方案，替换原8套自有预设，默认 Pro；来源与映射见 [配色资源](../resources/README.md)，决策见 ADR-024。
