# Snippets 与会话日志

更新：2026-10-20。片段管理、关闭归档与只读回看已有源码；编译、退出行为及四协议运行验收尚未完成。

## 1. Snippets

保险箱导航按主机、端口转发、凭据、Snippets、主机信任、会话日志排列。Snippets 支持新建、编辑、搜索和确认删除，名称与多行正文保存在本机加密保险库；更新和删除使用版本校验避免覆盖过期编辑。正文最多 64 KiB，保留首尾空格与换行，不接受空白正文或 NUL。

片段执行、插入终端或自动运行不在当前范围。Snippets 纳入白名单业务快照；第三方恢复新增副本，官方同步按稳定 ID 合并，均不执行内容。见 [备份](22-data-backup.md) 与 [官方同步](26-official-vault-sync.md)。

## 2. 归档时机与内容

会话日志替代原连接历史。创建配置、连接、断线、失败及远端退出均不写会话日志；关闭终端标签、关闭分屏窗格、关闭主窗口或正常退出应用时，才从该稳定终端实例提取文本并提交数据库。重连共用同一视图，最终归档该视图现存缓冲，不按每次后端 session 分拆。

日志通过固定 SerializeAddon 序列化 xterm 普通缓冲与关闭时仍激活的备用屏，保留当前滚屏范围、原始行列、ANSI 16/256 色、RGB 真彩色及样式，并冻结归档时的默认前景/背景和完整调色板（包含 OSC 动态改色）。保存的是终端缓冲快照，不记录持续原始输出或已被清除、滚屏淘汰的内容，不恢复可交互会话。正文采用版本化 JSON 封装，继续保存在已有 content 字段，无需数据库结构变更；旧纯文本记录仍可回看，已丢失的颜色无法恢复。封装后的正文最多 128 MiB，超过限制明确报错并保留终端，不能静默截断。

每条日志独立保存名称、协议、账号、主机/设备路径和端口等基础连接信息副本，以及开始/关闭时间。字段按协议适用性留空，Serial 的主机字段为设备路径，Local 没有远端账号、地址或网络端口。日志不包含凭据、认证配置或主机配置外键，删除配置不影响日志。终端输出本身可能包含用户命令或远端显示的敏感内容，按本机加密数据库保护。

## 3. 关闭与退出

关闭先禁止新输入、取消连接并等待后端终态和尾输出进入 xterm，再提取带配色的缓冲快照、等待数据库完整提交，最后销毁终端。标签、窗格与窗口退出都调用 TerminalRegistry 的统一关闭入口；重复关闭共用一次任务，同一终端 UUID 重试只保留一条最新归档。跨所有入口共享最多两项归档并发预算，等待连接、终态与尾输出使用完成信号。写入、尾输出等待或连接取消失败时阻止关闭并保留视图供重试。

窗口关闭和 Cmd+Q/应用退出请求统一等待归档；归档期间禁用主窗口交互，阻止迟到的新连接入口。应用退出使用 Rust `ExitRequested` 拦截与主窗口完成握手，不依赖不能等待异步提交的 `beforeunload`。

系统“强制退出”、SIGKILL、进程崩溃或断电无法执行此关闭流程。按“仅关闭时保存”的边界，不维护运行中正文检查点，因此这些情况不能保证未关闭视图的日志保留。退出握手、尾帧与落盘时序仍须三平台真实验收。

## 4. 回看与数据边界

会话日志页支持搜索、分页、查看、删除与清空。独立只读日志标签按需读取正文，不进入 Pinia，也不参与分屏/广播。普通历史先按原尺寸还原，再随窗口重排并使用 xterm 内部滚动；备用屏保持关闭时行列，通过独立视口双向滚动。2026-10-18 选择两种尺寸策略，以兼顾历史阅读与全屏程序布局。

回看须通过版本、尺寸、颜色和控制序列白名单校验，只还原受限终端样式/定位，不执行 OSC、链接或其他控制动作；无输入、会话 IPC 或链接激活。旧纯文本作为文本显示，已丢失的颜色无法恢复。

`session_logs`、`snippets` 在解锁初始化时幂等建表，不改写已应用迁移；旧 `session_history` 仅作 schema 兼容遗留，不再读写或转换。日志由用户显式删除/清空，无自动数量裁剪。

会话日志与终端正文不进入云备份，Snippets 进入。逻辑备份是白名单重建，不能使用活动数据库复制代替，详见 [存储](07-storage.md) 与 [备份](22-data-backup.md)。
