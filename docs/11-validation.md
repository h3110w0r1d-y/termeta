# 验证、兼容性与性能计划

最后更新：2026-10-15。以下运行项目均待用户明确授权执行；源码存在、静态检查通过和用户早期反馈均不代表当前版本验收通过。

## 1. 执行原则与证据

遵守 AGENTS.md：未经明确要求不构建、启动、执行测试、创建 SSH 测试服务器或连接真实主机/串口。可执行不构建项目的类型、格式、依赖清单、ACL、文档和差异静态检查。安装依赖禁用会触发构建/运行的生命周期脚本。

每项证据记录日期、工作树状态、平台/架构、工具链/锁版本、服务器版本、步骤、预期/实际与资源测量方法。使用专用测试数据，报告不含凭据或终端敏感正文；清理测试 OS item 和临时文件。fake driver 测试源码已存在但未运行，不能以 fake I/O 证明硬件或 SSH 互通。

## 4. 工作区与广播

| 场景                                        | 通过条件                                                                              |
| ------------------------------------------- | ------------------------------------------------------------------------------------- |
| 排序、四向合并、嵌套比例、窗格拖回 Tab/跨组 | 每个 terminalId 只出现一次；宿主 DOM/xterm 不重建；取消恢复原活动组，空组收缩         |
| 悬停切页/末尾插入/边界与小窗口              | 600 ms 切页目标正确、唯一提示线；固定页不参与、比例不越界、焦点和标题无残留           |
| 开启 SFTP 后拖工作区                        | 可排序，但既不能作为来源也不能作为目标形成分屏；Workspace 中 SFTP 开关无效            |
| 广播键盘/IME/粘贴/滚轮                      | 只发到本组有效连接、各自编码；点击/拖动/自动应答/认证不扩散，普通历史滚动不广播       |
| 广播变更与取消                              | 粘贴只确认一次；成员/组/会话代次变化使旧任务失效，重组关闭广播，比例与排序保留        |
| xterm 升级                                  | 复核 inputOrigin 内部用户输入事件，缺标记时禁用广播；公开 onData 不得独自承担来源判断 |

OSC 标题仅展示且不持久化；关闭提示验证 OSC 133 执行阶段与首次标题比较的组合规则、空信息、重连和整组关闭。该规则是启发式，不能证明远端进程空闲。

## 5. SFTP 验收矩阵

当前范围为浏览、上传和下载。所有原生拖入、Finder 拖出及以下端到端场景均待运行验收；独立双栏/本地浏览/跨端点复制/租约仍按后续实现单独验收。

| 场景           | 通过条件                                                                                                                                                                                                                                                                                                                                                                       |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 浏览与分页     | 每次最多 100 远端项，跨 READDIR 包不丢/重；10000 项/256 KiB 限制可见，隐藏项和选择计数正确                                                                                                                                                                                                                                                                                     |
| 显示与导航     | 选择框/名称图标/大小/权限；1024 进制两位小数；目录及目录链接始终优先，`..` 置顶且根目录禁用                                                                                                                                                                                                                                                                                    |
| 软连接         | READLINK/STAT 识别目标，失败降级未知；实际以 `/bin/...` 逻辑路径请求，不先展开目标；`..` 回逻辑父目录                                                                                                                                                                                                                                                                          |
| 文件上传与冲突 | 多选文件，已存在普通文件明确确认才截断写入；新文件独占创建，目录/链接/特殊项不被文件替换，取消/断线显示部分内容风险                                                                                                                                                                                                                                                            |
| 目录上传       | 同名目录保留并合并，逐文件确认；不删目录兜底，不跟随本地链接，树内远端链接拒绝自动合并，64 层/10000 项上限                                                                                                                                                                                                                                                                     |
| 原生拖入       | Finder/Explorer/Linux 文件管理器、Retina/多 DPI、取消及重复事件；仅当前侧栏目录为目标，确认后消费 owner-bound 一次性 dropId                                                                                                                                                                                                                                                    |
| 拖入授权       | 5 分钟/16 批/每批 1000 根路径限制；过期/跨窗口/重复消费拒绝，WebView 不能伪造本地路径                                                                                                                                                                                                                                                                                          |
| macOS 拖出     | 文件/真实目录/混合多选，Copy 外部接受后才显示下载记录；Esc/内部松开/无效落点不建记录，也不反向触发上传；内部Drop在源结束前后到达均忽略上传，取消后立即拖入Finder文件仍正常                                                                                                                                                                                                     |
| 文件承诺       | Finder 给出精确目标 URL 后才读取远端；后台串行写入，全部承诺和拖动完成后才报成功；刚越过阈值在软件内立即松键、源回报Copy或缺失ended时均按内部Drop/松键收尾并可再次拖动，不等待5秒，不生成下载记录；外部未兑现条目的空闲等待最多5秒，期间若开始写入则暂停计时；收尾后首次按钮点击、行选择和再次拖动均有效，无需第二次操作；外部成功后不抢Finder焦点；迟到回调拒绝、不重叠新任务 |
| 目录拖出       | 64 层/10000 项；独立目录句柄不扰动侧栏，源链接/特殊项明确失败；只创建新目录、不覆盖/删除旧目录，部分成功报告路径/数量                                                                                                                                                                                                                                                          |
| 普通文件下载   | 本地同目录独占临时项+硬链接无覆盖发布，拒绝同名；本地文件系统不支持硬链接时明确失败，不删除旧目标                                                                                                                                                                                                                                                                              |
| 队列与取消     | 最多 32 等待批次/20 结束记录，全局 4/每浏览器 1；选择器、扫描、确认、读写及原生回调可取消，隐藏继续、断线不重放                                                                                                                                                                                                                                                                |
| 故障与安全     | 磁盘满/配额/无权限/源大小变化/目标竞态/关闭窗口/断线清理；不伪报成功，不泄露正文，64 KiB 流保持有界且终端响应                                                                                                                                                                                                                                                                  |

Windows/Linux 原生拖出尚未实现，明确显示使用下载按钮；不能把替代操作视为 SP-11 通过。SFTP v3 缺通用 NOFOLLOW/条件写入，测试并发路径替换并记录限制，不宣称原子覆盖或完全消除竞态。

## 7. 性能与安全门槛

以下是待测初始目标，不是已达成指标：

| 指标        | 目标/方法                                                                         |
| ----------- | --------------------------------------------------------------------------------- |
| 启动/交互   | 离线冷/热各 20 次 p50/p95，启动 ≤2 秒；低延迟网络应用新增开销 p95 ≤20 ms          |
| 持续输出    | 可见终端 ≥2 MiB/s 持续 60 秒，以实际消费 ACK 计；高输出 10 分钟无持续线性内存增长 |
| 多会话/内存 | 20 会话、5 持续输出仍可操作；单普通会话进程树目标 ≤200 MiB，10 会话 ≤500 MiB      |
| 关闭/泄漏   | 正常/无 ACK/远端无响应取消 p95 ≤3 秒；100 次连接关闭无残留 session/task/socket    |
| 文件传输    | 4 并发大文件及目录扫描时内存有界，进度节流，终端输入/KeepAlive/取消仍响应         |

记录 CPU/内存、屏幕/字体/WebView/构建模式与网络 RTT；debug 结果不直接当 release 指标。有界、可取消、无静默丢字节和输入不重复优先于吞吐。发布前处理 [依赖公告](17-implementation-status.md#4-依赖与公告核查)、补齐 notices、源数据许可和三平台运行证据。
