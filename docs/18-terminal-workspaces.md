# 终端工作台与工作区存档

更新：2026-10-18。工作台管理运行标签、分屏与输入广播；工作区存档只保存布局和连接引用。当前没有自动恢复打开标签、跨窗口拖动或整体工作区合并；源码完成不代表桌面与三平台验收通过。

## 1. 运行模型与生命周期

`Workbench` 管理全部终端；`TerminalTabGroup` 是一个动态标签的布局；`TerminalItem` 保存单终端轻量状态；`Workspace` 表示多终端工作区及其显式存档。已保存工作区只剩一个窗格时仍保留存档身份。

[工作台 Store](../src/modules/workbench/store.ts) 分离 terminals 与 groups：activeId 指固定页或标签组，activeTerminal 指聚焦终端。布局树仅含终端叶子与带方向、比例的分割节点，不保存会话句柄、秘密或输出。每个 terminalId 只属于一组，焦点须指向组内叶子，删除叶子自动收缩空分支。

[TerminalStage](../src/modules/workbench/TerminalStage.vue) 按布局矩形在同一平面以 terminalId 挂载宿主，[TerminalRegistry](../src/modules/terminal/registry.ts) 持有 xterm。排序、切页、分屏、比例调整、区域交换和窗格迁移保留实例、缓冲、选区及连接；重连只更新 sessionId。断线、失败和远端退出不关闭视图。

## 2. 布局与关闭行为

固定保险箱/SFTP 不拖动、不接受合并。动态标签可排序；单终端可拖入目标窗格四向分割，窗格可在组内重排、跨组迁移或拖回独立标签。每次只分割命中的叶子，可嵌套；取消或无效释放不修改布局。纯排序保留活动标签和焦点。

分割比例限制 10%–90%，支持指针与键盘调整；交换手柄交换完整子树，保留区域比例、终端与广播成员。窗格聚焦决定搜索、配色和重连目标。关闭标签关闭整组，关闭窗格只关闭自身；先等待尾输出和会话日志提交再释放终端，失败则保留视图和错误。独立日志 TAB 只保存摘要引用，正文按需回看，不参与分屏、迁移或广播，见 [日志契约](23-snippets-and-session-logs.md)。

普通标签支持复制连接或向右拆分，创建独立会话并认证，不复制历史或输入；串口禁止复制，SFTP 侧栏开启时禁止拆分。标签双击可配置无动作、关闭、复制、拆分；工作区仅支持关闭。分组批量打开可创建独立标签或均分布局，不改动已有终端。

布局操作见 [layout.ts](../src/modules/workbench/layout.ts)，拖动见 [useTabDrag.ts](../src/modules/workbench/useTabDrag.ts)，关闭协调见 [useTerminalClose.ts](../src/modules/workbench/useTerminalClose.ts)。文件原生拖放与标签布局拖动彼此独立。

## 3. 输入广播

广播按组管理、默认关闭、仅驻内存；至少两个已连接的非 SSH 命令模式终端才能开启。成员重组或关闭窗格会关闭广播；标签排序、比例调整和区域交换保持状态。隐藏组、认证中、断线及关闭中的目标不接收广播。

键盘、IME 和粘贴只能由当前组聚焦且已连接的终端发起；远端滚轮可来自当前组未聚焦窗格，不改变键盘焦点。命令模式窗格不作为来源或目标，直接输入仍有效。设备/光标/焦点应答、认证、复制、选择、搜索、鼠标点击和拖动不广播。

只转发源 xterm 实际生成的最终用户输入。滚轮提取最终垂直动作，按各目标的光标/鼠标协议编码一次，不派发合成 wheel，也不在目标再次累积触摸板增量；普通历史滚动仍留在本地。目标独立排队、限额与检查会话代次，不保存、重试或重放输入，不保证远端程序同步执行或可见结果一致。

广播粘贴只确认一次并显示目标数量；各目标使用自己的括号粘贴模式。等待剪贴板或确认期间切组、切焦点、来源重连、广播或成员变化会取消，目标换会话或断线不补发。

来源识别与最终鼠标动作编码集中于 [inputOrigin.ts](../src/modules/terminal/inputOrigin.ts)，依赖固定 xterm 6 的内部能力；缺失时拒绝开启广播，单终端仍可输入。升级必须复核用户输入/自动应答区分、IME、鼠标协议与事件顺序。路由见 [inputRouter.ts](../src/modules/terminal/inputRouter.ts)，不依靠输入正文猜测来源。

## 4. 标题与关闭

远端 OSC 0/2 标题仅存内存，显示前清理控制及双向格式字符并限制长度，不改写原始输出；重连与结束清除旧值。普通标签保留原名称和连接编号，工作区显示保存名称及聚焦窗格的远端标题。

开启 confirmClose 时，已连接的 SSH 命令模式始终提醒；交互 Shell 根据 OSC 133 执行状态或标题冒号前缀相对首次值的变化提醒，目录后缀变化不提醒。标题和标记由远端提供，不是可靠命令检测，不从键盘输入推断。组/窗口统一确认，SFTP 传输另行确认。实现见 [activity.ts](../src/modules/terminal/activity.ts) 与 [title.ts](../src/modules/terminal/title.ts)。

## 5. SFTP 互斥

SFTP 侧栏仅面向单 SSH 终端。开启时不能作为分屏来源或目标，标签排序仍可用；隐藏后恢复合并，既有浏览与任务继续绑定原会话。断开/关闭取消，重连不重放。文件浏览、原生拖放与双栏对拷见 [SFTP](16-sftp-workspace.md)。

## 6. 显式保存与替换工作区

运行工作区标签菜单提供保存入口；打开弹窗时捕获布局，命名不使用远端标题。保存项与 SSH/Telnet/串口共用名称空间，trim 后区分大小写。只允许替换同名工作区，保留其 ID、分组与收藏；与其他类型同名报错。Rust 使用事务、revision 与唯一索引防并发覆盖。

`SavedWorkspace` 包含 root 和 focusedIndex。叶子为已保存 SSH/Telnet/串口的 profileId，分支为方向、比例及两个子树；焦点使用树遍历叶子序号。同一连接可被多次引用，每次打开独立会话。最多 64 个窗格、32 层分割，比例 10%–90%，焦点必须有效；DTO 拒绝额外字段。

不保存 terminalId/sessionId、密码、私钥、输出、运行状态、广播或远端标题；临时连接、Local、嵌套工作区及失效引用不能保存。保存事务验证引用存在，打开前验证整份存档，失效时不创建部分终端。删除连接不删除存档；引用连接后续编辑在下次打开时生效。

打开存档生成新终端和分割节点，恢复布局、比例、焦点与名称，广播关闭，不复用现有会话或缓冲。批量打开的存档各自独立，不嵌套入均分布局；打开标签和终端状态仍仅在内存。

SSH 交互 Shell 与命令模式可保存为不同名称的连接后组合存档，例如操作 Shell 与监控程序并排。存档仍只引用 profileId，命令取最新保存配置；活动会话使用后端 sshCommand 快照，不受编辑影响。命令退出保留输出，手动重新运行，不自动进入 Shell 或重启。

入口为 [SaveWorkspaceDialog](../src/modules/workbench/SaveWorkspaceDialog.vue)、[Store](../src/modules/workbench/store.ts) 与 [workspaces.rs](../crates/terminal-storage/src/workspaces.rs)。保存命令仅允许已解锁主窗口，存储模型见 [存储设计](07-storage.md)。SQLCipher 真实升级、保存/替换、重新打开认证及布局/广播的三平台行为仍需运行验收，统一见 [产品需求](01-product-requirements.md)。
