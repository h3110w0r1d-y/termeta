# 终端标签排序、分屏与输入广播

日期：2026-10-15。范围：按用户要求提前至 M2-13 的内存布局功能。**源码已实施，尚未完成编译/运行或桌面验收。** 不改变 SSH、IPC、存储与凭据契约。

## 1. 交互规则

- 首页与 SFTP 是固定标签，不拖动、不接受终端合并。动态单终端与 Workspace 标签可在顶部/左侧布局内排序，插入位置显示标记；会话滚动区边缘自动滚动。
- 主键按下移动至少6px才进入拖动，普通点击继续激活标签。拖动不会先激活源标签，因而可以将非激活的单终端拖入当前终端区。
- 当前激活标签拖到自身终端不操作。非激活的单终端标签可以作为合并来源；Workspace 可接受更多单终端。本期不支持整体 Workspace 合并。
- 在目标子终端中按归一化坐标选取最近的上/下/左/右边缘，绿色半透明遮罩覆盖该子终端对应一半。松手后原目标标签成为或继续作为 `Workspace`，来源标签消失，来源终端获得焦点。
- 窗格标题可拖回动态标签栏，按插入标记成为独立Tab；拖至最后一个Tab后方整片标签栏区域（含新建按钮、空白、间隙与连接数）放到末尾，最后一个Tab后半区与后方整区统一在新建按钮前显示唯一末尾插入线；拖动期间新建按钮不响应hover。也可拖到同一Workspace的其他窗格重分割，拖到自身无操作。跨组移动时，在目标动态标签悬停600ms切换，再拖入目标窗格四向分割；直接松在标签上仍是创建独立Tab。取消或无效释放时恢复拖动开始的活动标签，不修改布局。
- 每次只分割命中的叶子，初始比例各50%，可以嵌套。分隔线可拖动，比例限制10%–90%；指针调整还按子树尺寸尽量保留80px。极小窗口或深层嵌套不能保证每个终端始终达到80px。
- 分隔线可键盘聚焦，方向键每次调整5%，Home/End调整到10%/90%。Escape、失焦、指针取消/丢失捕获时清理拖动状态和遮罩；Escape结束分隔线拖动，已调整比例保留。
- 点击子终端使其成为活动终端；搜索、重连、配色和右键动作以聚焦终端为目标。子终端标题菜单明确显示目标名称。
- 标签关闭/关闭标签快捷键关闭该组全部终端，仅成员可能正在执行命令时统一确认一次；子终端关闭按钮只关闭自身。关闭后折叠空分支，剩一个终端时恢复该终端标题，组ID保持稳定。关闭期间禁止相关终端再次合并，失败终端保留并显示错误。

## 2. 状态与生命周期不变量

`WorkspaceStore.tabs` 保存全部终端轻量元数据；`groups` 保存导航顺序和 `{ id, root, focusedTerminalId, broadcast, broadcastRevision }`。`activeId` 是固定页或标签组ID，`active` 仍是聚焦终端元数据，不能将二者混用。

布局节点：

```ts
type LayoutNode =
  | { kind: "terminal"; terminalId: string }
  | {
      kind: "split";
      id: string;
      axis: "horizontal" | "vertical";
      ratio: number;
      first: LayoutNode;
      second: LayoutNode;
    };
```

布局不保存会话句柄、秘密或终端输出。每个 terminalId 只归属一个标签组，聚焦ID必须是该树中的叶子；分割创建节点，删除叶子自动收缩，不存在空分割节点。排序/合并/窗格迁移不改变连接重复序号。拖出时新建随机标签组ID，避免来源组仍使用该terminalId为组ID时发生冲突；两组先计算布局后提交，来源自动收缩，任何叶子始终只属于一组。

`TerminalStage` 计算百分比矩形，始终以 terminalId 为 key 在同一层渲染全部 TerminalPane。树不是递归组件层级，合并、排序、切页与调整比例都不重新挂载/移动 xterm 宿主。TerminalRegistry、sessionId、Channel、历史与选区保持原对象；宿主尺寸变化由既有 ResizeObserver 驱动 fit/PTY resize。每个窗格沿用自身配色背景；外框使用固定透明边框占位，焦点/广播状态线统一由窗格内部的 `::after` 绘制，内缩一个边框宽度以避开终端区裁剪边界。覆盖层通过局部堆叠隔离限制在窗格内，且 `pointer-events: none`，不影响输入、选区或布局尺寸；不通过定时刷新或重建 xterm 清除残影。只有聚焦终端接收本地快捷键；开启广播时其远端输入经独立路由分发到组内已连接终端。

## 5. 当前工作区输入广播（M2-14，2026-10-15）

每个分屏标题的关闭按钮右侧增加一入三出图标，使用Naive UI按钮/主题，`aria-pressed`表示开关；同组所有按钮共享状态，点击切换并将输入焦点交回所选终端。开启时聚焦窗格实线，其他窗格虚线且颜色与主题一致。默认关闭、仅内存保存；拖入、拖出、同组重排和关闭窗格自动关闭，缩放分割线/标签排序不改变状态。切换其他标签不向隐藏组分发输入。

广播源仅为当前组的聚焦且已连接终端，目标按每次输入取得本组已连接且未关闭的终端快照；源只发送一次，后台断线/失败/认证中终端跳过。键盘、IME提交、回车、控制键、功能键与Option跳词沿用xterm编码；无修饰方向键/Home/End按目标应用光标模式适配。每目标独立FIFO/输入序号/64KiB预算，不等待其他目标，不保存输入或重试；不能保证不同远端程序状态下执行结果相同或同步完成。

自动设备/光标/焦点应答只回原会话。认证/信任弹窗、复制、选择、搜索、关闭、布局调整均不广播。鼠标只转发远端滚轮：来源/目标启用鼠标协议或处于alternate全屏缓冲时，由目标xterm处理合成wheel事件，按目标协议/尺寸计算坐标与滚动量；普通历史滚动仍本地，点击/释放/移动/拖动上报不转发。路由深度保护防止滚轮及粘贴在目标端再次扩散，也避免滚轮生成的方向键被当作键盘重复广播。

粘贴先抓取组/广播版本和各目标会话代次，现有多行确认只出现一次，并显示目标数量；确认后等待Vue更新并检查剩余活动弹层（AppDialog活动标记随open移除，不受离场动画影响），每目标调用自身`paste`，按其括号粘贴模式编码。确认/剪贴板等待期间来源换会话、切组/切焦点、广播开关或布局成员改变则取消，目标换会话/断线不补发旧输入；是否启用多行确认仍遵循用户设置。

**版本边界：** 公开onData混合用户输入与自动应答，onKey不覆盖IME。因此薄适配只订阅固定版本内部`_core.coreService.onUserInput`同步事件，在紧随的公开onData中消费标记，不修改库方法/源码，不启用proposed API。能力缺失时单终端输入仍工作，拒绝开启广播并显示错误；升级xterm必须复核事件顺序、IME、设备应答及二进制鼠标。此依赖局限于一个文件。

OSC标题显示（2026-10-15）：xterm公开onTitleChange接收OSC 0/2，TerminalTab.remoteTitle仅存内存，title.ts集中清理控制/双向格式字符并限制160个Unicode码点，统一格式为原名称 (远端标题)。普通Tab保留原名称与(n)编号，Workspace标签展示聚焦窗格标题后缀，分屏标题各自展示。空标题及正常结束排空后清除后缀，重连在接入新流前清除旧值。原始输出不改写，订阅由xterm生命周期管理。该信息取决于远端是否发送标题，可包含目录/程序名，并非可靠命令检测。

动态关闭提醒（2026-10-15）：activity.ts统一维护本次连接的首次OSC标题和执行阶段；OSC 133 C置为执行中，A/B/D置为非执行中，未知标记忽略。判定规则为：已连接且（执行中，或当前标题与首次收到的标题不一致）。即使收到D结束，标题不同仍按用户要求提醒；空标题也是有效首次标题，未收到标题且无C不提醒。不从键盘输入猜测命令。Tab/关闭快捷键/窗格/窗口均复用规则；Workspace/窗口只提示一次并显示可能执行命令的终端数量。保留confirmClose总开关，未执行则直接释放连接和历史；重连重新建立标题基准，结束后重置，不持久化。
