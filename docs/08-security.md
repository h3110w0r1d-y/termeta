# 安全与隐私边界

更新：2026-10-19。本文集中维护跨模块安全约束；协议、传输及备份的细节由对应文档维护。当前实现尚未完成完整安全审计或三平台运行验收。

## 1. 威胁模型

| 威胁/输入 | 主要措施 | 限制 |
| --- | --- | --- |
| 中间人/冒充 SSH 服务器 | 握手证明、主机公钥 pin、首次核验与变更阻断 | 首次允许仍依赖用户核验 |
| 恶意远端输出 | xterm 字节渲染、文本元数据、禁用敏感 OSC 动作 | 依赖终端解析器安全和资源限制 |
| 前端注入/远端页面 | 本地打包资源、CSP、导航限制、最小 IPC | 被攻陷的主窗口仍可调用其合法权限 |
| 跨窗口/旧资源引用 | 调用窗口、资源 owner、challenge 关联与会话代次检查 | 随机 ID 本身不是授权 |
| 静态数据或备份泄露 | SQLCipher、OS 主密钥缓存、独立密码加密云包 | 不防御已解锁进程注入、内存转储、同用户恶意进程或 root |
| 输出洪泛/恶意文件与包 | 有界队列、ACK、长度/数量/解析预算 | 协议库内部缓冲及真实内存水位仍需测量 |

不实现自定义 SSH 密码学。GCM 校验和 SQLCipher 页 HMAC 不提供整库旧快照回放检测；元数据可供离线猜测，密码强度仍重要。密码与 OS 主密钥同时丢失无法恢复，旧明文库不会自动加密或清理。

## 2. IPC、窗口与资源授权

自定义命令必须同时登记到 [`AppManifest::commands`](../src-tauri/build.rs)、[命令名单](../src-tauri/src/command_names.rs)、handler 和相应 [capability](../src-tauri/capabilities/)。只写 capability 不能替代应用命令 ACL。命令由 Tauri 注入窗口上下文，Rust 验证本地 URL、窗口标签及资源归属，不能信任客户端 owner 或类型提示。

[`state.rs`](../src-tauri/src/state.rs) 的授权边界：

- `owner`：已解锁的本地 main；负责会话、主机、凭据、文件、转发、信任、Snippets 和会话日志。
- `settings_owner`：已解锁的本地 main/settings；仅用于明确授权的设置、保险库改密、JSON 导出、备份和官方账号命令，不赋予通用会话权限。
- 未解锁 main 可查询/解锁保险库；专用云初始化仅允许完全全新的 setup 状态，不能访问既有锁定库。

ACL 决定可调用的命令，业务 owner 决定可操作的对象。session/challenge/私钥引用/文件授权/恢复令牌仍逐次验证；不开放任意 shell plugin、前端 socket、通用文件读写、原始 SQL 或批量读取秘密接口。

## 3. WebView 与外部输入

默认只加载本地资源，拒绝远端导航和新窗口；发布与开发 CSP 分开，见 [`tauri.conf.json`](../src-tauri/tauri.conf.json)。发布不允许远端脚本、eval、frame 或 CDN 依赖，字体随包提供。`style-src 'unsafe-inline'` 用于 Vue/Naive UI 与 xterm 运行时样式，不能据此宣称已完整防御 XSS。

外链只由用户操作触发，经 [native.rs](../src-tauri/src/commands/native.rs) 校验 http/https、主机、长度、空白/控制字符和用户信息后交系统浏览器；拒绝 file/javascript/任意自定义 scheme。前端显示 banner、标题、认证提示、文件名等不可信值时使用文本，不用 HTML 注入。

快捷键、配色与设置导入只接受已注册命令、合法上下文及字段白名单，不允许脚本、CSS URL、任意原生动作或自动远端输入；格式限额见 [快捷键](14-shortcuts.md)、[终端配色](09-desktop-ux.md#6-应用外观与终端配色) 和 [设置实现](../src-tauri/src/settings.rs)。通用 CLI/URI/系统终端集成仍需另行校验，不能把来源标签当作鉴权；已有termeta协议仅接受下述固定账号回跳。

## 4. SSH 信任与秘密

认证材料只能在服务器身份核验后读取和发送。未知密钥默认拒绝，用户可一次允许或保存信任；变更密钥阻断。pin 比较规范端点、算法及完整公钥，保存时事务重查，普通连接确认不能覆盖不同旧密钥。替换须先明确撤销再核验。

当前固定 `russh=0.64.1`，主机签名偏好移除 RSA/SHA-1，RSA 私钥认证要求服务器声明 SHA-256/512，不自动降级；其他算法沿用该 release 默认配置，证书主机密钥不支持。详见 [SSH](05-ssh-design.md) 及 [host_key.rs](../crates/terminal-ssh/src/host_key.rs)。

Keyboard-interactive 仅对当前密码配置的单个非回显 Password/密码精确提示自动发送保存密码一次；已尝试密码协议、OTP、复合/未知/回显或重复提示不自动填充。零提示轮与通知同样受提示限额及八轮上限约束，OTP 不保存。

保存的秘密只供 Rust 使用，公共 DTO 不返回明文。密码输入在前端和 IPC 中会短暂存在，提交/取消后清空，不写全局状态、持久缓存或日志；JS 字符串不能可靠擦除。Rust 对受控短期秘密使用 `Zeroizing`，不承诺 SQLCipher、协议库和 OS 内部所有副本清零。主密钥派生、缓存与可恢复改密契约集中见 [存储](07-storage.md)。

私钥仅通过原生选择器登记引用，读取上限 1 MiB、仅 OpenSSH 文本；导入后秘密和口令保存在加密数据库，不写临时明文文件。[安全读取](../crates/terminal-storage/src/key_files.rs) 在 Unix 使用 O_NOFOLLOW，拒绝符号链接、非当前用户或其他用户有权限的文件，并比对打开对象的设备/inode；引用绑定文件字节 SHA-256，变更须重新选择。Windows ACL/对象竞态、读取期间原地改写仍有限制，不能声称消除全部 TOCTOU。

## 5. 终端输出与输入

远端原始 bytes 只交终端渲染，元数据清理不能改变正文。OSC52 剪贴板读写被禁用；远端不能触发本机命令、打开链接、下载或写文件。远端标题仅作有界内存提示，不改保存主机身份或信任，也不作为元数据记录到数据库/会话日志。OSC 标题和执行标记均可伪造，关闭提醒不能证明真实进程状态。

多行粘贴默认确认，不自动 trim、换行替换或追加 Enter。广播默认关闭、不持久化，成员重组关闭；仅分发受识别的用户输入，排除认证、设备应答、鼠标点击/拖动和命令模式窗格。键盘/粘贴要求焦点，当前组未聚焦窗格可作为滚轮来源，分发源端最终滚轮编码；目标独立校验容量与会话代次，不向断线或新会话补发。固定 xterm 用户输入标记能力缺失时禁止广播，升级必须复核。详见 [工作区](18-terminal-workspaces.md)。

有界输入输出、合法帧 ACK、独立取消和终态尾输出隔离见 [IPC](06-ipc-and-streaming.md) 与 [会话](04-session-model.md)；输出 ACK 不得阻塞关闭、KeepAlive 或信任响应。

## 6. 协议、设备与文件权限

| 功能 | 必须保留的边界 | 详细契约 |
| --- | --- | --- |
| Local | 当前用户权限；仅已解锁 main 启动。当前只接受系统 Shell/主目录/继承环境，不接受客户端可执行路径、命令、cwd/env；完整进程树清理仍待完善 | [会话](04-session-model.md) |
| Serial | 保存配置不访问设备；打开时 Rust 校验平台设备名、参数、权限和独占，不修改系统权限或安装驱动。控制线改变可能影响设备 | [Serial](19-serial-terminal.md) |
| Telnet | 用户显式选择的明文 TCP，无加密/身份验证/TLS 或 SSH 自动回退；登录在终端内完成，不读取 SSH 凭据/信任，不单独采集输入；终端回显可进入本机关闭日志 | [Telnet](20-telnet-terminal.md) |
| SSH 系统识别 | 保存 SSH 的交互 Shell 完成信任/认证后，用固定只读命令和独立 exec；5 秒/32 KiB，返回值不参与授权、信任或算法降级 | [SSH](05-ssh-design.md) |
| 转发 | 保存 SSH 主机由 Rust 重读凭据并独立认证，不申请 PTY/Shell；默认回环，SOCKS5 强制回环且仅 TCP CONNECT，载荷只在 Rust 中转 | [转发](21-port-forwarding.md) |
| SFTP | 会话 owner 与本地原生授权分离；前端不能提交任意本地路径，正文只在 Rust 流动，不拼接 Shell | [SFTP](16-sftp-workspace.md) |

SFTP 上传覆盖/目录合并可能留下部分结果，不能回滚；下载无覆盖发布。递归不跟随源符号链接或特殊文件，远端名称受限。原生拖入引用一次性、owner 绑定且会过期；macOS 承诺拖出仅按系统授权目标兑现，取消拒绝迟到请求。SFTPv3 不能通用证明父路径稳定或任意远端对象身份，不能声称原子覆盖或严格源快照；限额、路径竞态及清理规则仅在 SFTP 文档维护。

## 7. 本机数据与云备份

SQLCipher 保护静态业务数据，元数据和数据库必须配对保留；已应用迁移不可修改，不跳过 SQLx 校验或手工改写校验和。改密要求旧密码并在加密副本上切换，故障保留恢复目录；见 [存储与恢复](07-storage.md)。

云包只含表白名单快照，独立备份密码派生密钥并整包认证加密；Snippets 纳入白名单，本机设置、会话日志、OS 主密钥和云认证不导出。备份密码与云秘密保存在本机 SQLCipher，读取仅返回存在标记，目标变化不能复用旧秘密。HTTPS、证书验证、禁重定向/自动重试、下载限额和解析预算共同约束不可信云输入。

恢复经结构/业务校验后仅新增合并，保留本机数据与 pin；一次性令牌绑定窗口/模式且 5 分钟过期。首次云端恢复只允许全新库，创建成功但导入失败时保留加密材料。格式、算法、提供方和初始化语义集中见 [数据备份](22-data-backup.md)，AES 认证成功不替代业务校验，Secret Gist 也不是访问控制保险箱。

## 8. 官方账号认证

账号服务使用固定HTTPS来源，邮箱密码仅为本次注册/登录提交，不落入Vue持久化状态；应用Token仅保存在Rust管理的SQLCipher设置中，不进入白名单备份。GitHub/Google授权通过系统浏览器，桌面S256 proof与提供方PKCE/Google nonce分离，服务端callback不返回应用Token，仅把独立短期确认码通过固定termeta://回跳URI片段传回应用；必须匹配本机现存flow/provider、发起窗口、解锁状态、代次和期限，与Rust proof共同验证后才发放会话，避免只转发授权链接就为远程设备登录。原始URI不广播到WebView，确认码不进入HTTP查询、日志或持久化设置；自动唤起受阻时保留默认收起的手动输入备选，输入提交后清除，不能分享给其他人。冷启动无设备proof，取消/关闭/锁定后也不得从外部URI恢复授权。第三方邮箱必须已验证，身份以不可变subject唯一匹配，相同邮箱不自动绑定；解绑保留至少一种登录方式。账号密码、保险库主密码和备份密码彼此独立。

授权flow绑定发起窗口与代次，退出、关闭或保险库锁定后不得接受迟到结果；网络失败时退出仍清除本机会话，远端撤销失败需提示。服务端限制flow有效期、轮询间隔、一次兑换及账号会话关联，提供方未配置默认关闭。反代和应用日志不得记录callback的code/state、密码、Token或proof。配置和验证边界见[认证契约](25-account-authentication.md)，真实OAuth、会话并发及平台浏览器行为尚未验收。

## 9. 隐私与验证边界

当前没有持续应用诊断日志或诊断导出，默认无遥测/崩溃上传。2026-10-18 按产品要求增加关闭时会话正文归档，仅保存到本机加密数据库，不持续采集输入；彩色回看仅向无连接的只读 xterm 还原经白名单校验的缓冲序列，不解释 HTML、OSC 或外部链接，不上传备份。终端显示内容可能包含用户命令、登录回显及远端输出的秘密，不能将其视为脱敏日志；连接信息副本只包含基础数据，不读取凭据。系统强制结束/断电不保证未归档正文，完整边界见 [Snippets 与会话日志](23-snippets-and-session-logs.md)。诊断或终端正文外发仍须独立明确授权。

发布前仍需验证错误密钥/跨窗口/旧 challenge 拒绝、恶意输出和资源限额、CSP/导航、存储恢复、依赖公告/许可、签名及更新链路。源码与静态检查不能替代安全审计或三平台验收；剩余门槛见 [路线](10-roadmap.md)。
